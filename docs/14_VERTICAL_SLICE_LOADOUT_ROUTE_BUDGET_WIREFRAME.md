2. 소림사 나한금강공

### 보호

- 적 후보 배정은 이 10권과 기초 행동만 사용한다.
- 후보 때문에 11번째 무공서나 적 전용 판정 규칙을 만들지 않는다.

- 필요한 기술만 노출하는 `candidate loadout`은 무공서 전체를 새 규칙으로 변형하는 것이 아니다.
- 정확한 영구 스테이터스와 AI 수치 가중치는 후속 밸런스/데이터 바인딩까지 가역이다.

## 2. 후보 15명 기존 무공서·기술 배정

### 공통 Loadout 계약

각 후보는 다음 네 층으로 구성한다.

```yaml
signature_manual:
available_manual_techniques:
basic_actions:
behavior_focus:
```

- `signature_manual`은 인물의 기억점이다.
- `available_manual_techniques`는 슬롯 학습 목표에 필요한 기존 기술만 사용한다.
- `basic_actions`는 이동·보법·막기·회피·속공·강공·명상·준비 등 승인 기초 행동에서 고른다.
- 후보의 개성은 기술을 새로 만드는 대신 `behavior_focus`와 공개 이력으로 만든다.

### Slot 1 · 첫 검문

#### 연교
- 시그니처: **화산파 매화검결**.
- 기술: `매화삼첩`.
- 기초 행동 강조: 속공 / 막기 / 이동.
- 목적: 먼저 압박하려는 습관과 방어/대기 반례를 통해 첫 합·중단을 읽게 한다.
- 금지: `이십사수매화검법` 같은 후반 종합 연격으로 첫 전투를 과밀하게 만들지 않는다.

#### 도겸
- 시그니처: **개방 강룡장결**.
- 기술: `견룡재전`.
- 기초 행동 강조: 속공 / 막기 / 준비.
- 목적: 한 번 부딪친 뒤 자세를 고치는 습관과 불리할 때 압박 전환을 만든다.
- 금지: Slot 1에서 `비룡재천`의 밀치기·합 복합성을 주 교훈으로 사용하지 않는다.

#### 채령
- 시그니처: **남궁세가 창궁무애검법**.
- 기술: `철검십식`.
- 기초 행동 강조: 이동 / 속공 / 회피.
- 목적: 전진을 맞받는 합 성향을 가장 직접적으로 표현한다.
- 금지: `창궁검뢰` 전조·거리3을 Slot 1의 중심으로 만들지 않는다.

### Slot 2 · 금강문답

#### 묵진
- 시그니처: **소림사 나한금강공**.
- 기술: `금강호체`, `대력금강장`.
- 기초 행동 강조: 막기 / 준비 / 강공.
- 목적: 방어·강건·전조 대응을 정면으로 학습.

#### 석무
- 시그니처: **하북팽가 팽가도결**.
- 기술: `맹호출림`, `백호단문`.
- 기초 행동 강조: 막기 / 준비 / 강공.
- 목적: 버티다가 방어가 무너진 순간 결착하려는 압박을 제공한다.
- 주의: 강건 자체는 팽가도결 9성 효과가 필요한 영역이므로, Slot 2의 강건 대표는 묵진이 맡는다. 석무는 **방어와 전조 대응의 변주**다.

#### 단소
- 시그니처: **화산파 자하심법**.
- 기술: `자하토납`, `자하회천`.
- 기초 행동 강조: 막기 / 명상 / 속공.
- 목적: 자원·방어를 보존하다가 저자원 상태에서 회복/공격 판단이 바뀌는 상대.
- 금지: 장기 회복전으로 전투 시간을 늘리는 무한 회복 루프.

### Slot 3 · 장풍의 선

#### 설하
- 시그니처: **개방 강룡장결**.
- 기술: `견룡재전`, 필요 시 `비룡재천`.
- 기초 행동 강조: 이동 / 보법 / 장풍.
- 목적: 장력 사거리와 접근 타이밍을 통해 `거리도 수`라는 질문을 만든다.

#### 우람
- 시그니처: **양가 양가창결**.
- 기술: `추풍일섬`, `연환쇄로`.
- 기초 행동 강조: 이동 / 보법 / 막기.
- 목적: 창끝 거리·접근·후퇴를 가장 직접적으로 보여준다.

#### 비연
- 시그니처: **사천당문 천기암기록**.
- 기술: **3성 `추혼표`까지만 이 Slice의 적 후보 기본 노출 범위**.
- 기초 행동 강조: 이동 / 보법 / 회피.
- 목적: 거리 1~3의 암기와 역진입으로 `쫓기/기다리기` 판단을 만든다.
- 보호: 5성 `비성추혼`의 `[관찰]` 획득은 적에게 활성화하지 않는다. 적 전용 관찰 예외를 만들지 않는다.

### Slot 4 · 유전의 문

#### 청허
- 시그니처: **무당파 태극검결**.
- 기술: `운수검식`, `사량발천근`.
- 기초 행동 강조: 회피 / 준비 / 막기.
- 목적: 공개된 과거 플레이 습관을 바탕으로 회피·합·반격을 배치한다.

#### 담월
- 시그니처: **소요파 소요보결**.
- 기술: `미진환보`, `소요환위`.
- 기초 행동 강조: 회피 / 보법 / 속공.
- 목적: 후수와 회피 성공 뒤 반격·재배치의 위험을 보여준다.

#### 진려
- 시그니처: **남궁세가 창궁무애검법**.
- 기술: `철검십식`, `창궁검뢰`.
- 기초 행동 강조: 준비 / 이동 / 강공.
- 목적: 준비·전조를 보여 준 뒤 플레이어의 반복 반응을 시험한다.
- 보호: 대응 판단은 과거 해결 이력과 현재 공개 상태만 사용한다.

### Slot 5 · 오봉연검

#### 적우
- 시그니처: **화산파 매화검결**.
- 기술: `매화삼첩`, `낙매추영`.
- 기초 행동 강조: 이동 / 준비 / 회피.
- 목적: 독립 연격의 실제 체력 피해 연결과 합·중단·잔여타를 종합한다.

#### 풍목
- 시그니처: **하북팽가 팽가도결**.
- 기술: `맹호출림`, `백호단문`.
- 기초 행동 강조: 막기 / 준비 / 속공.
- 목적: 방어 파괴 조건에 따라 두 번째 결착타가 이어지거나 끊기는 흐름을 보여준다.
- 인물 원형 보정: 선행 문서의 `연환 권객`은 **연환 압박형 중량 무인**으로 해석하며, 무기/외형 제작 때 팽가도결과 일치시키도록 가역 수정한다.

#### 라진
- 시그니처: **양가 양가창결**.
- 기술: `추풍일섬`, `연환쇄로`.
- 기초 행동 강조: 이동 / 보법 / 막기.
- 목적: 접근→연속 찌르기→후퇴의 위치/공격 연계를 한 계획으로 읽게 한다.

### 배정 회귀 결과

- 10권이 모두 최소 한 번은 후보군에 사용된다.
- 같은 무공서는 다른 슬롯에서 다른 기계 질문으로 재사용할 수 있다.
- 재사용은 제작비를 낮추고, 플레이어가 이미 본 무공을 다른 사람이 어떻게 쓰는지 비교하게 한다.
- 동일 무공 재등장은 새 규칙이 아니라 **무인의 운용 차이**를 보여주는 장치다.

## 3. 다음 상대 후보 확정 시점

정보 Route가 실제 다음 상대를 대상으로 작동하려면 다음 슬롯의 후보가 먼저 확정되어야 한다.

### 확정 흐름

```text
Duel Result 확정
→ 다음 duel_slot의 후보를 run seed로 1명 확정
→ 후보 ID 잠금
→ Growth/Recovery Route
→ Information/Preparation Route
→ 해당 후보 Briefing
→ Combat
```

### 보호

- Route 진입 뒤 정보 선택에 따라 상대 후보를 다시 뽑지 않는다.
- 정보 선택은 상대를 바꾸지 않고 **그 상대에 대해 무엇을 알게 되는지**만 바꾼다.
- 후보 선택용 seed·가중치·내부 랜덤 결과를 플레이어에게 공개하지 않는다.
- 후보 선택이 완전 균등인지 가중 랜덤인지는 후속 데이터 Decision까지 가역이다.
- 재도전은 전투 직전 RunState 복원 규칙을 따르고, 정보 노드 재선택으로 상대를 reroll하는 우회로를 만들지 않는다.

## 4. 성장/회복 Route 수치 Seed

기존 콘텐츠 정본은 다음 두 경로를 요구한다.

```text
주요 비무1~4 집중 수련 동일 무공 = 32
Route에서 동일 무공 최소 +6
→ Duel 5 전 38 도달 가능

주요 비무1~4 자유 수련 = 24
Route 고효율 자유 수련 = +14
→ Duel 5 전 38 도달 가능
```

따라서 R1/R3/R5/R7은 아래 가역 수치를 사용한다.

| 노드 | 회복 선택 | 집중 수련 | 자유 수련 |
|---|---|---:|---:|
| R1 | 최대 체력의 25% 회복 + 기력1 + 내력1 | 선택 무공 +1 | 자유 +3 |
| R3 | 최대 체력의 25% 회복 + 기력1 + 내력1 | 선택 무공 +1 | 자유 +3 |
| R5 | 최대 체력의 25% 회복 + 기력1 + 내력1 | 선택 무공 +2 | 자유 +4 |
| R7 | 최대 체력의 25% 회복 + 기력1 + 내력1 | 선택 무공 +2 | 자유 +4 |

모든 회복은 최대치를 넘지 않는다. 절초기세·영구재화는 회복 선택으로 지급하지 않는다.

### 경로 검산

- 집중 Route 전체: `1+1+2+2 = 6` → 기존 32와 합쳐 38.
- 자유 Route 전체: `3+3+4+4 = 14` → 기존 24와 합쳐 38.
- 회복 선택은 해당 노드의 성장량을 포기하는 대가가 있다.
- 성장과 회복을 한 선택에서 모두 최대치로 주지 않는다.

### 수치 상태

`REVERSIBLE_BALANCE_SEED`.

이 값은 다음을 검증하기 위한 출발값이다.

- 회복 선택이 패배 방지에 실제 가치가 있는가.
- 성장 선택을 항상 압도하거나 항상 열등하지 않은가.
- Duel 5 전 10성 도달이 가능한 선택지이지 강제 정답이 아닌가.
- 회복 포기로 인한 snowball이 지나치지 않은가.

사람 플레이·시뮬레이션 전 `BALANCE_PASS`를 주장하지 않는다.

## 5. 정보 Route의 실제 선택값

정보 노드는 수치 보상 대신 다음 전투의 **공개 정보 범위 하나를 확장**한다.

각 노드에서 3범주 중 1개를 선택한다.

### R2 · 역참의 소문

- `BODY_TRACE`: 방어/강건과 관련된 공개 스테이터스 또는 확인된 상태 사실 1개.
- `MANUAL_RUMOR`: 상대의 시그니처 무공서 1권과 현재 확인 가능한 기술 범위.
- `RECENT_DUEL`: 최근 비무의 정성 행동 습관 1개.

### R4 · 무기점 시연

- `RANGE_RECORD`: 시그니처 공격의 공개 사거리 사실 1개.
- `FOOTWORK_SIGHTING`: 이동/후퇴/접근 성향 1개.
- `PAST_RANGE_FAILURE`: 과거 사거리 실패 사례 1개.

### R6 · 나루의 비무담

- `EVADE_RECORD`: 현재 공개 가능한 회피 관련 사실 1개.
- `COUNTER_CASE`: 과거 반격 성립 조건 사례 1개.
- `HABIT_RUMOR`: 반복 행동에 대한 정성 습관 1개.

### R8 · 비무장 앞 객잔

- `CHAIN_TRACE`: 연속 기술/후속 행동 범위 1개.
- `INTERRUPTION_CASE`: 과거 중단으로 연계가 끊긴 사례 1개.
- `FOLLOWUP_RUMOR`: 첫 수와 후속 수의 관계에 대한 정성 습관 1개.

### 공통 출력

```yaml
source_type: public_fact | past_case | qualitative_habit
subject_candidate_id:
short_text:
source_label:
```

금지 필드:

```yaml
hidden_plan:
ai_weight:
exact_probability:
best_counter:
seed:
```

## 6. 비전투 Wire-level 정보 위계

전투 UI 정본의 정보 위계를 재사용한다. 비전투 화면은 전투 계산을 새로 만들지 않는다.

### 6.1 Main

**1차:** `새 비무행`, `이어하기`.  
**2차:** 기록/설정.  
**3차:** 버전·부가 정보.

첫 플레이에서 세계관 설명보다 `새 비무행`이 먼저 보인다.

### 6.2 시작 무공 6중4

**상단:** `이번 비무행의 시작 무공 4개를 고르십시오` + 선택 `N/4`.  
**중앙:** 6개 무공 카드. 카드 본체는 이름·문파·한 줄 역할·주/보조 능력치·3성 기술 역할.  
**상세:** 기술 효과/요구치/향후 성장 미리보기.  
**하단 고정:** 추천 배분 보기 / 선택 초기화 / `비무행 시작`.

보호:
- 4개 선택 완료 전 시작 비활성.
- `추천 배분`은 기본 정답이 아니라 모든 첫 기술을 열기 위한 soft guarantee 설명이다.
- 10권 전체를 시작 선택에 노출하지 않는다. 기존 6중4 구조를 유지한다.

### 6.3 Duel Briefing

**1차 영역 — 상대:** 이름/이명, 짧은 인상, 초상 자리, Duel slot의 감정 질문.  
**2차 영역 — 내가 아는 것:** 공개 스테이터스, 확인된 무공/기술, Route 정보 0~1개.  
**3차 영역 — 나의 현재 상태:** 체력/자원, 주요 성장 무공.  
**4차 영역 — 모르는 것:** 이번 잠금 계획/정확 순서/내부 AI 정보는 알 수 없음을 짧게 명시.  
**CTA:** `비무 시작`.

`알 수 없음` 영역은 정보 부족을 버그처럼 보이지 않게 하고, 숨은 계획이 의도된 게임 규칙임을 명확히 한다.

### 6.4 Combat Review Overlay

기존 Combat UI의 우측/오버레이 책임을 유지한다.

**상단:** `이번 비무를 가른 장면` 1문장.  
**중앙:** 결정적 사건 카드 1~3개.  
각 카드: `사건 → 실제 원인 → 결과` 3행.  
**하단:** `결과 보기`.

금지:
- 모든 로그 기본 펼침.
- 추천 행동.
- 다음 적 행동 추측.

### 6.5 Duel Result + Reward

별도 Scene.

**상단:** 승/패 + Duel 번호.  
**중앙 좌측:** 승인된 등급/핵심 지표.  
**중앙 우측:** 보상 3개 선택지 `자유 수련6 / 집중 수련(지정5+자유3) / 문파 전수`.  
**하단:** 상대 반응 1~2줄 + `강호행로 계속`.

보호:
- Review 원인 설명을 Result에서 반복하지 않는다.
- 보상 선택에는 정확한 지급량을 표시한다.
- 선택 뒤 확인 1회로 확정하고, 확정 뒤 route 진입 시 다음 상대 candidate ID를 잠근다.

### 6.6 Growth/Recovery Route

**상단:** 장소명 + `지난 비무 뒤 무엇을 우선할 것인가?`  
**현재 상태 strip:** 체력/기력/내력 + 주력 무공 성장.  
**중앙:** 세 선택 카드.

카드 공통:
- 선택 이름
- 즉시 변화량
- 무엇을 포기하는지 짧은 문장

예:

```text
숨 고르기
체력 최대치의 25% + 기력1 + 내력1
이번 노드에서는 수련 포인트를 얻지 않습니다.
```

**하단:** 선택 전/후 preview + `확정`.

### 6.7 Information/Preparation Route

**상단:** 이미 잠긴 다음 상대의 이름/이명 + `무엇을 알아볼 것인가?`  
**중앙:** 정보 범주 3개 카드.  
**선택 preview:** `확인하게 될 정보의 종류`만 표시하고 실제 답은 확정 뒤 공개.  
**확정 후:** 획득 정보 1개를 기록에 추가.  
**CTA:** `비무 준비`.

정보 카드에서 실제 내용을 선택 전에 전부 보여주면 선택이 무의미해지므로 범주만 선공개한다.

### 6.8 완주 요약

**상단:** `첫 강호 비무행 완주`.  
**1차:** 5전 결과와 상대.  
**2차:** 가장 많이 등장한 Review 원인 2~3개.  
**3차:** 집중 성장 무공 / Route 선택 이력.  
**4차:** 반복 인물 마지막 짧은 비트.  
**CTA:** `기록 저장 / Main`.

플레이어 유형 자동 라벨링과 정답 빌드 추천은 하지 않는다.

## 8. 5회 적대적 검토

### Loop 1 · 10권 재사용이 캐릭터 복제처럼 보이는가

공격: 같은 매화검결/양가창결이 여러 슬롯에 등장하면 후보가 팔레트 스왑처럼 보일 수 있다.  
조치: 같은 무공 재등장은 다른 기술 범위·행동 습관·감정 질문에서만 사용하고, 후보의 공개 이력과 대응 성향을 다르게 한다.  
재검사: **PASS**, 사람 플레이에서 인물 구분 회상률은 NOT_RUN.

### Loop 2 · 적 천기암기록이 관찰 규칙을 깨는가

공격: 5성 효과를 그대로 쓰면 플레이어 전용 `[관찰]` 경계가 무너진다.  
조치: 비연은 기본 노출을 3성 `추혼표`까지로 제한. 적 전용 관찰 예외 금지.  
재검사: **PASS**.

### Loop 3 · Route 성장 수치가 10성 경로를 망치는가

공격: 집중 Route 합계가 6 미만이면 기존 38 경로가 깨지고, 자유 Route가 14 미만이면 자유 성장 경로가 깨진다.  
조치: 집중 `1+1+2+2=6`, 자유 `3+3+4+4=14` 정확히 보존.  
재검사: **PASS**.

### Loop 4 · 정보 노드가 미래 상대와 불일치하는가

공격: 정보 선택 뒤 상대를 뽑으면 획득 정보가 무효가 되거나 reroll exploit이 생긴다.  
조치: Result 종료 때 next_candidate_id 잠금 → 두 Route → Briefing.  
재검사: **PASS**.

### Loop 5 · 비전투 UI가 전투 UI보다 복잡해지는가

공격: 8개 Route와 여러 정보 카드가 별도 시스템처럼 비대해질 수 있다.  
조치: 모든 비전투 선택은 3카드 이하, 상세은 필요 시 확장, 공통 `현재 상태 strip + 3선택 + preview + 확정` 문법 재사용.  
재검사: **PASS**.

### Clean-exit reattack

남은 P1/P2:
- `25% HP + 기력1 + 내력1` 회복값은 사람/시뮬레이션 전 가역이며 밸런스 PASS가 아니다.
- 후보별 정확한 영구 스테이터스·무공 성급·AI 가중치·seed 선택 정책은 데이터 바인딩 단계가 필요하다.
- 후보 15명의 이름·외형·성별·말투는 비주얼/캐릭터 기획 전 가역.
- Wire가 실제 15~22분 demo time budget을 만족하는지 Human NOT_RUN.
