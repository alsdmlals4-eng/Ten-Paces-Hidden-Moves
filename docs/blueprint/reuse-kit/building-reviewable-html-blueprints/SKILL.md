# 검토 가능한 HTML 블루프린트

사람이 원본의 목적·현황·이미지 쓰임새를 한곳에서 읽고 항목에 바로 의견을 남기는 파생 화면을 만든다. 프로젝트의 기존 기획·규칙·코드·자산 정본은 계속 원본이 소유한다.

## 먼저 연결할 것

- 현재 프로젝트의 지침, 기획/데이터 owner, 실제 화면·자산 사용처, HTML 생성기와 발행기를 확인한다. 이미 승인된 같은 범위는 이어서 수행한다.
- 기존 HTML이 있으면 그 생성기·리뷰 저장소를 확장한다. 결과 HTML만 고쳐 재발행 때 사라지는 변경이나 별도 정본을 만들지 않는다.
- 재사용 의도에 맞게 [십보강호 사례](references/ten-paces-example.md)의 필요한 consumer만 읽는다. 프로젝트명·장르·분류·게임 규칙은 복제하지 않는다. 기존 Base Visual Dashboard는 내용/권위 owner이고 이 스킬은 HTML 구현·검수 방법을 보완한다.

## 읽기·배치

- 항목마다 종류, 안정적인 표시 번호, 구체적 쓰임새, 만든 목적/기대효과, 검토 상태를 연결한다. 예: `전투 · 이미지 142 · 행동설계 상태창`.
- 번호와 댓글 ID를 정렬 위치로 만들지 않는다. 정렬·필터·재발행·폐기 뒤에도 같은 대상을 가리키게 한다. 같은 파일의 여러 사용처는 자산 ID와 사용처 ID를 나누어 기록한다.
- 분류는 실제 사용 화면/캐릭터/동작/기능으로 결정한다. 파일 이름만으로 전투 이미지를 휴식 화면에 연결하지 않는다. 근거가 없으면 사용처 미확인으로 표시한다.
- 관련 그림은 중간 크기의 비교 칸, 수치/비용/효과/조건은 공통 표, 사건은 제목·상황 한 번과 선택지별 결과 표로 묶는다. 공용 성장 규칙은 한 표로 두고 개별 무공은 차이만 적는다.
- 본문 이동은 해당 항목의 앵커로 연결한다. 사용자 요청 없이 공간을 차지하는 상시 사이드 패널을 늘리지 않는다. 코멘트는 대상 바로 아래에 둔다.

## 작성과 저장

[리뷰·미디어 계약](references/review-media-contract.md)을 필요한 부분만 따른다.

- 입력 직후 복구용 초안을 기록하고 잠깐의 유휴 뒤 영구 저장한다. 한글 조합 입력 중 전송/재렌더를 미룬다.
- 저장 완료 표시만 국소 갱신한다. 전체 목록 교체·해시 이동·scrollIntoView를 저장 콜백에 넣지 않는다. 스크롤, 초점, 선택 범위를 보존한다.
- 서버 확인 전 파일에 저장됐다고 표시하지 않는다. 브라우저 임시 보관, 저장 중, 저장 완료, 실패, 충돌을 구분한다. 여러 탭/늦은 응답이 새 내용을 덮지 않게 revision과 항목별 base를 확인한다.
- 폐기 요청은 검토 상태다. 실제 삭제는 사용자 권한과 확인한 파일·사용처 범위에 따른다. 요청 버튼만 누른 상태를 삭제 완료로 보이지 않는다. 삭제/이동의 원래 경로·해시·처리 결과를 남긴다.

## 이미지·움직임·속도

- 목록에는 크기가 제한된 미리보기, 확대에는 원본을 연결한다. 원본 승인 해시를 미리보기 해시로 덮지 않는다.
- GIF의 프레임을 정지 썸네일로 바꿔 놓고 재생된다고 하지 않는다. 영상은 목록에서 미리 전부 실행하지 않고 선택할 때 한 플레이어로 연다.
- 포스터가 보이는 것과 재생 성공은 다르다. 파일·MIME·CSP·Range 응답과 실제 브라우저의 시간/화면 진행을 확인한다. 잘못된 원본, 정지 캡처, 만료 서버, 디코더 문제를 나눠 진단한다.
- 이미지 영역 크기를 미리 확보하고 필요한 것만 지연 로딩한다. 불변 자료만 캐시하고 변경된 코멘트만 갱신한다.
- 개선 수치는 같은 조건으로 비교한다. 파일 참조량 감소를 FPS·초기 다운로드·실사용 지연 개선으로 확대하지 않는다.

## 결과 확인과 다른 프로젝트 적용

- [검수 시나리오](references/review-media-contract.md#확인할-상황)에서 바뀐 동작과 실제 위험만 검증한다. 프로젝트의 기존 테스트와 승인/검토 절차를 재사용하며 별도 횟수 규칙을 추가하지 않는다.
- 제공 예시는 `scripts/scaffold.py --output <빈 폴더> --project-id <id> --project-name <이름>`으로 만든다. Python 표준 라이브러리만 필요하다.
- 이 예시는 서버 없는 UI 패턴 시연이다. 코멘트는 현재 브라우저의 같은 미리보기 주소(origin)에만 보관되고 JSON으로 내보낼 수 있다. 포트·브라우저·PC 변경 전에 내보내도록 안내한다. 실제 프로젝트에는 기존 영구 리뷰 저장소와 발행기로 연결한다.
- 완료 시 원본 owner, 사용자 실행 경로, 저장 위치/한계, 실제 확인한 동작을 설명한다. Base 공통 규칙이나 다른 프로젝트에 적용하는 것은 사용자가 요청한 범위에서 별도로 수행한다.
