# 십보강호 사람용 블루프린트 · 통합 편집 구조

상태: 81쪽 사람용 통합 편집판 생성·최종 검수. 기존 82쪽 복원·대조판은 역사 비교용으로 보존한다. 제품 전체 구현 완료와는 구분한다.

## 최신 제작 순서 · 2026-09-10 사용자 확정

무공 10권의 3성·7성·10성 삽화를 먼저 제작하고, 해당 무공을 주력으로 쓰는 상대를
그 시각 언어에 맞춰 새로 제작한다. 기존 적 이미지 유지 지시는 이 범위에서 대체된다.
플레이어 캐릭터는 변경하지 않는다. 기존 상대 이름·보유 무공·전투 규칙을 자동 변경하지 않는다.
무공과 소개 문구가 충돌하면 연결된 실제 무공과 승인된 인물 설정을 대조하여 교정한다.
상대는 무기·옷의 구조·체형·자세·기운 색에서 주력 무공을 읽을 수 있어야 한다.
같은 무공을 쓰는 여러 상대는 동일 인물 복제 대신 얼굴·연령 인상·체형·소품으로 구별한다.
기존 원화·모션은 새 자산의 정본 등록·consumer 교체·런타임 검증 전까지 보존한다.
도감용 종이 배경 삽화와 전투용 투명 전신·모션·분리 VFX는 별도 산출물이다.
도감 삽화 생성 성공을 전투 모션 적용 완료로 표시하지 않는다.
최신 사용자 지시에 따라 무공 시연 인물과 상대 도감 모두 여성 무인을 포함한다.
여성을 회피·암기 역할에만 제한하지 않고 도법·장법 등 묵직한 무공에도 배정한다.
천기암기록은 여성 무인으로 제작을 시작했다. 성별 때문에 능력치나 기술 규칙을 차등 적용하지 않는다.

## 1부 · 어떤 게임인가

한 줄 약속 → 핵심 재미와 플레이어 경험 → 핵심 시스템의 관계 → 한 회차 전체 플로우 →
화면 아틀라스. 화면별 썸네일·진입 조건·하는 선택·나가는 곳을 함께 표시한다.
재미는 검증된 성과가 아닌 경험 가설로 구분한다. 기술적인 코드 번호는 본문에서 제외한다.

## 2부 · 강호행로

비무 사이 4회 선택 → 3갈래 후보의 비교 → 사건 / 휴식 / 조사·정탐 / 수련 → 결과와 복귀.
각 종류에 화면·선택지·대가·얻는 것·실패/취소·정보 공개 범위를 붙인다.
사건은 발생→선택→결과의 핵심 장면으로 보여주며 예시 사건과 실제 구현된 사건을 구분한다.

## 3부 · 전투

준비 화면과 상세 와이어프레임 → 해금 기술의 5×2 선택 → 현재 계획 → 3수·3수·4수 해결 →
거리 → 관찰 → 공격·방어·회피·합 → 순차 타격 중단 → 절초 → 승패·보상·복기.
전장 60%는 현재 사용자 디자인 목표다. 실제 캡처와 목표 그림을 같은 완료 상태로 표시하지 않는다.
합은 상단 접촉·승패별 반동·공간 회복·효과 접점·카메라·소리를 시간 순서로 설명한다.

## 4부 · 강호의 상대

인물 도감은 10전 완성형을 중심으로 주력 무공·성향·약점·능력치를 보여준다.
인물마다 먼저 한 페이지의 `삽화 + 보유 무공 + 능력치` 상세 도감을 둔다.
왼쪽 약 38%는 해당 인물 전용 삽화, 오른쪽은 별호·한 줄 전투 성향·능력치 표·
보유 무공과 성수·해금 기술·관찰 포인트 순서다. 이름과 10전 기준 표시는 상단에 둔다.
능력치에는 외공·근골·신법·내공·심안뿐 아니라 확인된 체력·기력·내력 최대치를 구분하여 싣는다.
주력 기술은 사람이 이해할 수 있는 효과와 대응 단서로 설명하고 코드 식별자는 노출하지 않는다.
인물 삽화를 공통 도겸 그림으로 대체하지 않는다. 2026-09-10 첨부 예시의 도겸 그림과
낮은 단계 수치는 레이아웃 참고 전용이며 새 도감의 자산·10전 수치로 채택하지 않는다.
별도 등장표는 인물마다 10전부터 1전까지 실제 숫자와 무공 성수·해금 기술을 표시한다.
등장표는 인물 상세 바로 다음에 두고 같은 삽화·장문 설명을 반복하지 않는다.
현재 단계표: [상대별 상세표](OPPONENT_STAGE_TABLES.md).
원본 후보는 15명이고 회차 비무는 10전이다. 후보 수와 스테이지 수를 혼동하지 않는다.
회차 시작 확정·저장·이어하기 재추첨 금지는 기존 승인 Decision을 따른다.

## 5부 · 무공 도감과 데이터

무공 1권당 한 상세 페이지를 기본으로 한다. 상단은 이름·문파·운용 철학·장단점.
하단 세 열은 3성 기술 / 7성 기술 / 10성 절초이며 각각 새 전용 삽화를 하나씩 둔다.
5성 강화는 3성 기술 아래, 9성 강화는 7성 기술 아래에 설명만 둔다.
비용·거리·효과 순서·후속 중단 조건은 생략하지 않는다. 강화용 중복 삽화는 만들지 않는다.
10권의 3·7·10성 삽화 30종을 모두 생성·저장했다. 실제 편집 선택은 ART_SELECTION.json에서 읽는다.
양가창결 손·창대, 매화 검끝 여백, 창궁 검끝, 팽가 그립은 교정본을 사용하고 원본을 보존했다.
일반 행동·효과 예산·성장 예산은 무공별 반복 설명에서 분리하여 공통 표로 한 번만 싣는다.

## 6부 · 구현 이해와 단계별 체크

읽기 전용 한글 구현 지도와 기획→상세→자산→구현→검증 표를 둔다.
현재 기능·추가 기획·미검증·다음 작업을 구분하며 문서 쪽수나 테스트 개수로 완성률을 만들지 않는다.

## 중복 제거와 보존 기준

- 동일 기술·규칙의 설명은 책임 페이지 한 곳에만 둔다. 다른 절에서는 쪽수로 연결한다.
- 같은 페이지의 구버전·신버전을 동시에 본문에 넣지 않는다.
- 원본 시각 자료의 유용한 디테일은 재편집에 사용하되 오래된 숫자와 상태는 현행 owner로 교정한다.
- 기존 PDF를 삭제하지 않는다. 새 통합본의 원본 대비 coverage를 검사한다.
- 제목·폰트·여백·장 구분·쪽수는 하나의 편집 양식으로 통일한다.
- 사용자의 2026-09-10 지시에 따라 부분 PDF는 전달하지 않는다. 전체 통합·데이터 대조·
  페이지별 렌더 검수가 끝난 완성본만 전달하며 내부 검토용 파일은 별도로 유지한다.

150행의 수치·성수·별호와 공통 자원 상한을 편집했다. 전체 페이지 렌더 검수와 전달 기록을 따른다.
남은 제품 작업: 신규 후보 최종 시각 확정, 게임 연결, 단계 수치의 사람 밸런스 검증,
