# 십보강호 전투 UI·아트 명세

> 책임: 최신 전투 규칙의 입력·예상·결과·복기·접근성 표현

## 1. UI 목표

플레이어가 위치·거리·자원·현재 묶음·전조·타격 번호·합·방어·회피·효과·중단·잔여타·성장 결과를 한 화면과 복기에서 설명할 수 있어야 한다.

## 2. 화면 구조

- 상단: 양측 체력·기력·내력·기세·방어도·회피 횟수·`[강화]`·`[강건]`.
- 중앙: 10칸 전장·거리·밀착.
- 하단: 3/3/4 슬롯, 항상 사용 가능한 행동·해금 기술.
- 오버레이: 상세, 전투 기록, 결정적 복기.
- 절초 목록 3종은 현행 T0에 보존한다.

## 3. 시각 자산

현재 수묵 자산과 폴백 도형·텍스트를 유지한다. 자산이 없어도 모든 핵심 정보를 읽을 수 있어야 한다.

## 4. 상단 HUD

- 현재/최대 자원과 예상값을 구분.
- 방어도는 누적·소모를 숫자로 표시.
- 회피는 남은 횟수와 유효 수 범위를 표시.
- `[강건]`은 “피해 방지”가 아니라 “다음 중단 1회 방지”로 설명.
- `[강화]`는 다음 공격 ×1.5와 선소모 시점을 표시.

## 5. 행동 슬롯

`[전조]`, `[실행]`, `[절초 예약]`, `타격 1/3`, `중단 취소`, `전투 불능 취소`를 구분한다. 다중 슬롯 비용은 첫 전조에서 이미 지불됐음을 보여 준다.

## 6. 합·대응·중단 결과 UI

### 순차 합

각 타격에 다음을 표시한다.

```text
1타: A 8 vs B 5 → A 합 승리 → 차이 원피해3
방어도2 흡수 → 체력 피해1
B 중단 → B 2·3타 취소
A 2·3타 → 단독 잔여타
```

### 효과

- `PER_HIT`은 발동한 타격마다 별도 로그.
- `ONCE_PER_ACTION`은 최초 발동 뒤 “행동당 1회 소비” 표시.
- `ON_HIT`과 `ON_HEALTH_DAMAGE`를 문구로 구분.

### 기세

여러 합을 이겨도 행동당 +1임을 요약한다.

## 7. 입력·접근성

- 명시적 포커스와 키보드 동등 입력.
- 색 외에 아이콘·형태·텍스트·로그를 함께 사용.
- 모션 감소·빠른 재생·즉시 완료가 결과를 바꾸지 않음.
- 타격 연출 건너뛰기 시에도 순서와 원인을 텍스트로 보존.

## 8. 성장·지도 PoC UI

- 시작 무공 6개에서 4개 선택.
- 기술 카드에 슬롯·자원·타격·scope/trigger·예산 상태 표시.
- 전투 후 등급 차원과 공개 적별 과제를 설명.
- 두 경로 노드의 위험·보상을 선택 전에 비교.

## 9. 현재 검증 상태

기존 T0 UI에는 기술 증거가 있으나 새 규칙 UI는 미구현이다. `HUMAN_NOT_RUN`, 접근성 사용자·목표 플랫폼 성능은 `UNVERIFIED`다.
