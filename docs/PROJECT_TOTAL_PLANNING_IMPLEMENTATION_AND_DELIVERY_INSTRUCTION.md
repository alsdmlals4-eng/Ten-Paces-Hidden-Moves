이 문서는 Base 공용 절차의 복사본이 아니다. 십보강호에서 새 채팅·새 담당자가 **현재 GitHub + repository owner만 fresh-read하여 동일한 실행 경계**를 복원하도록 프로젝트 고유 불변식과 최신 계약 locator만 유지한다. `TEN-DEC-20260828-REPOSITORY-ONLY-CANONICAL-WORKSPACE-01`은 r5.4의 Notion workspace 조항을 대체하며, 나머지 제품 안전 경계는 유지한다.


## 2. DOMAIN SPLIT

**GitHub repository**는 Markdown/JSON human-facing 및 structured canon, game data, code, Scene/Resource, tracked asset, tests, CI, runtime evidence를 소유한다.

승인된 의미 변경은 같은 Decision/Requirement identity로 repository human-facing/structured owner에 반영하고 destination readback한다. Notion은 신규 output·sync·attachment 대상이 아니며 historical migration input으로만 보존한다.
