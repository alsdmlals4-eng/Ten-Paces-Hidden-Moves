## 1. 권위와 구현 경계

- 최신 사용자 승인 Decision과 approved planning JSON이 최우선이다.
- 본 문서는 활성 전투 책임 원본이다.

## 2. 전장과 거리

- 전장은 논리적으로 1~10의 일자형 10칸이다.
- 플레이어에게 노출하는 전투 시작 공개 거리는 `2`다.
- 기본 전투 UI는 절대 칸 번호 발판을 상시 표시하지 않고 두 전투원의 상대적 간격과 `거리 N`을 표시한다.
- 런타임의 시작 상태·거리 계산·AI 입력·HUD·로그는 모두 시작 공개 거리 `2`를 같은 의미로 사용해야 한다. 내부 좌표는 그 계산을 만족하는 구현 세부이며 별도 공개 거리나 두 번째 공간 규칙을 만들지 않는다.
- 새 절대 시작 좌표는 단일 구현계약에서 경계·점유·회귀 검증과 함께 정하며, 지금은 `IMPLEMENTATION_BINDING_PENDING`이다.
- 현재 Godot 런타임의 플레이어4/상대7 시작 좌표는 `IMPLEMENTED_LEGACY` 증거로 보존한다.
- 같은 타일의 거리는 0이며 `[밀착]`이다.
- 같은 빈 목적지와 정지 상대 칸 진입을 허용한다.
- 자리 교환·상대 통과·전장 밖 이동은 금지한다.
- 방향성 공격은 방향과 사거리를 모두 만족해야 실제 적중한다.

예시:

```text
검객 A ───── 거리 2 ───── 검객 B
거리 0 = [밀착]
```

## 3. 라운드와 계획 확정

- 한 라운드는 `3수 → 3수 → 4수`의 세 묶음이다.
- 플레이어는 현재 묶음만 편집하며 `행동계획 실행`으로 확정한다.
- `행동계획 실행`은 유효한 현재 묶음을 commit하고 전투·해결 애니메이션으로 전환한다. 실행 뒤 해당 묶음의 제거·재배치·대상/방향 편집은 불가하다.
- 2수 행동은 첫 수 `[전조]`, 둘째 수 `[실행]`이다.
- 3수 행동은 앞 두 수 `[전조]`, 마지막 수 `[실행]`이다.
- 계획판에서 실행 수는 실제 행동 종류를 표시한다. 예: 2슬롯 공격은 `1수 [전조] → 2수 [공격] 기술명`.
- `[전조]`는 실행 전 점유·표시 단계이며 독립적인 강화 효과가 없다.
- 다중 수 행동의 모든 전조·실행 슬롯은 하나의 `action_instance_id`로 연결한다.
- 전조 중 실제 체력 피해를 받고 `[강건]`으로 중단을 막지 못하면 연결된 남은 전조와 실행 슬롯을 전부 취소한다.
- 다중 수 행동의 비용은 첫 전조에서 전액 선지불하며 확정 뒤 중단·사거리 실패·방향 실패에도 환불하지 않는다.

각 묶음 전환·시작 순서:

```text
직전 묶음 종료 상태·전투불능 정산
→ 생존한 양측 기력 +1·절초기세 +1(각 최대치 적용)
→ 적 AI가 회복된 현재 공개 상태로 이번 묶음 계획 확정
→ 적 계획 잠금
→ 축적 관찰량으로 앞 수 행동 종류 공개
→ 플레이어 계획·행동계획 실행
→ 묶음 실행
```

- 전투 최초 1묶음 시작에는 전환 회복을 적용하지 않는다.
- `1묶음→2묶음`, `2묶음→3묶음`, `3묶음→다음 라운드 1묶음`에 동일한 회복을 적용한다.
- 묶음 전환·라운드 시작에는 별도 내력 자동 회복이 없다. 내력은 준비된 명상·청심조식·운수회신 등 승인된 명시 경로로만 회복한다.
- 적은 이번 묶음만 계획하고 미래 묶음을 미리 만들지 않는다.
- 적은 플레이어의 미확정 슬롯·대상·방향을 읽지 않는다.
- 공개 뒤 적 계획을 더 유리한 행동으로 교체하지 않는다.

## 4. 영구 스테이터스

영구 전투 스테이터스는 외공·근골·신법·내공·심안 5종이다. 디자인 하드캡은 없으며 기존 `1~15`는 초기 밸런스 검증 구간이다. 합법적인 성장으로 15를 넘어도 절단·소실·재분배하지 않고 실제 영구값을 기술 요구치와 전투 공식에 사용한다.

| 스테이터스 | 주 역할 |
|---|---|
| 외공 | 외가 피해·강공·밀치기·방어 파괴 |
| 근골 | 최대 체력·방어도·버티기·강건 계열 |
| 신법 | 신법계 무공 수치·기술 요구·이동/회피 임계 효과 |
| 내공 | 내가 피해·최대 내력·호신·회복 |
| 심안 | 간파·반격·전조 대응·관찰 계열 임계 효과 |

- 기본 이동 칸·기본 회피 횟수·기본 관찰량·기본 준비 강화는 고정치이며 스테이터스 1점마다 증가하지 않는다.
- 고정 전용 효과가 아닌 피해·방어·회복·자원 등 연속 수치 효과는 최소 1개의 스테이터스를 참조한다.
- 한 효과는 주 능력치 1개와 선택적 보조 능력치 1개, 최대 2개를 참조한다.
- 기술 해금 요구와 연속 수치 배수는 서로 다른 계약이다.
- 시작 능력치는 각 기본2, 자유 분배6, 선택한 시작 무공4개의 2성 주 능력치+1을 순서대로 적용해 최종 총합20·평균4다.
- 선택한 시작 무공의 3성 첫 기술은 주 영구 능력치4를 요구한다. 모든 네 기술을 여는 최소 `[추천 배분]`은 제공하지만 동시 활성은 강제하지 않는다.
- 7성 두 번째 기술은 해당 무공의 주 영구 능력치8을 요구하며 보조 능력치 요구는 없다.
- 요구치 미달 시 무공 수련·기존 보상은 유지하고 해당 기술만 잠긴다. 영구 요구치 충족 시 별도 비용 없이 자동 활성화하며 임시 능력치 감소로 다시 잠기지 않는다.
- 무공서 짝수 성 보너스는 최초 도달 시 새로 지급한다: 2성 주+1, 4성 주+1·보조+1, 6성 주+2·보조+1, 8성 주+3·보조+2.
- 검증점은 1·4·15와 현재 콘텐츠에서 합법적으로 도달 가능한 최대값이다. 회피율·피해감소율처럼 규칙을 무효화할 수 있는 파생 효과는 별도 점근 곡선·효과 한계·기술 임계 계약으로 보호한다.

## 6. `[준비]`와 `[강화]`

`[준비]`는 독립 기초 행동이고 `[강화]`는 그 행동이 부여하는 상태·효과 태그다.

- 준비 상태는 다음 비이동 행동까지 유지된다.
- 이동·보법은 준비 상태를 소비하지 않는다.
- 다음 공격은 원공격력 +2와 `[강건]`을 얻고 준비 상태를 소비한다.
- 다음 명상은 기력 +1·내력 +1·절초기세 +1을 적용하고 준비 상태를 소비한다.
- 막기·회피·기타 비이동 행동은 처리 또는 유효 시도 뒤 준비 상태를 소비한다.
- 새 준비가 실행되면 기존 준비 상태를 교체한다.
- 위 기본 강화값은 고정치이며 연속 능력치 배수를 붙이지 않는다.

## 7. `[관찰]`과 비무 전 조사

비무 전 조사로 다음 객관 정보를 확인한다.

- 상대 영구 스테이터스
- 보유 무공서와 성취
- 현재 사용 가능한 기술
- 기술의 행동 종류·슬롯·비용·사거리·고정 효과·알려진 조건

AI 가중치·선호 행동·실제 현재 계획·정답 파훼법은 공개하지 않는다.

관찰 공개 행동 종류:

- `[전조]`
- `[이동]`
- `[공격]`
- `[방어]`
- `[회피]`
- `[준비]`
- `[자원]`
- `[관찰]`

- 기본 관찰 1회는 관찰량 1을 고정 획득한다.
- 적은 먼저 현재 적용 대상 묶음을 확정·잠그고, 그 뒤 축적 관찰량만큼 앞 수부터 행동 종류를 공개한다.
- 저장·획득 상한은 없다.
- 남은 관찰량은 묶음·라운드 경계를 넘어 이월한다.
- 복합 기술은 `[이동+공격]`처럼 실제 구성 종류를 모두 표시한다.
- 기술명·무공서명·정확한 비용·방향·거리·피해·사거리·대상·AI 가중치는 공개하지 않는다.
- 적 AI는 관찰 행동을 사용하지 않는다.

예:

```text
상대 실제 잠금: 비연검(2슬롯) → 이동
관찰량1: [전조] / ? / ?
관찰량2: [전조] / [공격] / ?
관찰량3: [전조] / [공격] / [이동]
```

`비연검`은 표기 예시용 이름이며 제품 콘텐츠 승인이 아니다.

## 8. 판정 파이프라인

```text
대응
→ 속공
→ 이동
→ 공격
→ 살아남은 비공격 행동(명상·준비·관찰·자원 행동)
```

- 같은 단계에 양측 유효 공격이 있으면 기존 `[합]` 규칙으로 처리한다.
- 공격과 명상·준비·관찰·자원 행동이 같은 수에 있으면 공격·합·피해·중단을 먼저 정산한다.
- 실제 체력 피해를 받고 `[강건]`으로 막지 못하면 아직 실행되지 않은 같은 수의 비공격 행동과 연결된 다중 수 행동의 후속 슬롯을 취소한다.
- 공격 단계 내부는 다음 순서로 처리한다.

```text
행동 시작 효과
→ 공격 행동별 피해 단위 목록 생성
→ 양측 현재 순번 피해 단위 [합]
→ 합 승리 효과·절초기세
→ 사거리·방향
→ 회피와 회피 성공 절초기세
→ 방어도 차감(방어도 자원 자체는 비소모)
→ 체력 피해
→ 적중·체력 피해 효과
→ 중단·강건
→ 유지된 다음 피해 단위 합 또는 잔여 단독 타격
→ 공격 행동 종료 효과
```

## 9. `[합]`·연격·방어·회피·`[필중]`

### `[합]`과 `[연격 N]`

- `[연격 N]`은 최종 총피해를 N개 피해 단위로 나눈다.
- 나머지는 뒤쪽 피해 단위부터 1씩 배분한다.
- 총피해가 N보다 작으면 0 피해 단위를 만들지 않고 유효 횟수를 `min(N, 총피해)`로 줄인다.
- 총피해가 0이면 피해 단위·합 공격력·적중을 생성하지 않는다.
- 같은 수에 양측 유효 공격이 있으면 각 공격의 현재 순번 피해 단위끼리 앞에서부터 `[합]`한다.
- 높은 피해 단위가 승리하고 차이가 승자의 현재 원피해가 된다.
- 패자의 현재 피해 단위만 취소하며, 동점은 양측 현재 피해 단위만 상쇄한다.
- 현재 피해 단위 해결 뒤 양측 체력 피해가 0이고 양쪽 공격 행동이 유지되며 다음 피해 단위가 모두 남아 있으면 다음 순번 피해 단위도 다시 `[합]`한다.
- 체력 피해가 발생해 공격 행동이 중단되면 해당 행동의 미실행 후속 피해 단위를 취소한다. `[강건]` 등 명시적 중단 방지가 공격 행동을 유지시키면 다음 피해 단위 합을 계속할 수 있다.
- 한쪽 피해 단위 목록이 먼저 끝나거나 한쪽 공격만 유지되면 상대의 유지된 잔여 피해 단위는 일반 단독 타격으로 순차 해결한다.
- 합 승리 절초기세는 합 승리 횟수와 무관하게 공격 행동당 전투원별 최대 +1이다.

예시:

```text
A 연격 [8,5,7], B 연격 [6,7,4]
1타: 8 대 6 → A 합 승리
B가 방어로 체력 피해 0이고 양측 공격이 유지됨
2타: 5 대 7 → B 합 승리
A도 체력 피해 0이고 양측 공격이 유지됨
3타: 7 대 4 → A 합 승리
```

반대로 1타에서 B가 체력 피해를 받고 중단되면 B의 2·3타는 취소되며 A의 유지된 2·3타는 단독 타격으로 해결한다.

### 사거리 밖 합

- 공격 사거리 밖이어도 현재 순번 피해 단위의 합 비교는 진행한다.
- 패자의 현재 피해 단위만 취소하고 동점은 현재 피해 단위끼리만 상쇄한다.
- 승자는 정상 합 승리로 절초기세와 `ON_CLASH_WIN`을 얻는다.
- 승자 공격이 사거리·방향 조건을 만족하지 못하면 해당 현재 피해 단위의 체력 피해와 적중 기반 효과는 0이다.
- 사거리 밖 합으로 양측 체력 피해가 0이고 양쪽 공격이 유지되면 다음 순번 피해 단위끼리 다시 합한다.
- 실제 적중이 없으므로 `ON_HIT`·`ON_HEALTH_DAMAGE`와 적중 조건 부가효과는 발생하지 않는다.

### 방어도

```text
체력 피해 = max(0, 원피해 - 현재 방어도)
```

- 방어도 차감은 피해값에서 현재 방어도를 고정 감산한다는 뜻이며, 방어도 자원 자체는 피격으로 소모되지 않는다.
- 방어도는 피해 단위마다 고정 감산한다.
- 라운드 종료 시 0이 된다.
- PoC 초기 상한은 10이다.

### 회피

- 기본 회피 횟수 1은 가장 먼저 도달한 회피 가능 피해 단위 1개를 제거한다.
- 연격 전체를 자동 회피하지 않는다.
- 회피한 피해 단위의 피해와 회피로 무효화되는 부가효과는 적용되지 않는다.
- 실제 회피 가능한 피해 단위를 제거한 회피 성공 사건마다 절초기세 +1을 얻는다. 회피 횟수 획득만으로는 기세를 얻지 않는다.
- 밀치기는 방어로 체력 피해가 0이어도 적중 조건을 만족하면 적용될 수 있지만, 해당 피해 단위를 회피하면 적용되지 않는다.

### `[필중]`

- 필중은 회피만 무시하고 합·방어·거리·방향·중단·KO는 무시하지 않는다.
- 예약 필중은 실제 존재하는 회피를 우회한 유효 공격 효과에만 1스택 소비한다.
- 연격 공격 효과가 필중이면 모든 피해 단위가 회피를 무시하지만 예약 충전은 공격 효과당 1개만 소비한다.

## 10. 태세·중단·`[강건]` — 사용자 표시는 `[준비]`

역사적 등록부 절 이름의 `태세`는 현재 사용자 표시 용어가 아니다. 현재 기초 행동은 `[준비]`이며, 내부 호환 ID `basic_stance`만 유지할 수 있다.

- 피해 단위의 효과와 체력 피해를 정산한 뒤 중단을 판정한다.
- 유효 피격으로 체력 피해가 발생하면 대상의 현재 `action_instance_id`를 중단하고 미실행 연격 피해 단위뿐 아니라 남은 전조·실행 슬롯도 전부 취소한다.
- 예: 1수 유운삼첩 전조 중 피격·중단되면 2수 유운삼첩 실행은 발생하지 않는다.
- `[강건]`은 유효한 중단 1회만 막는다.
- 강건은 피해·상태·KO를 되돌리지 않는다.
- 강건이 중단을 막아 공격 행동이 유지되고 다음 피해 단위가 있으면 다음 순번 합을 계속할 수 있다.
- 체력이 0이 되면 남은 피해 단위와 비필수 후속 효과를 즉시 생략한다.

## 11. 적중·트리거·이동 부가효과

- `ON_CLASH_WIN`: 각 합 승리 사건에서 발생할 수 있으며 사거리 밖 승리도 포함한다. 공격 행동당 발동 상한이 필요한 효과는 데이터에 명시한다.
- `ON_HIT`: 합에서 제거되지 않고 사거리·방향을 만족하며 회피되지 않은 피해 단위가 하나 이상 있을 때 발생한다. 방어로 체력 피해가 0이어도 적중이다.
- `ON_HEALTH_DAMAGE`: 실제 체력이 1 이상 감소할 때만 발생한다.
- 기본 트리거 범위는 공격 효과당 1회다. 피해 단위마다 발동하려면 `PER_DAMAGE_PACKET`을 명시한다.
- `[밀치기 N]`, `[추격 N]`, `[후퇴 N]`은 각 태그의 적중·방향·경계 규칙을 따른다.
- 공간 부족 잔여 이동은 피해·절초기세·다른 효과로 변환하지 않는다.
- 같은 공격 효과에 여러 이동 부가효과가 있으면 작성된 종속 효과 순서가 필수다.

`적중`은 결정론적 사건 이름이다. `예상 명중률` 또는 `% 명중률` 시스템은 존재하지 않는다.

## 12. 자원과 절초

- 절초기세 범위는 0~5다.
- 합 승리는 공격 행동당 최대 +1을 제공한다.
- 실제 회피 성공은 회피 사건당 절초기세 +1을 제공한다.
- 준비된 명상은 기력 +1·내력 +1·절초기세 +1을 제공한다.
- 모든 묶음 전환은 생존한 양측에 기력 +1·절초기세 +1을 제공하며 각 최대치를 적용한다.
- 묶음 전환·라운드 시작에는 별도 내력 자동 회복이 없다.
- 기본 절초와 무공서 10성 절초는 각자의 슬롯·기력·내력·절초기세 비용과 해금 조건을 따른다.
- 절초를 포함한 모든 다중 자원 비용은 첫 슬롯에서 전액 선지불한다.
- 계획 확정 전 행동 제거 시 예약 비용을 환불한다.
- 확정 뒤 전조 중단·사거리 실패·방향 실패·회피에는 환불하지 않는다.
- 기력·내력 소모는 슬롯 예산과 별도로 사용 가능 틱 예산을 증가시킨다.
- 짧은 슬롯 행동도 기력·내력 비용을 높여 더 높은 효과 예산을 가질 수 있다. 다만 실제 최대 자원으로 지불 가능해야 하며 면제·환불되는 비용은 동일한 추가 예산을 받지 않는다.

## 13. 공개 상태 기반 라이벌 후보 AI

- 현행 적 계획 출처 토큰은 `public_state_ai`다.
- `CombatAiPlanner`는 현재 공개 상태, 보유 기술, 해결 이력, 결정적 seed만 사용한다.
- 플레이어의 미확정 계획·UI hover·포커스·미공개 입력을 사용하지 않는다.
- 관찰 공개 뒤 잠긴 묶음을 교체하지 않는다.
- 테스트용 고정 bundle fixture는 `enemy_bundles`를 사용하더라도 `ai_enabled == false`인 명시적 테스트 경로에서만 허용한다.
- AI 가중치·선호 행동·정답 파훼법은 플레이어에게 자동 공개하지 않는다.
- 첫 5전 locked candidate는 reusable `runtime_archetype_id`와 legal 기초 행동 focus 순서, `final_stat_total_seed`를 하나의 전투별 binding으로 변환한다. 다섯 성향은 후보별 코드 분기가 아닌 `data/run/vertical_slice_opponent_archetypes.json`의 data profile이 소유한다.
- binding은 새 combat engine에만 deep-copy되어 candidate ID·derived five stats·planner profile을 설정한다. 거절된 binding은 bridge snapshot이나 이미 시작한 combat state를 변경하지 않으며, 다음 combat/retry는 새 engine으로 다시 만든다.
- stat 배분은 canonical five-stat order에서 `floor(total × weight / 20)` 뒤 largest remainder와 canonical order tie-break를 사용한다. 모든 결과는 positive이며 locked total과 같아야 한다.
- resolver는 묶음 해결 뒤 `[실행]` record만 `round_number`, `bundle_index`, `actor`, `card_id`, `category`, `outcome`으로 투영해 oldest-to-newest 최대 6개를 `public_resolution_history`에 남긴다. 전조·target·direction·UI·미확정 계획은 남기지 않는다.
- bound profile만 public distance 이동, legal focus bonus `+1.20 / +0.60 / +0.30`, 그리고 sequence의 최대 두 행동을 사용한다. 두 번째 행동은 첫 행동의 실제 slot span 뒤 같은 3/3/4 묶음에 들어갈 때만 배치한다. unbound consumer는 기존 global rival profile과 single-action 정책을 유지한다.

## 14. 전투 종료와 재시작 — 결전 다시 시작

- 1~3라운드는 정상 규칙을 사용한다.
- 4라운드 종료부터 양측에 결착 피해를 동시에 적용한다.

```text
결착 피해 = 최대 체력 × 10% + 5 × (라운드 - 3)
```

- 방어도·막기·회피·피해 감소·무적·일반 반격을 무시한다.
- 세 번째 묶음·상태 효과를 정산하고 승패를 먼저 확인한 뒤, 승패가 없을 때만 적용한다.
- 결착 피해 동시 KO는 직전 체력 비율 → 해당 라운드 유효 체력 피해 → 무승부 순으로 판정한다.
- `결전 다시 시작`은 전투 직전 `RunState`와 같은 seed를 복원하는 패배 재도전 경로다.
- 같은 전투 재도전 비용은 `[영구재화]` 1→2→3개이며 3에서 상한이다.
- 피해·임시 자원·미획득 보상은 롤백하지만 영구재화 지불은 롤백하지 않는다.

## 15. 전투 종료 등급

전투 종료 `S/A/B/C`의 현재 핵심 원자료는 다음 5개다.

1. 회피 성공 횟수
2. 합 승리 횟수
3. 플레이어가 잃은 체력
4. 전투 라운드 수
5. 절초 사용 여부·횟수

- 연격 대 연격에서 여러 순번의 합을 이기면 실제 합 승리 사건 수를 원자료에 기록하되, 정확한 파밍 방지·상한·정규화는 후속 결정이다.
- 사거리 밖 합 승리도 합 승리 횟수에 포함한다.
- 완전 파훼는 해당 공격 행동으로 받은 최종 체력 피해 0인 로그·복기 사건이다. 부가효과가 남아도 완전 파훼일 수 있다.
- 기존 위협 대응30·전술 실행25·자원15·피해 관리15·공개 과제15와 S85/A70/B55/C0은 비활성이다.
- 동일 위협 100%→50%→0% 감쇠는 현재 등급 산식에 적용하지 않는다.
- 5개 지표의 가중치·정규화·등급 경계·파밍 방지는 후속 결정 전까지 `TBD`다.

## 16. 기술 작성과 중앙 점수표

기술 작성 순서:

```text
행동 구조·비용
→ 태그
→ 고정 기본치
→ 주·보조 스테이터스와 배수
→ 5·9성 기본 강화·스테이터스 임계 효과
```

- 관찰·이동·회피·준비의 기본 효과는 고정 전용이다.
- 그 외 연속 수치 효과는 최소 1개의 명시적 스테이터스 참조를 가진다.
- 태그·고정치·능력치 배수·사거리·자원 비용·조건은 별도 ledger 행으로 계산한다.
- 슬롯 목표 예산은 1수 20틱, 2수 50틱, 3수 80틱이며 기본 허용 편차는 ±5틱이다.
- 사용 가능 예산은 `슬롯 예산 + 기력 비용×4틱 + 내력 비용×7틱 + 절초기세·기타 확정 비용 허용량 + 조건 허용량`이다.
- 기력·내력 비용 허용량은 슬롯 수와 독립적으로 누적된다. 따라서 1수 행동도 높은 확정 자원 비용을 지불하면 2수 무비용 행동보다 높은 사용 가능 예산을 가질 수 있다.
- 이동과 공격 사거리는 동일한 거리 가격을 사용한다: 1칸당 15틱.
- 공격 사거리1은 기본 근접 기준점으로 0틱이며, 최대 사거리2=15틱·3=30틱·4=45틱이다.
- 고정 이동1=15틱·2=30틱·3=45틱이며, 이동과 사거리를 함께 가진 기술은 양쪽 ledger를 모두 합산한다.
- 거리5 이상은 동일한 선형 15틱 단위를 사용하되 현재 10칸 전장과 기술별 합법 범위를 함께 검토한다.

능력치 배수 가격:

```text
배수 틱 = 올림(효과 1점 가격 × 배수 × 기준 스테이터스 4)
실제 정수값 = 내림(고정 기본치 + Σ(현재 스테이터스 × 배수))
```

- 배수 작성 기본 단위는 0.25다.
- 주·보조 능력치는 같은 가격이며 보조 할인은 없다.
- 시작 총합은20, 평균은4이며 개별 능력치는 선택과 분배에 따라 달라진다.
- 기술은 스테이터스 1·4·15와 현재 콘텐츠의 최대 합법 도달값에서 sanity 검사한다.
- 중앙 가격 변경은 기존 기술을 자동 수정하지 않는다.
