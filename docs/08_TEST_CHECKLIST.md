# 십보강호 테스트 체크리스트

> 책임: 최신 PoC 계약의 정적·자동·Godot·Windows·사람 증거와 완료 주장  
> 규칙 원본: `docs/02_COMBAT_RULES.md`

## 1. 판정 상태

`PASS / PARTIAL / FAIL / NOT_RUN / BLOCKED / DEFERRED_BY_USER`를 사용한다. 파일 존재·자동 테스트·Godot·Windows·사람 이해·접근성·성능은 서로 대체하지 않는다.

## 2. 현재 증거 요약

- 기존 10칸·4/7·3/3/4·AI·재시작: 기술적으로 검증된 `IMPLEMENTED_LEGACY`.
- 새 수치·연격·효과·성장·3전 PoC: `NOT_RUN`.
- STEP 14 사람 플레이: `NOT_RUN`.

## 3. 전장·점유·대상

### BOARD-002 밀착·공동 목적지

- [ ] 같은 타일의 거리는 0 `[밀착]`.
- [ ] 정지 상대 칸 진입·공동 빈 목적지 허용.
- [ ] 자리 교환·상대 통과 금지.
- [ ] 방향·사거리 실패 이유 기록.

## 4. 자원·기초 행동

- [ ] 체력30·공격력4·방어도5·기력5·내력5·기세0/5.
- [ ] 속공4·강공10·명상+1/+1.
- [ ] `[강화]` floor(raw×1.5).
- [ ] 다중 슬롯 첫 전조 선지불과 무환불.

## 5. 합·방어·회피·필중

### CLASH-001 기본 합

- [ ] 단일 공격의 원공격력 차이와 동점 상쇄.
- [ ] 합 승리 기세가 행동당 최대 +1.

### CLASH-002 연격

- [ ] 앞 타격부터 짝짓기.
- [ ] 타격쌍별 차이 피해.
- [ ] 실제 체력 피해 후 패자 후속타 취소.
- [ ] 승자 잔여타는 단독 타격.
- [ ] 타격 수가 다르면 짝 없는 타격 정상 실행.

### DEFENSE-001

- [ ] 방어도5 누적·흡수량만큼 소모.
- [ ] 체력 피해0이면 피해 기반 중단 없음.

### EVADE-001

- [ ] 타격 1회당 회피 횟수1 소비.
- [ ] 필중은 회피만 무시하고 횟수를 소비하지 않음.

## 6. 중단·강건·효과

- [ ] 현재 타격 효과 정산 뒤 중단 판정.
- [ ] `[강건]`이 슬롯 수와 무관하게 중단 1회만 방지.
- [ ] 피해·효과는 유지되고 KO는 방지하지 못함.
- [ ] `PER_HIT/ONCE_PER_ACTION` 정상·중복·취소.
- [ ] `ON_HIT` 체력 피해0 발동과 `ON_HEALTH_DAMAGE` 미발동.
- [ ] 합 패배·상쇄·회피·중단 취소 타격은 효과 미발동.
