# 전투 규칙 자원 회복 현행 개정

- 상태: `[현행]`
- Decision ID: `TEN-DEC-20260804-RESOURCE-SATURATION-INTERNAL-RECOVERY-01`
- 부모 규칙서: `docs/02_COMBAT_RULES.md`
- 적용 범위: 묶음 전환·라운드 시작 자동 회복, 내력 회복 경로
- 제품 런타임: `NOT_IMPLEMENTED`

## 권위 우선순위

`docs/02_COMBAT_RULES.md`의 다른 전투 규칙은 계속 현행이다. 다만 다음 구형 문구는 `[대체됨]`이다.

```text
생존한 양측 기력 +1·내력 +1·절초기세 +1
```

현재 유효 규칙은 다음과 같다.

```yaml
stamina_gain: 1
internal_gain: 0
ultimate_momentum_gain: 1
resource_caps_apply: true
first_bundle_start: false
```

적용 전환:

- 1묶음 → 2묶음
- 2묶음 → 3묶음
- 3묶음 → 다음 라운드 1묶음

처리 순서:

```text
직전 묶음 종료 상태·전투불능 정산
→ 생존한 양측 기력 +1·절초기세 +1
→ 각 최대치 적용
→ 적 AI가 회복된 공개 상태로 이번 묶음 계획 확정·잠금
→ 관찰 공개
→ 플레이어 계획·확정
```

## 내력 회복

라운드 시작 또는 묶음 전환에 별도 내력 자동 회복이 없다. 내력은 다음 명시적 경로로만 회복한다.

- 준비된 명상 내력 +1
- 청심조식의 승인된 기본·조건부 회복
- 운수회신 등 승인된 조건부 회수
- 향후 별도 Decision으로 승인된 효과

조건부 회복은 조건 실패 시 전부 0이다.

## 소프트락 방지

내력 0에서도 무비용 기본 행동·이동·준비·명상·청심조식·내력 비소모 행동을 조합해 합법 행동 묶음을 만들 수 있어야 한다.

## 참조 금지

부모 계약 또는 부모 규칙서의 내력 자동 회복 `1`을 새 overlay 없이 현재 런타임 값으로 사용하면 `CANON_CONFLICT`다.
