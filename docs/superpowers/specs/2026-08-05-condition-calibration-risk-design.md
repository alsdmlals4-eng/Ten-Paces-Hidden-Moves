# 조건 난도 보정 위험 설계

- 설계일: 2026-08-05
- 대상 위험: `CONDITION_CALIBRATION_RISK`
- 제안 Decision: `TEN-DEC-20260805-CONDITION-CALIBRATION-01`
- 부모 효과 권위: `TEN-DEC-20260804-TECHNIQUE1-CONDITIONAL-REWORK-STAR5-01`
- 선행 stacked PR: `#89`
- 제품 런타임: 변경하지 않음

## 1. 목표

조건부 기술이 `실패 시 낮은 저점, 성공 시 높은 고점`을 유지하면서도, 작성 당시 선언한 난도와 실제 성공률이 어긋날 때 무료 고효율 기술이나 함정 기술로 굳어지는 문제를 막는다.

기존 다섯 가격 계수는 유지하고 `85% 이상` 구간을 `준확정`으로 추가한다. 가격은 실시간 자동 변경하지 않으며, 충분한 사람 플레이 증거와 별도 Decision이 있을 때만 수동 재분류한다.

## 2. 기준 집단

가격 분류의 기준 집단은 다음과 같다.

```text
규칙을 이해한 일반 플레이어의 유효 시도 성공률
```

- 튜토리얼을 마치고 공개 정보·조건 문구·거리·자원 규칙을 이해한 일반 플레이어를 대상으로 한다.
- 고수·개발자·디버그 세션만으로 난도를 결정하지 않는다.
- AI 자동 시뮬레이션은 도달 가능성·실패 지점·로그 계약 검증에만 사용한다.
- 사람의 고점 만족도와 실패 저점 수용도는 시뮬레이션으로 PASS 처리하지 않는다.

## 3. 조건 난도 구간

| 난도 | 유효 시도 성공률 | 가격 계수 | 원가 감소 |
|---|---:|---:|---:|
| 준확정 | `0.85 이상 1.00 이하` | `1.00` | 0% |
| 쉬움 | `0.70 이상 0.85 미만` | `0.85` | 15% |
| 보통 | `0.50 이상 0.70 미만` | `0.70` | 30% |
| 어려움 | `0.30 이상 0.50 미만` | `0.55` | 45% |
| 매우 어려움 | `0.15 이상 0.30 미만` | `0.40` | 60% |
| 극단적 | `0 이상 0.15 미만` | `0.25` | 75% |

- 구간은 `0~1`을 빈틈과 중복 없이 정확히 덮는다.
- `준확정`은 사실상 안정적으로 얻는 효과이므로 조건 할인을 받지 않는다.
- 계수는 관측 성공률을 그대로 복사하지 않는다. 조건 준비 가능성·상대 대응·구조적 고점 가치를 보수적으로 가격에 남긴다.

## 4. 성공률 분모

### 전체 사용 성공률

```text
조건 성공 횟수 / 합법적으로 확정한 해당 기술 사용 횟수
```

기술의 실제 기대가치와 오사용 문제를 함께 보여준다.

### 유효 시도 성공률

```text
조건 성공 횟수 / 확정 시점의 공개 정보상 조건 성공이 가능했던 사용 횟수
```

가격 재분류는 유효 시도 성공률을 기준으로 한다.

유효 시도 조건:

- 기술이 합법적으로 확정됐다.
- 확정 시점의 공개 상태만으로 조건이 이미 불가능하지 않았다.
- 디버그 강제 성공·강제 실패·개발자 치트 전투가 아니다.
- 전투 포기·강제 종료로 결과가 확정되지 않은 표본이 아니다.

상대의 숨은 계획·이동·방어·회피·합·중단으로 실패한 경우에는 유효 실패로 포함한다. 상대 대응이 조건 난도의 일부이기 때문이다.

공개 상태상 이미 불가능했던 사용은 가격 분모에서 제외하되 `PUBLICLY_IMPOSSIBLE_ATTEMPT`로 별도 기록한다.

## 5. 실패 지점 분류

조건 시도는 정확히 하나의 최종 결과를 가진다.

- `PUBLIC_STATE_MISMATCH`
- `PREDICTION_MISS`
- `POSITION_FAILURE`
- `INTERRUPTED`
- `EVADED_OR_MISSED`
- `NO_HEALTH_DAMAGE`
- `PARTIAL_CHAIN_FAILURE`
- `SUCCESS`

같은 trigger를 공유하는 5성 patch는 부모 조건과 하나의 성공 사건을 공유한다. 부모 조건 성공과 5성 patch 성공을 두 번 세어 성공률을 부풀리지 않는다.

## 6. 경고·재분류 Gate

### 조기 경고

다음을 모두 만족하면 `CALIBRATION_WARNING`을 기록한다.

- 유효 시도 30회 이상
- 서로 다른 전투 10회 이상
- 관측 성공률이 선언 구간 밖으로 10%p 이상 이탈

경고만으로 가격·효과·비용을 변경하지 않는다.

### 정본 재분류

다음을 모두 만족해야 한다.

- 유효 시도 100회 이상
- 서로 다른 전투 30회 이상
- 아래 증거 중 하나 이상
  - Wilson 95% 신뢰구간 전체가 선언 난도 구간 밖
  - 연속 두 측정 배치에서 같은 방향으로 선언 구간 이탈; 각 배치 유효 시도 50회·전투 15회 이상

고점 만족도와 저점 수용도는 필수 진단값이지만, 통계 증거 없이 계수를 자동 변경하는 대체 근거로 사용하지 않는다.

### 재분류 처리

- 한 단계 차이: 새 계수로 원가를 재계산하고 총예산 편차 `±5틱`을 다시 검사한다.
- 두 단계 이상 차이: `CONDITION_DESIGN_REVIEW_REQUIRED`로 전환하고 자기충족·대응 수단·trigger 모호성·복합 조건 독립성을 먼저 감사한다.
- 효과·비용·슬롯 조정은 별도 전후 예산표와 사용자 승인 없이는 적용하지 않는다.

## 7. 통계 악용 방지

- 실시간·자동 repricing 금지
- 디버그·강제 성공·강제 실패 표본 제외
- 전투 포기·강제 종료 표본 제외
- 공개 상태상 불가능한 사용은 가격 분모에서 제외하되 오사용 지표로 유지
- 반복 실패를 의도적으로 만드는 테스트 세션은 `CALIBRATION_TEST_ISOLATED`로 격리
- 한 기술의 통계를 다른 기술 조건에 대입 금지
- 같은 condition event를 부모 효과와 milestone patch가 중복 집계 금지
- 재분류는 반드시 별도 Decision과 전후 예산표를 거친다.

## 8. 현재 여섯 기술 처리

현재 기술1의 효과·비용·선언 난도는 변경하지 않는다.

- 유운삼첩: 2타 `보통`, 3타 `매우 어려움`, 완주 후퇴 `극단적`
- 금강가세 완전 방어: `어려움`
- 운수회신 유효 회피: `어려움`
- 추풍일섬 창끝: `매우 어려움`
- 청심조식 저자원: `매우 어려움`
- 철각유영 완전 탈출: `어려움`

동일 조건에 연결된 5성 patch는 별도 난도 표본이 아니라 부모 조건 그룹을 공유한다.

## 10. 검증 경계

자동 검증은 다음을 강제한다.

- 여섯 난도 구간이 0~1을 빈틈·중복 없이 덮음
- 준확정 계수 1.00
- 기존 다섯 계수가 기술1 부모 계약과 일치
- 유효 시도와 전체 사용 성공률 정의 존재
- 공개 상태상 불가능한 시도는 가격 분모 제외·오사용 지표 포함
- 숨은 상대 대응 실패는 유효 시도 분모 포함
- 실패 지점 8종과 중복 성공 방지
- 경고 30/10/10%p, 재분류 100/30 Gate
- 자동 repricing 금지
- 사람·밸런스·Godot·Windows 검증 `NOT_RUN`
