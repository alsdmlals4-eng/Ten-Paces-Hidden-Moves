# 1. [화산파] 매화검결

## 무학

적중한 검초가 다음 검초를 피우며 이동과 연격으로 하나의 매화검세를 완성한다. 화려함은 타수 자체가 아니라 검세가 단계적으로 피어나는 데서 나온다.

## 성장

- **3성 기술1 — 매화삼첩:** 근거리 세 번의 독립 검격. 실제 체력 피해가 발생해야 다음 타격으로 이어진다.
- **5성 — 낙매유향:** 세 타가 모두 성공하면 공격 후 후퇴하고 방어를 얻는다.
- **7성 기술2 — 낙매추영:** 1칸 접근한 뒤 거리 1~2에서 단발 합 공격을 수행한다. 연격이 아니라 추격과 결착이 목적이다.
- **9성 — 매화연세:** 낙매추영의 합에서 승리하면 `[준비]`를 얻는다.
- **10성 절초 — 이십사수매화검법:** 접근·연속 검초·제한 추격·결착검으로 완성되는 전체 매화검식이다.

```text
접근 1
→ 연속 검격을 각각 판정
→ 정해진 적중 수 충족 시 추격 1
→ 사거리 재확인
→ 결착검
→ 종료 위치 확정
```

금지: 실제 24회 판정, 실패 피해 이월, 무제한 추격. `이십사수`는 완성된 검법 체계를 뜻하며 게임에서는 읽을 수 있는 단계로 압축한다.

# 2. [소림사] 나한금강공

## 무학

공격을 피하지 않고 방어와 `[강건]`으로 받아내며, 굳어진 육체와 내력을 장력으로 전환한다. 이 무공의 공격은 쉽게 흔들리지 않지만 절대 중단 면역은 아니다.

## `[강건]` 공통 규칙

- 금강공의 공격 동작은 핵심 공격 또는 전조보다 먼저 `[강건]`을 생성한다.
- `[강건]`은 현행 전투 규칙에 정의된 중단 방지 기능만 사용한다.
- `[강건]`이 소진되거나 기존 규칙으로 중단을 막지 못하면 공격은 취소될 수 있다.
- 자동 무적·피해 무시·전투불능 방지·무제한 중단 면역으로 확장하지 않는다.

## 성장

- **3성 기술1 — 금강호체:** 방어와 `[강건]`을 먼저 얻는다. 다음 자기 행동 전까지 실제 공격을 완전히 흡수하면 추가 방어·기력 보상을 얻는다.
- **5성 — 금강불괴:** 완전 흡수 성공 시 내력 1을 추가 회복한다.
- **7성 기술2 — 대력금강장:** `[강건]`과 방어 2를 먼저 얻고 현재 방어를 기록한 뒤 장력 공격을 수행한다. 기록한 방어만큼 상한 있는 일반 추가 피해를 준다. 방어는 소비하지 않는다.
- **9성 — 금강진력:** 대력금강장이 실제 체력 피해를 주면 `[강건]`을 다시 얻는다.
- **10성 절초 — 여래신장:** 첫 전조에 방어와 `[강건]`을 얻고 실행 전까지 실제 방어 손실을 기록한다. 실행 시 거대한 장력과 기록한 충격을 방출한다.

```text
첫 전조: 방어·강건 생성, 전투당 기록 시작
→ 실행 전까지 실제 방어 손실 기록
→ 실행 시 거리 확인
→ 기본 장력 공격
→ 기록 손실을 상한 내 추가 피해로 전환
→ 기록 종료
```

상대 대응: 반복 공격으로 `[강건]`을 먼저 소진시키거나, 실행 시 거리를 벗어나거나, 합·방어로 장력을 견딜 수 있다.

금지: 전면 피해 반사, 방어 손실이 없는데 최대 피해, 무적, 상한 없는 방어 비례 피해.

# 3. [무당파] 태극검결

## 무학

상대의 힘과 검로를 읽어 흘리고, 기울어진 힘을 합과 반격으로 되돌린다.

## 성장

- **3성 기술1 — 운수검식:** 회피를 부여하고 성공 시 후퇴한 뒤 내력과 방어를 회복한다.
- **5성 — 유전회신:** 회피 성공 시 절초기세 1을 얻는다.
- **7성 기술2 — 사량발천근:** 심안 기반 합 공격. 합 승리 시 방어와 내력을 얻는다.
- **9성 — 음양전환:** 합 승리 시 상대를 1칸 밀친다.
- **10성 절초 — 태극혜검:** 대응 시간에 들어오는 공격과 특별 합을 수행해 승리하면 공격을 흘리고 반격한다.

```text
태극 검세 준비
→ 대응 시간 내 공격과 접촉
→ 특별 합
→ 승리 시 상대 공격 흘리기
→ 반격
→ 내력·방어 안정화
```

상대가 대응 시간에 공격하지 않거나 합에서 이기면 태극혜검의 반격은 성립하지 않는다.

# 4. [양가] 양가창결

## 무학

정확한 창끝 거리를 만들고 찌른 뒤, 반격 거리 밖으로 물러나 되받아 찌른다.

## 성장

- **3성 기술1 — 추풍일섬:** 1칸 접근 후 거리 1~2에서 찌른다. 정확한 창끝 거리에서 추가 방어 파괴를 얻는다.
- **5성 — 이화회창:** 창끝 적중 성공 시 공격 후 1칸 후퇴한다.
- **7성 기술2 — 연환쇄로:** 두 번 찌르고 한 번 이상 적중하면 후퇴한다.
- **9성 — 쌍룡쇄로:** 두 타 모두 적중하면 상대를 1칸 밀친다.
- **10성 절초 — 회마창:** 첫 찌르기 후 크게 물러나고 다시 돌아서서 두 번째 창격을 가한다.

```text
첫 찌르기
→ 결과 처리
→ 후퇴 2
→ 사거리 재확인
→ 회마 찌르기
→ 결과 처리
```

후퇴 뒤 사거리가 끊기면 두 번째 공격은 실패한다.

# 5. [화산파] 자하심법

## 무학

자색 내공을 순환시켜 소모된 자원을 되돌리고 무너지기 직전의 몸을 다시 전투 가능한 상태로 안정화한다.

## 성장

- **3성 기술1 — 자하토납:** 기본 내력을 회복한다. 행동 시작 시 저자원 조건을 만족하면 기력과 방어를 추가 회복한다.
- **5성 — 자기양원:** 저자원 조건을 만족한 자하토납에 제한된 체력 회복을 추가한다.
- **7성 기술2 — 자하회천:** 내력을 먼저 회복한 뒤 강건·방어·체력을 순서대로 안정화한다.
- **9성 — 자하귀원:** 저자원 조건을 만족한 자하회천은 종료 후 `[준비]`를 얻는다.
- **10성 절초 — 자하신공:** 체력·기력·내력·방어를 전투 복귀선까지 회복하고 실행 완료 시 절초기세 1을 회복한다. 전투당 한 번만 선언할 수 있다.

## 자하신공 전투당 1회 계약

```text
행동 확정·첫 전조 시작
→ 전투당 사용권 즉시 소모
→ 사용 시작 시 체력·자원 기록
→ 내력 회복
→ 기력 회복
→ 강건·방어 안정화
→ 시작 시 저자원 조건을 만족했다면 제한된 체력 회복
→ 실행 완료 시 절초기세 +1, 최대치 적용
```

- 사용권은 행동 확정과 첫 전조 시작 시 소모한다.
- 이후 중단·거리 실패·전투불능으로 실행하지 못해도 사용권을 돌려주지 않는다.
- 전투 종료까지 재사용·충전·초기화 효과로 복구할 수 없다.
- 절초기세 회복은 실행 완료 시에만 적용한다.
- 완전 회복·최대치 초과 저장·전투 상태 초기화는 금지한다.

# 6. [소요파] 소요보결

## 무학

공격이 닿기 전에 위치를 비우고 상대가 허공을 친 순간 반격한 뒤 다시 공격선 밖으로 빠진다.

## 성장

- **3성 기술1 — 미진환보:** 먼저 후퇴하고 회피를 부여한다. 성공 시 추가 후퇴와 절초기세를 얻는다.
- **5성 — 나영무흔:** 선행·후속 후퇴가 모두 성공하면 `[강건]`을 얻는다.
- **7성 기술2 — 소요환위:** 회피 성공 시 후퇴 전에 원래 공격자를 반격하고 반격 후 최대 2칸 후퇴한다.
- **9성 — 유영귀허:** 반격의 합 위력이 증가한다.
- **10성 절초 — 능파미보:** 공격을 피하고 반격한 뒤 공격자 반대 방향으로 결정론적인 장거리 변위를 수행하고 `[준비]`를 얻는다.

```text
회피 부여
→ 회피 성공
→ 이동 전 위치에서 반격
→ 반격 결과 처리
→ 공격자 반대 방향으로 최대 3칸 이동
→ 준비 획득
```

자동 회피 성공·무작위 이동·숨은 계획 열람은 금지한다.

# 7. [개방] 강룡장결

## 무학

단순하고 강맹한 장력으로 정면을 돌파하되 모든 힘을 한 번에 소진하지 않고 여력을 남긴다.

## 성장

- **3성 기술1 — 견룡재전:** `[강건]`을 만든 뒤 거리 1에서 장력을 가한다.
- **5성 — 잠룡물용:** 실제 체력 피해를 주면 방어를 얻는다.
- **7성 기술2 — 비룡재천:** 1칸 접근해 합 장력을 가하고 합 승리 시 상대를 밀친다.
- **9성 — 항룡유회:** 합 승리 시 기력 1을 회복한다.
- **10성 절초 — 항룡십팔장:** 연속 장세를 하나의 합 판정에 연결해 방어 파괴·체력 피해·밀치기를 순차 수행한다.

```text
접근 1
→ 강맹한 합
→ 승리 시 첫 장세로 방어 파괴
→ 두 번째 장세로 체력 피해
→ 마지막 장세로 밀치기 2
```

소림 여래신장은 방어·충격 축적형이며 항룡십팔장은 사전 축적 없는 즉시 돌파형이다.

# 8. [사천당문] 천기암기록

## 무학

정밀한 암기로 방어와 회피를 소모시키고 여러 투사체가 비처럼 이어져 안전한 공간을 줄인다.

## 성장

- **3성 기술1 — 추혼표:** 거리 1~3의 단발 암기로 피해와 방어 파괴를 가한다.
- **5성 — 비성추혼:** 실제 체력 피해를 주면 관찰 1을 얻는다.
- **7성 기술2 — 폭우이화침:** 거리 2~4에서 두 발을 독립 판정한다. 첫 적중은 방어를 추가로 파괴한다.
- **9성 — 유성귀영:** 한 발 이상 적중하면 공격 후 1칸 후퇴한다.
- **10성 절초 — 만천화우:** 거리 1~4에 네 차례 독립 암기 판정을 연속 수행한다.

```text
사거리 확인
→ 1발 판정·결과
→ 2발 판정·결과
→ 3발 판정·결과
→ 4발 판정·결과
→ 종료
```

독·출혈·무작위 표적은 별도 시스템 승인 전 추가하지 않는다.

# 9. [하북팽가] 팽가도결

## 무학

무거운 도세로 상대의 방어문을 먼저 부수고 열린 틈에 결착도를 내려친다.

## 성장

- **3성 기술1 — 맹호출림:** 거리 1의 묵직한 도격으로 피해와 방어 파괴를 가한다.
- **5성 — 호아파문:** 이 공격으로 상대 방어가 0이 되면 절초기세 1을 얻는다.
- **7성 기술2 — 백호단문:** 첫 도격 후 상대 방어가 0이면 두 번째 결착도가 이어진다.
- **9성 — 호맥강신:** 두 번째 도격이 발생하면 `[강건]`을 얻는다.
- **10성 절초 — 오호단문도:** 두 번의 파문도와 한 번의 결착도로 상대의 방어문을 순차 절단한다.

```text
첫 파문도
→ 방어 처리
→ 두 번째 파문도
→ 방어 처리
→ 상대 방어 0 확인
→ 결착도
```

화산은 실제 체력 적중이 다음 검초를 열고 팽가는 방어 파괴가 다음 도격을 연다.

# 10. [남궁세가] 창궁무애검법

## 무학

검세를 정면으로 세우고 준비된 내공과 심안으로 직선상의 상대를 검압과 합으로 제압한다.

## 성장

- **3성 기술1 — 철검십식:** 거리 1의 강한 합 검격. `[준비]`를 소비하면 추가 방어 파괴를 얻는다.
- **5성 — 창궁입세:** 준비를 소비한 공격은 합 전에 방어를 얻는다.
- **7성 기술2 — 창궁검뢰:** 전조 후 거리 1~3에 직선 검압을 가한다. 합 경쟁과 원거리 결착이 중심이다.
- **9성 — 무애검세:** 정확한 거리 3에서 합에 승리하면 절초기세 1을 얻는다.
- **10성 절초 — 제왕검형:** 전조 동안 검세를 세운 뒤 거리 1~3에서 특별 합을 수행하고 승리하면 방어를 깨뜨린 뒤 단발 결착검을 가한다.

```text
전조로 제왕검세 형성
→ 실행 시 거리 확인
→ 특별 합
→ 승리 시 방어 파괴
→ 단발 결착검
```

자동 합 승리·자동 필중·화산식 연격·무당식 공격 흘리기를 추가하지 않는다.

# 역할 비대체 검사

| 충돌 후보 | 분리 기준 |
|---|---|
| 여래신장 / 항룡십팔장 | 방어·충격 축적형 / 즉시 합 돌파형 |
| 매화검 / 오호도 | 실제 체력 적중 연계 / 방어 파괴 연계 |
| 매화검 / 만천화우 | 근접 이동 연격 / 원거리 독립 다단 압박 |
| 태극혜검 / 능파미보 | 합과 힘 전환 / 회피와 위치 전환 |
| 회마창 / 창궁검뢰 | 후퇴 후 재반격 / 전조 후 직선 검압 |
| 자하신공 / 일반 회복 | 전투당 1회 전신 복귀·절초기세 회복 / 반복 가능한 부분 회복 |
| 금강공 / 일반 강건 공격 | 방어·충격을 장력으로 전환 / 공격 지속성만 제공 |

# 적대적 검토 결과

## 해결한 P1

1. **자하신공 반복 회복 악용:** 전투당 1회, 첫 전조에 사용권 소모, 중단 시 환불 없음으로 막는다.
2. **자하신공 절초기세 순환 폭주:** 실행 완료 시 +1만 회복하고 최대치를 적용하며, 같은 전투에서 자하신공 자체를 재사용할 수 없다.
3. **금강공 절대 중단 면역:** 기존 `[강건]` 규칙만 사용하고 소진 후에는 중단될 수 있도록 제한한다.
4. **여래신장과 항룡십팔장 역할 중복:** 축적형과 즉시 돌파형으로 조건·순서를 분리한다.
5. **다단 무공 동형화:** 매화는 체력 적중, 팽가는 방어 파괴, 당문은 독립 원거리 판정을 연결 조건으로 사용한다.

## 남은 P2·사람 검증

- 자하신공의 절초기세 +1이 전투 후반의 연속 절초 빈도를 과도하게 높이는지 측정한다.
- 금강공의 `[강건]` 생성 빈도가 다단 공격 상대로 너무 약하거나 단발 공격 상대로 지나치게 강한지 측정한다.
- 만천화우 네 번의 독립 판정이 전투 로그와 카드 한 장에서 읽히는지 확인한다.
- 유명 고유명은 내부 출처 메타데이터와 출시 전 명칭 검토 목록을 유지한다.
