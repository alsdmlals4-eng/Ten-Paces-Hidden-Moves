# 절차형 주요 비무 후보 풀·강호행로 설계

## 목적

첫 데모의 주요 비무 1~5전과 비무 사이 경로에 반복 플레이 가치를 부여하되, 초반 학습 순서와 난이도 곡선을 훼손하지 않는다.

## 핵심 구조

- 주요 비무 단계는 특정 인물이 아니라 학습 역할 슬롯이다.
- 각 슬롯은 후보 3명을 보유한다.
- 첫 비무는 후보 3명 중 1명을 seed 기반으로 선정한다.
- 이후 비무는 후보 3명 중 2명을 경로 종착점으로 제시한다.
- 플레이어는 노드 2개가 포함된 경로를 선택하고 해당 상대와 대결한다.
- 노드 유형·배치·연결·후보 선정은 같은 seed에서 재현된다.

## 슬롯 1 후보

| 후보 | 이명 | 공통 학습 역할 안의 변주 |
|---|---|---|
| 연교 | 사문검객 | 정석적인 이동·속공·막기 |
| 백소령 | 유운검수 | 이동 비중과 거리 1 찌르기 강화 |
| 진무백 | 철선문도 | 막기로 템포를 늦춘 뒤 속공 |

세 후보 모두 공개 전조, 거리 1, 같은 수 합, 체력 피해 중단을 학습시킨다.

## 슬롯 2 후보

| 후보 | 이명 | 공통 학습 역할 안의 변주 |
|---|---|---|
| 묵진 | 철벽승 | 방어도·강건·강공의 정석 순환 |
| 하진강 | 진산권객 | 낮은 이동성과 방어도 상한 접근 |
| 위청람 | 현문도객 | 방어도 만료와 강공 시점 교차 |

세 후보 모두 능력치 비례 방어도, 비소모 감산, 체력 피해 중단, 강건을 학습시킨다.

## 경로 생성

```text
현재 비무
→ 다음 슬롯 후보 3명 중 2명 제시
→ 1차 노드층 2~3개 중 1개 방문
→ 2차 노드층 2~3개 중 1개 방문
→ 선택한 경로의 상대와 주요 비무
```

### 1차 노드층

- 휴식
- 수련
- 일반 사건
- 무공 교류

현재 체력과 성장 방향을 조정한다.

### 2차 노드층

- 상대 정보
- 대응 수련
- 다음 비무 한정 자원 준비
- 위험 사건

제시된 후보 상대와 직접 연결된 준비를 제공한다.

## 생성 안전장치

- 제시된 두 상대 모두 최소 한 경로로 도달 가능해야 한다.
- 각 상대 경로에 안전 회복 또는 성장 기회가 최소 하나 존재해야 한다.
- 각 상대 경로에 정보 또는 대비 기회가 최소 하나 존재해야 한다.
- 낮은 체력에서는 회복 경로를 최소 하나 보장한다.
- 핵심 규칙은 정보 노드가 없어도 항상 공개한다.
- 같은 노드·사건은 한 회차에서 중복하지 않는다.
- 동일 유형 노드는 최대 두 번까지만 연속 방문한다.
- 제시되지 않은 상대 전용 정보는 생성하지 않는다.

## 데이터 흐름

```text
run_seed + slot_id + gap_index
→ 후보 3명 적격성 필터
→ 후보 2명 추첨
→ 1차·2차 노드 후보 추첨
→ 안전장치 검사
→ 연결선 생성
→ 플레이어 경로 선택
→ 선택 상대와 전투
→ 전투·노드 기록 저장
```

생성 실패 시 완전 재추첨하지 않고, 실패한 제약만 충족하도록 후보 또는 연결선을 최소 교체한다. 동일 입력은 동일 결과를 만들어야 한다.

## 제작 범위

데모 5개 슬롯에 후보 3명을 적용하면 잠재 상대는 15명이다. 콘텐츠 비용을 제한하기 위해 슬롯별 공통 AI 템플릿과 기본 행동 세트를 공유한다. 후보 고유성은 전조, 행동 가중치, 대표 무공 하나, 외형과 서사에 집중한다.

## 검증

- 동일 seed에서 후보·노드·연결이 동일한가
- 서로 다른 seed에서 실제 경로와 상대 조합이 달라지는가
- 각 슬롯의 학습 목표가 후보에 관계없이 유지되는가
- 회복과 정보가 특정 경로에만 몰려 명백한 정답이 되지 않는가
- 첫 데모 반복 플레이에서 3회 이상 다른 상대·경로 조합을 경험할 수 있는가
- 전체 10전 기준 30~40분 목표를 유지하는가

## 상태

- 기획 구조: 승인
- 슬롯 1·2 후보 3명: 기획 등록
- 정확한 능력치·무공 수치: 후속 밸런스 검토
- 런타임 구현: 금지
- 사람 플레이 검증: 미실행
