## 목적

여섯 시작 무공서를 수치 묶음이 아니라 하나의 무학 체계로 재설계한다.

각 무공서는 다음 성장 서사를 가져야 한다.

```text
무공서 방향성·무학
→ 3성 기술1: 무학의 기본 운용
→ 5성: 기술1의 완성도 강화
→ 7성 기술2: 같은 무학의 다른 응용
→ 9성: 기술2의 단일 완성
→ 10성 절초: 무학 전체의 최종 경지
```

## 무공 제작 정본 절차

### 1단계 — 무공서의 방향성과 무학 결정

먼저 다음을 확정한다.

- 플레이어가 이 무공으로 어떤 전투를 하게 되는가.
- 힘·거리·방어·합·회피·자원을 어떤 원리로 다루는가.
- 빠름·묵직함·유연함·견고함 등 동작 감각이 무엇인가.
- 이 무공이 절대로 해서는 안 되는 행동이 무엇인가.

### 2단계 — 기술과 절초의 방향성 결정

- 기술1은 무학의 기본 운용법이다.
- 기술2는 기술1보다 높은 가치가 가능하지만 다른 전술 역할을 가져야 한다.
- 9성은 기술2의 단일 완성 효과 하나다.
- 절초는 기술1과 기술2를 단순 합산하지 않고 무학 전체를 하나의 최종 동작으로 완성한다.

### 3단계 — 해결 순서 결정

복합 효과는 반드시 실행 순서를 가진다.

```text
선행 상태·사거리 생성
→ 핵심 공격·합·회피 판정
→ 결과 보상
→ 후속 이동·정리
```

예외는 공격 사거리를 만들기 위한 접근 이동이다. 후퇴처럼 공격 사거리를 끊을 수 있는 이동은 공격·반격보다 먼저 실행하지 않는다.

### 4단계 — 효과 설정과 예산 편성

- 무학과 기술 방향성을 먼저 전투 효과로 번역한다.
- 그 뒤 슬롯·비용·조건을 포함한 사용 가능 예산 안에서 수치를 조정한다.
- 예산은 아이디어의 출발점이 아니라 과잉과 결핍을 통제하는 제약 장치다.
- 7성 `+10틱`은 별도 패시브가 아니라 기술2 통합 예산에 포함한다.

### 5단계 — 적대적 검토

- 효과가 무학과 직접 연결되는가.
- 일반 피해·방어 증가로 개성이 평준화되지 않는가.
- 기술2가 기술1을 전 상황에서 폐기하지 않는가.
- 절초가 자동 정답·무적·필중·숨은 계획 접근이 되지 않는가.
- 실제 해결 순서가 효과의 의도를 망치지 않는가.

## 공통 성장 원칙

```text
가치 상위호환 + 역할 비대체
```

- 높은 성급은 더 높은 총가치를 가질 수 있다.
- 기술1·기술2·절초는 같은 무학을 공유하지만 사용 시점과 역할은 달라야 한다.
- 구조적 효과는 명시적 성급·threshold에서만 바뀐다.
- 거리·순서·합·회피·중단 실패를 자동으로 삭제하지 않는다.
- 해결 중 추가 버튼·선택·숨은 계획 접근은 만들지 않는다.

# 1. 유운검결

## 무공서 방향성

끊어지지 않는 검세로 상대의 빈틈을 따라 흐르며 압박하는 이동형 검법.

## 무학

구름은 멈추지 않는다. 한 번 열린 검로를 따라 공격을 이어가며, 상대가 물러나면 흩날리는 꽃잎을 쫓듯 자연스럽게 따라붙는다.

## 전투 감각

- 가볍고 유연함
- 성공한 공격이 다음 동작을 연다
- 이동은 도주보다 검세 유지와 추격에 사용
- 단일 고화력보다 흐름과 연속성이 핵심

## 기술1 — 유운삼첩

방향성: 첫 검이 길을 열고, 연속 적중으로 검세를 완성하는 근거리 3연격.

해결 순서:

```text
1타
→ 실제 체력 피해 시 2타
→ 다시 실제 체력 피해 시 3타
→ 세 타 모두 성공하면 후퇴
```

유지 사항:

- 총피해를 한 번 계산한 뒤 3타로 분배
- 실패한 타격의 피해 이월 없음
- 5성은 총피해 강화로 기본 연격 역할을 선명하게 함

## 기술2 — 낙영추검

방향성: 멀어진 상대를 따라붙어 거리 1~2에서 단발 결착을 노리는 추격검.

해결 순서:

```text
전진 1칸
→ 사거리 확인
→ 단발 공격·합 판정
```

역할 경계:

- 유운삼첩의 연속타를 복제하지 않는다.
- 추가 전진·필중·무료 재추격을 붙이지 않는다.
- 7성 최종 통합 효과는 단발 피해와 합 경쟁을 강화하는 방향으로 조정한다.

## 10성 절초 — 유운만리(가칭)

방향성: 접근·연격·추격이 끊기지 않는 하나의 검세로 완성되는 최종 경지.

동작 구조:

```text
접근
→ 연속 공격
→ 대상의 거리 변화에 맞춘 정해진 추격
→ 마지막 결착검
→ 종료 위치 확정
```

금지:

- 무제한 추격
- 실패 타격의 피해 몰아주기
- 상대 이동을 무시하는 필중 연속타

# 2. 금강호체공

## 무공서 방향성

공격을 받아내며 굳어진 육체와 축적한 방어를 힘으로 전환하는 공방일체 무공.

## 무학

금강은 충격에 흔들리지 않는다. 받은 힘을 몸 안에 가두고, 굳어진 몸의 무게를 다시 상대에게 돌려준다.

## 전투 감각

- 묵직하고 정면 대응적
- 방어는 생존 수치이자 공격 전환 자원
- 회피보다 받아내기
- 준비한 방어와 실제 흡수 성공이 보상으로 연결됨

## 기술1 — 금강가세

방향성: 몸을 먼저 굳히고 실제 공격을 완전히 받아냈을 때 더 강한 금강체를 완성한다.

해결 순서:

```text
방어 생성
→ 상대 공격 수용
→ 완전 흡수 판정
→ 방어·강건·기력 보상
→ 5성에서는 내력 추가 회복
```

역할: 순수 방어 준비와 완전 방어 보상.

## 기술2 — 반진권

방향성: 몸을 순간적으로 굳힌 뒤 현재 방어의 무게를 주먹에 실어 공격한다.

승인된 구조:

```text
방어 2 획득
→ 방어 획득 직후 현재 방어도 기록
→ 적 공격
→ 기록한 방어도만큼 일반 피해 추가, 최대 4
```

설계 규칙:

- 기존 방어 보유 조건 제거
- 방어 추가 피해는 최대 4
- 방어도는 소비하지 않음
- 기존 적중 후 방어·강건 획득은 제거
- 방어 기록값은 공격 도중 다시 계산하지 않음
- 방어 추가 피해에 별도 능력치 계수를 곱하지 않음

기술 관계:

- 반진권 단독 사용도 방어 2와 추가 피해 2로 작동
- 금강가세로 방어를 미리 축적하면 최대 추가 피해를 안정적으로 달성
- 금강가세는 수비, 반진권은 방어의 공격 전환

## 10성 절초 — 금강진천격(가칭)

방향성: 자신의 방어뿐 아니라 실제로 받아낸 충격까지 축적해 한 번에 되돌리는 금강체의 최종 경지.

동작 구조:

```text
강한 방어 생성
→ 실제 공격 수용
→ 흡수한 충격 기록
→ 방어와 충격을 한 번의 공격으로 전환
→ 잔여 방어 유지
```

금지:

- 공격을 받지 않아도 최대 성능
- 무조건 피해 반사
- 무적
- 방어 축적량에 제한 없는 피해 증가

# 3. 태극유전검

## 무공서 방향성

상대의 힘을 정면으로 막지 않고 흐름을 읽어 흘린 뒤 그 힘을 되돌려주는 대응형 검법.

## 무학

강한 힘과 맞서지 않는다. 상대의 방향을 읽어 비켜내고, 힘이 기울어진 순간 작은 힘으로 큰 힘을 움직인다.

## 전투 감각

- 침착한 대응
- 회피와 합이라는 두 종류의 힘 전환
- 상대 행동을 제대로 읽은 보상
- 자동 반격보다 성공한 대응 뒤 안정화

## 기술1 — 운수회신

방향성: 공격선을 흘려내고 몸과 내력을 안정된 흐름으로 되돌린다.

해결 순서:

```text
회피 부여
→ 회피 성공
→ 후퇴
→ 내력·방어 회복
→ 5성 절초기세 획득
```

역할: 회피 대응과 안전 복구.

## 기술2 — 사량발천근

방향성: 힘이 맞닿는 순간 상대 균형을 비틀어 합에서 우위를 얻고, 승리한 힘을 방어와 내력으로 순환한다.

해결 순서:

```text
공격·합 위력 형성
→ 합 판정
→ 합 승리
→ 방어 획득
→ 내력 획득
```

역할 경계:

- 운수회신의 회피를 부여하지 않는다.
- 자동 합 승리·숨은 계획 접근을 금지한다.
- 일반 고화력 공격보다 합과 힘 전환을 설명의 중심에 둔다.

## 10성 절초 — 태극귀원(가칭)

방향성: 상대의 힘과 자신의 힘을 하나의 태극 흐름으로 순환시켜 되돌리는 최종 대응검.

동작 구조:

```text
상대 공격과 접촉
→ 공개된 힘과 방향을 읽음
→ 합 또는 흘리기 판정
→ 성공한 힘 전환
→ 반격
→ 자기 방어·내력 안정화
```

금지:

- 숨은 행동 열람
- 자동 합 승리
- 조건 없는 전면 피해 반사

# 4. 추풍창법

## 무공서 방향성

창의 긴 사거리와 직선 추진력을 이용해 정확한 창끝 거리에서 찌르고 간격을 다시 지배하는 창법.

## 무학

창은 멀리 닿지만 가까운 적에게는 제 힘을 쓰지 못한다. 바람처럼 거리를 만들고, 창끝이 가장 강한 지점에서 적을 꿰뚫는다.

## 전투 감각

- 빠르고 직선적
- 거리 2의 창끝 보상
- 진입과 이탈을 모두 사용
- 정확한 거리 관리가 화력으로 연결

## 기술1 — 추풍일섬

방향성: 한 걸음 진입해 정확한 창끝 거리에서 단번에 꿰뚫는 고위험 단발 찌르기.

해결 순서:

```text
전진 1칸
→ 거리 확인
→ 찌르기
→ 창끝 성공 판정
→ 추가 피해·방어 파괴
→ 5성 후퇴·방어 보상
```

## 기술2 — 연환쇄로

방향성: 두 번의 찌르기로 적의 진로를 묶고, 공격이 끝난 뒤 창의 간격을 회수한다.

해결 순서:

```text
1타
→ 1타 결과 처리
→ 2타
→ 2타 결과 처리
→ 한 번 이상 적중했는지 확인
→ 후퇴 1칸
```

역할 경계:

- 추풍일섬의 창끝 방어 파괴를 복제하지 않는다.
- 실패한 1타 피해를 2타에 이월하지 않는다.
- 후퇴는 두 공격이 끝난 뒤 실행한다.

## 10성 절초 — 추풍관일(가칭)

방향성: 진입·관통·이탈이 하나의 직선으로 완성되는 창술의 최종 경지.

동작 구조:

```text
창끝 거리 형성
→ 강력한 직선 찌르기
→ 제한된 방어 돌파
→ 공격 결과 처리
→ 적정 창 거리로 이탈
```

금지:

- 거리 1에서도 창끝 최대 보상
- 최대 사거리·최대 피해·무료 이동의 무조건 동시 획득
- 무제한 관통

# 5. 청심양생공

## 무공서 방향성

호흡과 경맥을 정돈해 소모된 내력을 순환시키고 무너지기 직전의 몸을 안정화하는 양생 심법.

## 무학

억지로 힘을 짜내지 않는다. 흐트러진 호흡을 바로잡고 막힌 경맥을 열면 기와 혈은 스스로 제자리로 돌아간다.

## 전투 감각

- 폭발적 완전 회복보다 안정적 순환
- 자원이 낮을수록 가치가 높음
- 장기전 유지
- 무한 지연과 전투 초기화는 금지

## 기술1 — 청심조식

방향성: 짧은 호흡으로 내력을 회복하고, 극저자원 상태에서는 더 깊은 조식으로 기력·방어·체력을 보조한다.

해결 순서:

```text
기본 내력 회복
→ 행동 시작 전 저자원 조건 확인
→ 조건 만족 시 기력·내력·방어 추가 회복
→ 5성 체력 회복
```

역할: 평시 자원 정비와 고갈 예방.

## 기술2 — 회기전맥

방향성: 막힌 경맥을 먼저 열어 내력을 되돌리고, 회복된 기를 전신에 순환시켜 몸을 안정화한다.

권장 해결 순서:

```text
저자원 조건 확인
→ 기력 비용 지불
→ 내력 2 회복
→ 강건 획득
→ 방어 회복
→ 체력 회복
```

후속 효과는 회복 후 내력값을 참조하는 방향을 우선 검토한다. 다만 원가 상승과 내력 상한 포화는 3단계 예산 편성에서 재계산한다.

역할: 저자원 위기 안정화.

## 10성 절초 — 대주천귀원(가칭)

방향성: 전신 경맥을 한 바퀴 순환시켜 고갈된 내력과 손상된 육체를 다시 싸울 수 있는 기준선까지 회복한다.

동작 구조:

```text
현재 체력·자원 상태 확인
→ 경맥 개방
→ 내력 순환
→ 방어·강건 안정화
→ 제한된 체력 회복
```

금지:

- 조건 없는 완전 회복
- 전투 상태 초기화
- 최대치 초과 저장
- 무한 지연

# 6. 무영십보

## 무공서 방향성

공격선에서 자취를 지우고, 상대가 허공을 친 순간 빈틈을 찌른 뒤 다시 거리를 없애는 신법.

## 무학

먼저 달아나는 것이 아니다. 상대 공격이 닿는 순간 그 자리를 비우고, 빈틈을 찌른 뒤 흔적 없이 사라진다.

## 전투 감각

- 빠르고 날카로움
- 위치 전환과 회피 후 역공
- 선제 안전 확보와 반응형 반격을 분리
- 숨은 계획을 미리 아는 능력은 없음

## 기술1 — 철각유영

방향성: 공격이 오기 전에 먼저 거리를 만들고 이어지는 공격까지 흘려낸다.

해결 순서:

```text
선행 후퇴
→ 회피 부여
→ 회피 성공
→ 추가 후퇴
→ 절초기세 획득
→ 5성 강건·방어 보상
```

역할: 선제 이탈과 안전 확보.

## 기술2 — 십보환위

방향성: 공격을 피한 바로 그 자리에서 빈틈을 반격하고, 반격이 끝난 뒤 자취를 감춘다.

승인된 해결 순서:

```text
회피 1회 부여
→ 회피 성공
→ 이동 전 위치에서 원래 공격자에게 반격
→ 반격 결과 처리
→ 최대 2칸 후퇴
```

설계 규칙:

- 반격 사거리는 후퇴 전 위치에서 확인
- 반격이 빗나가도 회피 성공 시 후퇴 실행
- 후퇴 공간이 없으면 제자리 유지
- 추가 위치 선택 입력 없음
- 자동 회피 성공·추가 회피·숨은 계획 접근 금지

역할: 반응형 회피·반격·이탈.

## 10성 절초 — 십보무흔(가칭)

방향성: 공격이 닿는 순간 자취를 지우고 빈틈에 나타나 일격을 가한 뒤 다시 시야 밖으로 사라지는 최종 신법.

동작 구조:

```text
회피 부여
→ 회피 성공
→ 빈틈 반격
→ 위치 전환
→ 후속 공격선에서 이탈
```

금지:

- 자동 회피 성공
- 숨은 계획 확인
- 무제한 연속 회피·반격

## 여섯 무공 성장 관계 요약

| 무공서 | 기술1 | 기술2 | 10성 절초 |
|---|---|---|---|
| 유운검결 | 연격의 흐름 | 추격 단발 결착 | 접근·연격·추격의 단일 검세 |
| 금강호체공 | 방어 축적 | 방어를 공격으로 전환 | 방어와 받아낸 충격의 방출 |
| 태극유전검 | 회피·흘리기 | 합을 통한 힘 전환 | 상대 힘 전체의 순환·반전 |
| 추풍창법 | 창끝 단발 찌르기 | 2타 압박과 거리 회수 | 진입·관통·이탈의 일체화 |
