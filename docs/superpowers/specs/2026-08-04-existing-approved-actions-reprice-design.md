# 기존 승인 행동 새 거리 가격 적용 설계

- 승인 근거: 사용자 승인 `권장안대로 진행`
- Decision ID: `TEN-DEC-20260804-EXISTING-ACTIONS-REPRICE-01`
- 적용 상태: `CURRENT_APPROVED_PLANNING`
- 구현 범위: 기획 계약·자동 검증·정본 동기화
- 제외 범위: HTML PoC, Godot 런타임, 미확정 10성 고유 절초

## 목표

새 통합 거리 가격인 이동 1칸 15틱, 공격 사거리1 초과 1칸당 15틱을 기존 승인 행동에도 실제 적용한다. 기존 행동의 피해·거리·이동·태그·조건·무공 역할은 보존하고, 기력·내력 비용 또는 슬롯 수만 조정해 모든 행동을 허용 편차 `±5틱` 안에 둔다.

## 권위 구조

역사 Decision과 원본 계약은 승인 당시 근거로 보존한다. 제품 구현과 이후 기술 작성에서는 `docs/planning-data/approved_20260804_existing_action_reprice_contract.json`을 마지막에 적용하여 비용과 슬롯을 덮어쓴다. 이 오버레이가 기존 계약의 비용·슬롯 필드보다 우선한다.

## 적용 대상

- 기초 공격 3종: 속공, 강공, 장풍
- 3성 기술1 6종
- 7성 기술2 6종
- 총 15종

10성 고유 절초는 효과가 승인되지 않았으므로 제외한다. 이동·막기·회피·관찰·명상·준비처럼 거리 가격 조정 대상이 아닌 기초 행동도 제외한다.

## 조정 원칙

1. 효과 정체성 보존: 피해 공식, 이동 칸, 최대 사거리, 연격 수, 회피, 방어, 조건을 변경하지 않는다.
2. 비용 우선: 새 가격 초과분은 기력·내력 비용 증가로 맞춘다.
3. 슬롯 예외: 비용만으로 과도해지는 십보환위만 2수에서 3수로 변경한다.
4. 사용 가능 예산: 슬롯 예산 + 기력×4 + 내력×7 + 조건·기타 확정 허용량.
5. 지불 가능성: 기력 최대5, 내력 최대4 안에서 확정 지불 가능해야 한다.
6. 허용 편차: 모든 행동은 `±5틱` 안에 있어야 한다.

## 구현 계약

- 오버레이는 `action_id`, 유효 슬롯, 유효 비용, 거리 구조, 거리 제외 효과 원가, 거리 원가, 전체 효과 원가, 조건 허용량, 사용 가능 예산, 편차를 모두 보유한다.
- 구현 데이터 생성기는 역사 원본을 읽은 뒤 오버레이를 적용해야 한다.
- 자동 검증은 정확히 15개 ID, 분류 3/6/6, 가격 공식, 편차, 지불 가능성을 검사한다.
- 1틱이라도 임의 변경되거나 하나의 행동이 누락되면 CI가 실패한다.

## 위험과 검증

추풍일섬·철각유영·연환쇄로는 높은 내력 또는 기력 비용 때문에 연속 사용성이 크게 낮아진다. 이는 이동·거리의 높은 전술 가치에 대한 의도된 비용이지만, 사람 밸런스 검증에서 선택률과 자원 고갈률을 확인해야 한다. 현재 사람 검증·Godot 검증·Windows 검증은 `NOT_RUN`이다.
