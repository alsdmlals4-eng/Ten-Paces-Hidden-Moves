## 사용자 확정 원칙

초기 무공은 실재 무술인지보다 한국·중국 무협 독자에게 친숙하고 즉시 이해되는지가 중요하다.

```text
실재 무술 여부보다 무협 인지도 우선
한국 무협과 중국 무협을 모두 조사
창작물 속 무공도 적극 허용
문파의 대표 무공과 절초를 우선 사용
10성 절초의 이름과 판타지를 먼저 정한 뒤 하위 기술을 역설계
```

## 1. 필수 조사 범위

무공서·기술·절초를 추가하거나 변경하기 전에 다음 두 문화권을 모두 조사한다.

### 한국 무협

- 한국 구무협·신무협·웹소설·웹툰·게임에서 굳어진 문파 관용 설정
- 한국 독자가 특정 문파를 보고 즉시 기대하는 대표 무공
- 중국 원전과 다르게 한국 무협에서 독자적으로 강화된 연결
- 예: 화산과 매화검법, 자하신공의 강한 결합

### 중국 무협

- 김용·고룡·양우생 등 대표 무협 작품과 후대 드라마·영화·게임에서 반복된 무공
- 중국 독자가 특정 문파·세가·인물을 보고 기대하는 대표 무공
- 원작 고유 설정과 여러 작품에 확산된 장르 관용 설정을 구분
- 예: 개방의 항룡십팔장·타구봉법, 무당의 태극권·태극검

한쪽 문화권만 조사하고 다른 쪽의 인지도를 추정하지 않는다.

## 2. 실재성보다 인지도 우선

다음 모두 무공 후보로 허용한다.

- 실재 중국 무술과 병장기 기술
- 고전·현대 무협 소설 속 창작 무공
- 영화·드라마·만화·웹소설·게임에서 유명해진 창작 무공
- 한국 무협에서 문파 대표 설정으로 굳어진 관용 무공
- 중국 무협 원작에서 특정 문파·인물의 대표기로 알려진 무공

실재 역사에 존재하지 않는다는 이유만으로 유명 무공을 배제하지 않는다.

## 3. 후보별 필수 메타데이터

모든 후보는 최소 다음을 기록한다.

| 필드 | 설명 |
|---|---|
| 이름 | 한글 표기와 필요 시 한자·중문 표기 |
| 관련 문파·세가 | 소림·무당·화산·개방·당문 등 |
| 무공 종류 | 검법·장법·권법·내공·신법·암기·봉법 등 |
| 한국 무협 인지도 | HIGH / MEDIUM / LOW |
| 중국 무협 인지도 | HIGH / MEDIUM / LOW |
| 문파 연상도 | 이름만 보고 해당 문파를 떠올릴 가능성 |
| 출처 분류 | 실재 무술 / 특정 작품 고유 / 장르 관용 / 한국 무협 관용 / 프로젝트 창작 |
| 대표 작품·사용 맥락 | 인지도의 근거가 되는 작품·매체 |
| 전투 판타지 | 플레이어가 이름에서 기대하는 행동 |
| 역할 적합성 | 현재 전투 역할과의 일치 여부 |
| 중복 위험 | 기존 무공·기술·절초와의 역할 중복 |
| 출처 의존 위험 | 특정 작품을 지나치게 직접 연상시키는 정도 |
| 채택 방식 | 원명 사용 / 문파명 병기 / 변형명 / 창작명으로 재구성 |

## 4. 인지도 평가 우선순위

```text
한국·중국 양쪽에서 문파 대표로 통하는 이름
→ 한쪽에서 매우 유명하고 다른 쪽에서도 이해 가능한 이름
→ 특정 작품에서 유명하지만 문파·역할 연상이 강한 이름
→ 한국 무협 관용명 또는 중국 무협 관용명
→ 프로젝트 창작명
```

완전 창작명은 유명 후보가 역할·세계관·중복 검토를 통과하지 못했을 때만 사용한다.

## 5. 문파 표시 의무

무공 카탈로그와 설계 문서에는 관련 문파·세가·유파를 반드시 표시한다.

표시 예:

```text
[화산파] 매화검법
[소림사] 나한권
[무당파] 태극검
[개방] 항룡십팔장
[사천당문] 만천화우
[하북팽가] 오호단문도
```

프로젝트 세계관에 원본 문파가 직접 존재하지 않는 경우 다음 중 하나를 명시한다.

- 원류 문파
- 계승 유파
- 모방·복원 무공
- 동명 이계통 무공

관련 문파를 숨긴 채 이름만 차용하지 않는다.

## 6. 절초 우선 역설계

절초는 무공서에서 가장 중요한 이름과 선택 약속이다.

```text
1. 관련 문파와 대표 판타지 결정
2. 인지도 높은 대표 절초 후보 조사
3. 10성 절초 이름·전투 장면·실패 조건 결정
4. 절초의 원리를 가르치는 무공서 방향성 결정
5. 7성 기술2와 9성 완성 효과 역설계
6. 3성 기술1과 5성 추가 효과 역설계
7. 해결 순서·예산·상대 대응 검토
```

유명 무공 전체가 하나의 체계인 경우에도 게임에서는 10성 절초가 그 체계의 완성 경지를 대표할 수 있다.

## 7. 대표 문파 벤치마크 출발점

다음은 조사 시작점이며 자동 채택 목록이 아니다.

| 문파·세가 | 우선 조사할 유명 무공 |
|---|---|
| 화산파 | 매화검법·이십사수매화검법·자하신공 |
| 소림사 | 나한권·대력금강장·금강불괴·역근경·여래신장 계열 |
| 무당파 | 태극권·태극검·태극혜검·제운종 |
| 개방 | 항룡십팔장·타구봉법 |
| 사천당문 | 만천화우·폭우이화침·암기·독공 계열 |
| 하북팽가 | 오호단문도 |
| 아미파 | 아미검법·금정면장 계열 |
| 곤륜파 | 양의검법·운룡 계열 신법 |
| 종남파 | 전진·선천·검진 계열 후보 |
| 남궁세가 | 창궁·제왕검 계열 한국 무협 관용 설정 |
| 모용세가 | 두전성이 계열 |
| 대리 단씨 | 일양지·육맥신검 계열 |
| 명교·마교 | 건곤대나이·천마신공 계열 |

각 후보는 한국·중국 양쪽 인지도와 현재 게임 역할을 다시 확인한 뒤 채택한다.

## 8. 적대적 검토 추가 항목

### 인지도 공격

- 문파 이름을 제거해도 사용자가 해당 계열을 알아보는가.
- 유명하다는 판단이 한 작품 팬덤에만 의존하지 않는가.
- 한국에서는 유명하지만 중국에서는 전혀 다른 문파로 인식되지 않는가.
- 중국 원작 고유명인데 한국 무협 관용 설정으로 오인하고 있지 않은가.

### 기대 불일치 공격

- 항룡십팔장이라는 이름인데 약한 견제기처럼 보이지 않는가.
- 만천화우라는 이름인데 단발 암기 하나만 던지지 않는가.
- 금강불괴라는 이름인데 방어 체감보다 공격 피해가 중심이지 않은가.
- 매화검법인데 연속성·분화·검세의 아름다움이 표현되지 않는가.
- 자하신공인데 내공 축적·순환·검법 지원과 연결되지 않는가.

### 문파 역할 공격

- 소림·개방·당문·화산의 대표 판타지가 서로 바뀌지 않았는가.
- 같은 문파의 두 무공이 같은 역할을 반복하지 않는가.
- 유명 이름을 붙였다는 이유로 역할 비대체 규칙을 무시하지 않는가.

### 출처 의존 공격

- 특정 작품의 이름·설명·초식 구성을 그대로 복제하고 있지 않은가.
- 원명 사용이 필요하지 않은데도 인지도를 이유로 과도하게 차용하지 않는가.
- 출시 전 별도 명칭·권리 검토가 필요한 후보를 표시했는가.

## 9. 현재 10권 설계에 대한 즉시 영향

기존 10권 초안은 자동 승인하지 않는다.

다음 후보는 재검토한다.

- 당문 절초 `천녀산화` → `만천화우` 우선 검토
- 소림 방어 무공만 유지하는 안 → `여래신장` 공격 판타지 포함 여부 재검토
- 개방 무공 부재 → `항룡십팔장` 또는 `타구봉법` 계열 추가 검토
- 화산 창작 검법 중심 안 → `매화검법`·`자하신공`을 중심으로 전면 재검토
- 문파가 표시되지 않은 양가·팔극·오호도·곤법 후보 → 문파·세가 표기를 필수화

기존 효과·예산은 역사 자료로 유지하되, 새 10권 역할표가 승인되기 전에는 정본으로 승격하지 않는다.
