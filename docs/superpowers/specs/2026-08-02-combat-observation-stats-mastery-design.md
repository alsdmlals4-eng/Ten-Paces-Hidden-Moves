# 전투 관찰·스테이터스·무공서 성장 설계

- 승인 Decision: `TEN-DEC-20260802-OBSERVATION-STATS-MASTERY-01`
- 상태: `APPROVED_DESIGN`
- 범위: 기획 정본과 데이터 계약
- 제외: Godot 런타임, 밸런스 확정, 실제 Windows·사람 검증

## 목적

플레이어가 비무 전 조사로 상대의 가능한 수를 알고, 전투 중 `[관찰]`로 다음 묶음의 행동 종류를 읽은 뒤 자신의 3/3/4 계획을 구성하게 한다. 성장에서는 무공서 수련과 무인의 영구 스테이터스를 결합하되, 기술마다 별도 수련도를 요구하지 않는다.

## 핵심 경험

1. 상대 후보와 무공서를 조사해 가능한 수의 범위를 파악한다.
2. 현재 묶음에서 공격·방어 기회를 포기하고 관찰량을 축적한다.
3. 다음 묶음 시작에 적이 현재 상태로 계획을 잠근다.
4. 관찰량만큼 `[전조]`, `[이동+공격]` 같은 종류를 확인한다.
5. 기술 목록·거리·자원·과거 행동을 결합해 실제 수를 추론한다.
6. 무공서 성취와 영구 스테이터스를 성장시켜 기술과 절초를 완성한다.

## 시스템 경계

### DuelPool

- 5개 학습 역할 슬롯을 소유한다.
- 슬롯마다 후보 3명을 소유한다.
- 전투 시스템이나 기술 데이터를 직접 계산하지 않는다.

### PreDuelIntel

- 짧은 무림식 소개, 영구 스테이터스, 무공서·성취, 사용 가능한 기술을 제공한다.
- AI 가중치나 정답형 파훼법은 제공하지 않는다.

### EnemyBundlePlanner

- 묶음 시작 시 현재 공개 상태를 입력받는다.
- 이번 묶음만 생성하고 즉시 잠근다.
- 플레이어의 미확정 계획을 입력받지 않는다.

### ObservationBank

- 플레이어 전용 관찰량을 저장한다.
- 상한 없이 묶음·라운드 경계를 넘겨 이월한다.
- 적 묶음 확정 뒤 앞 수부터 종류를 공개하고 남은 양을 유지한다.

### MartialManualProgression

- 무공서별 성, 현재 성까지 투자한 수련포인트, 성취별 보상을 소유한다.
- 기술별 별도 수련도는 소유하지 않는다.
- 2·4·6·8성의 고정 스테이터스 보너스와 3·7·10성 기술 해금 판정을 제공한다.

### TechniqueAvailability

- 무공서 요구 성과 영구 스테이터스 요구를 검사한다.
- 미달 기술을 잠금 상태로 유지한다.
- 조건 충족 시 자동 활성화한다.
- 일시 스테이터스 감소로 이미 활성화된 기술을 다시 잠그지 않는다.

### SettlementPressure

- 4라운드 종료부터 결착 피해를 동시 적용한다.
- 동시 전투 불능 시 승인된 체력 비율·유효 피해 순서로 판정한다.

## 데이터 흐름

```text
비무 후보 확정
→ 비무 전 조사
→ 적 현재 묶음 계획·잠금
→ 관찰량 적용·종류 공개
→ 플레이어 현재 묶음 계획·잠금
→ 전투 해결
→ 관찰량 적립
→ 다음 묶음 또는 결착 압력
→ 비무 종료
→ 중간 노드에서 수련포인트·영구 스테이터스 획득
→ 무공서 성취·기술 사용 가능 상태 재계산
```

## UI 계약

- 무공서는 `유운검결 [7성/10성]`처럼 현재 성과 최대 성을 표시한다.
- 다음 성취 진행은 `다음 8성: 수련 3/6`처럼 무공서 단위로 표시한다.
- 기술 잠금 화면은 `요구 성취`와 `영구 스테이터스`를 분리해 표시한다.
- `수련도 5/4`처럼 기술 자체가 수련도를 가진 것으로 오해되는 표기는 금지한다.
- 관찰 결과는 기술 카드 대신 종류 토큰으로 표시한다.
- 복합 기술은 `[이동+공격]`처럼 모든 구성 종류를 한 토큰에 표시한다.
- 공개된 종류와 비공개 세부값을 시각적으로 구분한다.

## 성장 계약

- 영구 스테이터스: 외공, 근골, 신법, 내공, 심안.
- 주요 범위: 1~15.
- 시작 직접 분배, 짝수 성 고정 보너스, 중간 노드 보상으로 성장한다.
- 5·9성은 대응 기술의 기본 패치와 별도 임계 효과를 함께 등록한다.
- 10성은 무공서 고유 절초만 제공한다.

## 실패와 복구

- 스테이터스 미달 기술은 획득 기회를 잃지 않고 잠긴다.
- 무공서 수련은 잠긴 기술과 무관하게 계속된다.
- 관찰량이 남아도 아직 생성되지 않은 미래 묶음을 선행 생성하지 않는다.
- 적 계획이 공개 뒤 실행 불가능해지면 승인된 전투 실패·취소 규칙을 적용하며 더 유리한 행동으로 교체하지 않는다.
- 결착 피해 적용 전 이미 승패가 났다면 결착 피해를 적용하지 않는다.

## 테스트 요구

1. 3수 묶음에서 관찰량 5 사용 시 3수 공개 후 2가 이월되는가.
2. 4수 묶음 네 수가 모두 공개될 수 있는가.
3. 3묶음에서 얻은 관찰량이 다음 라운드 1묶음에 적용되는가.
4. 복합 기술이 모든 종류를 공개하고 기술명은 숨기는가.
5. 적 계획이 관찰 공개 뒤 바뀌지 않는가.
6. 적 AI가 미확정 플레이어 계획을 입력받지 않는가.
7. 4·5·6라운드 결착 피해가 각각 `10%+5`, `10%+10`, `10%+15`인가.
8. 동시 전투 불능 판정이 승인 순서를 따르는가.
9. 7성 도달·스테이터스 미달 기술이 잠기고 8·9·10성 수련은 계속 가능한가.
10. 이후 영구 스테이터스 충족 시 별도 비용 없이 기술이 활성화되는가.
11. 일시 약화가 이미 터득한 기술을 잠그지 않는가.
12. 5·9성 기본 패치와 임계 효과가 서로 독립적으로 적용되는가.
