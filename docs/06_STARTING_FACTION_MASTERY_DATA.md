## 1. 현재 상태

프로젝트 코어가 사용자 승인된 상태에서 무공서 성장 골격, 시작 총합20, 3성 주 능력치4, 7성 주 능력치8, 짝수 성 신규 지급 구조도 승인되었다. 런타임에는 아직 최신 스테이터스·기술 요구 조건이 연결되지 않았으며 개별 무공 기술 수치와 기술 예산은 `POC_HYPOTHESIS`다.

현재 T0에는 세력 선택이 없고, 런타임의 공용 절초 3종은 기술 계보 보존 대상으로 남는다. 새 무공·세력 데이터는 공용 전투 계약을 대체하지 않고 확장한다.

## 2. 현행 전투 계약과 연결 원칙

전투 행동은 `기본 행동 + 무공서 기술`로 구성한다. 무공 기술은 공용 필드 `action_slots`, `stamina_cost`, `internal_cost`, `range`, `move_range`, `hits`, `effects`, `sure_hit`을 조합한다. 세력 하나를 위해 별도 라운드·판정 엔진을 만들지 않는다.

효과는 `scope=PER_HIT|ONCE_PER_ACTION`과 `trigger=ON_ACTION_START|ON_ACTION_RESOLVE|ON_CLASH_WIN|ON_EVADE_SUCCESS|ON_HIT|ON_HEALTH_DAMAGE|ON_ACTION_END`를 명시한다.

기술 결과는 다음 세 층으로 구성한다.

1. 항상 적용되는 고정 효과
2. 외공·근골·신법·내공·심안 중 허용된 스테이터스 참조
3. 5·9성에서 해당 기술에 추가되는 스테이터스 임계 효과

이동거리(`move_range`), 공격 사거리, 관찰량, 행동 슬롯 수, 회피 횟수, 전조 수와 같은 구조적 값은 스테이터스1점마다 연속 증가하지 않는다. 기술에 명시된 임계 효과에서만 변경한다.

## 3. 다음 PoC 성장 실험

다음 PoC에서는 시작 후보6개 중4개를3성으로 선택한다. 네 중간 구간의 수련·전투·사건 보상에서 분산 투자와 집중 투자를 비교한다. 한 무공에 3→10 총38 수련포인트를 집중하면 주요 비무5 전 10성 절초와 높은 스테이터스 요구를 달성할 가능성이 있어야 하지만, 모든 경로의 보장값으로 만들지는 않는다.

검증 질문:

- 성장 선택이 다음 전투의 거리·순서·자원 계획을 실제로 바꾸는가?
- 단순 피해 상승보다 합·중단·방어·회피·관찰 판단을 강화하는가?
- 짝수 성 보너스와 중간 노드가 기술 요구 스테이터스를 무리 없이 연결하는가?
- 같은 Schema로 두 번째 무공과 두 번째 기술을 만들 수 있는가?
- 능력치4·15·현재 합법 최대값에서 높은 수치가 잘못된 계획을 반복적으로 덮지 않는가?

## 4. 장기 보유 구조 가설

- 한 회차에 여러 무공을 익힐 수 있다.
- 해금 기술은 덱·손패·장착 제한 없이 사용 후보가 된다.
- 배운 무공 수 하드캡보다 수련포인트·회차 길이·해금 간격으로 실제 기술 수를 제한한다.
- 정확한 보유 한도는 T1 이후 결정한다.
- 10성 보상은 무공서 고유 `[절초]`로 고정한다. `진의` 선택 구조는 사용하지 않는다.

## 5. 시작 규칙

- 외공·근골·신법·내공·심안은 각각 기본2다.
- 자유 분배6점을 모두 사용한 뒤 후보 무공6개 중4개를3성으로 선택한다.
- 선택한 각 무공의2성 주 능력치+1을 적용해 최종 시작 총합20·평균4를 만든다.
- 직접 분배 단계의 각 능력치는2~6이며 무공 보너스는 이후 적용되어6에서 잘리지 않는다.
- 3성 첫 기술은 해당 무공의 주 영구 능력치4를 요구한다.
- 어떤 시작 무공4개 조합도 네 기술을 모두 활성화할 수 있으며 `[추천 배분]`은 최소 해금 기준선만 제공한다. 일부 기술 잠금 전문화는 경고 후 허용한다.
- 기본 절초3종은 무공 성급과 독립적으로 시작부터 사용 후보다.
- 배운 무공 수 하드캡은 없다.
- 실제 사용 가능 기술은 수련 자원, 영구 스테이터스와 회차 길이로 제한한다.

## 5.2 습득·중복 계약

- 시작 선택 무공과 회차 중 신규 습득 무공은 모두3성으로 시작한다.
- 1성 패시브와2성 고정 스테이터스 보너스는 즉시 한 번만 적용한다.
- 3성 기술은 주 영구 능력치4 충족 시 활성화하며 미달이면 기술만 잠긴다.
- 이미 보유한 문파 무공3성 보상을 다시 고르면 같은 무공의 지정 수련10으로 변환하며2성 보너스를 재지급하지 않는다.
- 무공 기술은 `category`, `resolution_phase`, `targeting_mode`, `attack.raw_powers/range`, `movement.timing/mode/max_tiles`를 명시한다.
- 각3·5·7·9·10성 전환점은 안정 필드 `skill_milestone`으로 기록한다.
- 5·9성 patch는 기본 강화와 스테이터스 임계 효과를 분리해 기록한다.
- 기술마다 별도 수련도나 수련포인트를 두지 않는다.
- 짝수 성 보너스의 idempotent 키는 무공ID+성취별 milestone+회차ID를 기준으로 구현한다.

## 6. 영구 스테이터스

핵심 스테이터스는 외공·근골·신법·내공·심안5종이며 디자인 하드캡은 없다. 기존1~15는 초기 밸런스 검증 구간이고 합법적인15 초과값을 절단·소실·재분배하지 않는다.

| 스테이터스 | 역할 |
|---|---|
| 외공 | 외가 공격·강공·밀기·방어 파괴 |
| 근골 | 최대 체력·방어도·강건·버티기 |
| 신법 | 이동·보법·회피 |
| 내공 | 최대 내력·내가 효과·호신·회복 |
| 심안 | 관찰·간파·반격·전조 대응 |

영구 스테이터스 획득처:

- 시작 직접 분배
- 무공서2·4·6·8성의 고정 보너스
- 별도 승인된 중간 노드 또는 콘텐츠 보상

회피율·피해 감소율·발동 확률처럼100%에 가까워질수록 규칙을 무효화하는 파생 효과는 원천 능력치 상한이 아니라 별도 점근 곡선·효과 한계·기술 임계로 보호한다.

## 7. 1~10성 구조

| 성 | 해금·성장 |
|---:|---|
| 1 | 고유 패시브 |
| 2 | 주 영구 능력치+1 신규 지급 |

| 4 | 주+1·보조+1 신규 지급 |

도달 비용은4:2, 5:3, 6:4, 7:5, 8:6, 9:8, 10:10이며3→10 총38이다.

무공서 수련은 스테이터스 요구로 막히지 않는다. 요구치는3·7·10성 신규 기술의 활성 여부에만 사용한다.

- 3성 기술: 주 영구 능력치4
- 7성 기술: 주 영구 능력치8, 보조 요구 없음
- 10성 절초: 높은 요구치, 다음 승인 묶음에서 확정
- 한 기술의 요구 스테이터스는 최대2종

7성 직전 무공 자체 보너스의 자동 주 능력치 하한은6이다. 주8은 시작 분배·다른 무공 시너지·승인된 영구 성장에서 추가2점을 요구하는 빌드 Gate다.

무공서가 요구 성에 도달했지만 스테이터스가 부족하면 해당 기술만 잠긴다. 무공서는 계속 수련할 수 있으며, 이후 영구 스테이터스를 충족하면 별도 비용 없이 자동 활성화된다. 한번 터득한 기술은 전투 중 일시 스테이터스 감소로 다시 잠기지 않는다.

5·9성 기본 강화는 성취 도달 즉시 적용한다. 스테이터스 미달 시 해당 기술의 임계 효과만 비활성화하고 이후 조건 충족 시 자동 활성화한다.

## 8. 세력 정체성 후보

PoC에서는 세력 전체를 제작하지 않고 다음 전투 역할만 검증한다.

| 역할 후보 | 대표 무공 | 공용 계약 연결 |
|---|---|---|
| 연격 검법 | 유운검결 | 순차 합·중단 |
| 호신 외공 | 금강호체공 | 방어도·강건 |
| 대응 검법 | 태극유전검 | 회피·합 보정 |
| 거리 병기 | 추풍창법 | 사거리·이동 |
| 양생 심법 | 청심양생공 | 자원·의료 |
| 경공 | 무영십보 | 이동·회피 |

문파명·세력 수·무기 계통은 역할 중복과 제작 비용을 검증한 뒤 확정한다.

## 10. 슬롯 예산

- 0.05=1tick.
- 목표20/50/80tick.
- ±5tick 허용.
- 최대 사거리 총비용은1=0, 2=10, 3=25, 4=40tick이며5 이상은 별도 승인 전 `TBD`.
- 피해·사거리·이동·방어·회피·필중·강건·추가 타격·자원·조건을 중앙 가격표의 `price_id × quantity` ledger로 계산.
- 중앙 가격 변경 시 기존 기술 자동 수정 금지.
- 5·9성 스테이터스 임계 효과도 별도 가격표와 검증 가능한 ledger를 가져야 한다.

## 11. `[의료]`

- 시작0, 최대4.
- 청심양생공1·5·10성의 기존 후보값은 최신1~10성 계약에 맞춰 재배치가 필요하다.
- 희귀 회차 사건에서+1 후보.
- 승리 후 `min(잃은 체력, 2+[의료])`.
- 전투 중 회복·객잔·시장에는 자동 적용하지 않는다.

## 12. 기본 절초·10성 절초·진의

- 기본 절초3종은 PoC 시작부터 기존 기세5·연속 슬롯·대상 계약으로 사용할 수 있다.
- 무공별10성 절초는 해당 무공10성 도달과 후속 승인될 높은 영구 스테이터스 요구 충족으로 해금된다.
- 별도 비무 승리 게이트는 사용하지 않는다.
- 10성 절초는3슬롯80tick 기준으로 평가한다.
- 집중 보상32+최소 집중 노드6 경로는 주요 비무5 진입 전 한 무공10성 도달을 가능하게 한다.
- 절초 스테이터스 요구까지 포함한 실제 달성 가능성은 시작 분배·짝수 성 보너스·승인된 중간 노드를 합쳐 검증한다.
- 선택적10성 능력이 없어도 PoC를 정상 완료할 수 있어야 한다.
- `진의` 선택 구조는 폐기되었으며10성 보상은 절초로 고정한다.
