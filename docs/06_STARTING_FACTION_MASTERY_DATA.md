# 십보강호 세력·핵심무공·심법 성장 가설

> 책임: 시작 무공 후보·1~10성 성장·기술 예산·`[의료]` 공급  
> 현재 전투 규칙: `docs/02_COMBAT_RULES.md`  
> 데이터 원본: `docs/planning-data/poc_martial_arts.json`  
> 상태: T1 이후 가설 원본이지만 다음 PoC의 성장 표본을 포함한다.

## 1. 현재 상태

프로젝트 코어가 사용자 승인된 상태에서, 다음 PoC용 성장 데이터를 작성했다. 런타임에는 연결되지 않았으며 모두 `POC_HYPOTHESIS`다.

현재 T0에는 세력 선택이 없고, 런타임의 공용 절초 3종은 기술 계보 보존 대상으로 남는다. 새 무공·세력 데이터는 해당 공용 전투 계약을 대체하지 않고 확장한다.

## 2. 현행 전투 계약과 연결 원칙

무공은 공용 필드 `action_slots`, `stamina_cost`, `internal_cost`, `range`, `move_range`, `hits`, `effects`, `sure_hit`을 조합한다. 세력 하나를 위해 별도 라운드·판정 엔진을 만들지 않는다.

효과는 `scope=PER_HIT|ONCE_PER_ACTION`과 `trigger=ON_ACTION_START|ON_ACTION_RESOLVE|ON_CLASH_WIN|ON_EVADE_SUCCESS|ON_HIT|ON_HEALTH_DAMAGE|ON_ACTION_END`를 명시한다.

## 3. 다음 PoC 성장 실험

다음 PoC에서는 시작 후보 6개 중 4개를 3성으로 선택한다. 네 중간 구간의 수련·전투·사건 보상에서 분산 투자와 집중 투자를 비교한다. 한 무공에 3→10 총 38 수련포인트를 집중하면 주요 비무 5 전에 10성 절초에 도달할 가능성이 있어야 하지만, 모든 경로의 보장값으로 만들지는 않는다.

검증 질문:

- 성장 선택이 다음 전투의 거리·순서·자원 계획을 실제로 바꾸는가?
- 단순 피해 상승보다 합·중단·방어·회피 판단을 강화하는가?
- 같은 Schema로 두 번째 무공과 두 번째 기술을 만들 수 있는가?

## 3.1 주요 비무 성장 선택

- 자유 수련: 자유6.
- 집중 수련: 지정 무공5 + 자유3, 총 8.
- 문파 전수: 해당 문파 무공을 3성으로 습득. 비교가치 10의 제한 보상이지만 수련포인트로 직접 환산하지 않는다.
- 주요 비무 1~4 집중 수련 32 + 네 중간 구간 최소 집중 수련6 = 38로 주요 비무5 진입 전 10성을 보장 가능한 경로로 만든다.
- 자유 수련24 경로는 고효율 중간 노드14를 골라야 38에 도달한다.

## 4. 장기 보유 구조 가설

- 한 회차에 여러 무공을 익힐 수 있다.
- 해금 기술은 덱·손패·장착 제한 없이 사용 후보가 된다.
- 배운 무공 수 하드캡보다 수련포인트·회차 길이·해금 간격으로 실제 기술 수를 제한한다.
- 심법·진의는 자원 순환·상태 유지·명상 변형을 담당할 수 있으나 다음 PoC 필수 범위가 아니다.
- 정확한 보유 한도는 T1 이후 결정한다.

## 5. 시작 규칙

- 후보 무공 6개 중 4개 선택.
- 모두 3성 시작.
- 시작 기술 4개 해금.
- 기본 절초 3종은 무공 성급과 독립적으로 시작부터 사용 후보.
- 배운 무공 수 하드캡 없음.
- 실제 사용 가능 기술은 수련 자원과 회차 길이로 제한.

## 5.1 습득·중복 계약

- 시작 선택 무공과 회차 중 신규 습득 무공은 모두 3성으로 시작해 1성 패시브와 3성 기술을 즉시 활성화한다.
- 이미 보유한 문파 무공 3성 보상을 다시 고르면 같은 무공의 지정 수련10으로 변환한다.
- 무공 기술은 `category`, `resolution_phase`, `targeting_mode`, `attack.raw_powers/range`, `movement.timing/mode/max_tiles`를 명시한다.
- 5·9성 patch는 허용 필드와 중앙 가격표로 추가 tick을 재계산하며 오타 필드·위조 tick을 거부한다.

## 6. 1~10성 구조

| 성 | 해금 |
|---:|---|
| 1 | 패시브 |
| 3 | 기술 1 |
| 5 | 기술 1 패치 |
| 7 | 기술 2 |
| 9 | 기술 2 패치 |
| 10 | 절초 또는 진의 |

도달 비용은 4:2, 5:3, 6:4, 7:5, 8:6, 9:8, 10:10이며 3→10 총 38이다.

## 7. 세력 정체성 후보

PoC에서는 세력 전체를 제작하지 않고 다음 전투 역할만 검증한다.

| 역할 후보 | 대표 무공 | 공용 계약 연결 |
|---|---|---|
| 연격 검법 | 유운검결 | 순차 합·중단 |
| 호신 외공 | 금강호체공 | 방어도·강건 |
| 대응 검법 | 태극유전검 | 회피·합 보정 |
| 거리 병기 | 추풍창법 | 사거리·이동 |
| 양생 심법 | 청심양생공 | 자원·의료 |
| 경공 | 무영십보 | 이동·회피 |

문파명·세력 수·무기 계통은 역할 중복과 제작 비용을 검증한 뒤 확정한다.

## 8. 시작 무공 후보

| 무공 | 정체성 | 다음 PoC 역할 |
|---|---|---|
| 유운검결 | 연격·이동 | 순차 합·첫 타격 중단 |
| 금강호체공 | 방어·강건 | 전조 보호·방어도 |
| 태극유전검 | 회피·반격 | 타격 회피·조건 반격 |
| 추풍창법 | 거리·이동 | 거리2 운용 |
| 청심양생공 | 자원·의료 | 회복과 장기 체력 관리 |
| 무영십보 | 이동·회피 | 위치 파훼 |

세부 기술·패치·예산은 JSON을 편집한다.

## 9. 슬롯 예산

- 0.05=1tick.
- 목표 20/50/80tick.
- ±5tick 허용.
- 피해·사거리·이동·방어·회피·필중·강건·추가 타격·자원·조건을 중앙 가격표의 `price_id × quantity` ledger로 계산.
- 중앙 가격 변경 시 기존 기술 자동 수정 금지.

## 10. `[의료]`

- 시작 0, 최대 4.
- 청심양생공 1·5·10성에서 각 +1 후보.
- 희귀 회차 사건에서 +1 후보.
- 승리 후 `min(잃은 체력, 2+[의료])`.
- 전투 중 회복·객잔·시장에는 자동 적용하지 않는다.

## 11. 기본 절초·10성 절초·진의

- 기본 절초 3종은 PoC 시작부터 기존 기세5·연속 슬롯·대상 계약으로 사용할 수 있다.
- 무공별 10성 절초는 해당 무공 10성 도달로 해금되며 별도 비무 승리 게이트를 사용하지 않는다.
- 10성은 3슬롯 80tick 기준으로 평가한다.
- 집중 보상32+최소 집중 노드6 경로는 주요 비무5 진입 전 한 무공 10성 도달을 가능하게 한다. 자유 보상24+고효율 노드14 경로는 생성·선택에 따라 `POSSIBLE_NOT_GUARANTEED`다.
- 진의는 항상 보이는 상태·로그 원인을 제공해야 한다.
- 선택적 10성 능력이 없어도 PoC를 정상 완료할 수 있어야 한다.

## 12. 성장 진입 게이트

- 두 번째 기술을 같은 Schema로 만들 수 있다.
- 강화가 단순 피해 정답이 아니라 계획을 바꾼다.
- 5·9성 패치가 새 카드 수를 폭증시키지 않는다.
- AI도 공개 정보만으로 기술을 사용할 수 있다.
- 예산·효과·실패 이유를 복기할 수 있다.

## 13. 검증 기준

JSON 파싱·canonical pretty-print·ID 고유성·정규화 card fields·tick ledger·패치 허용 필드와 재계산·`[의료]` 교차 파일 합계·효과 trigger/condition·습득/중복·3→10 38포인트 두 경로를 정적으로 검사한다. 실제 전투 밸런스·재미·UI 이해는 `UNVERIFIED`다.
