# 십보강호 세력·핵심무공 성장 가설

> 책임: 시작 무공 후보·1~10성 성장·기술 예산·`[의료]` 공급  
> 최신 성장 결정: `docs/decisions/2026-08-02_OBSERVATION_STATS_MASTERY_DECISION.md`  
> 현재 전투 규칙: `docs/02_COMBAT_RULES.md`  
> 데이터 원본: `docs/planning-data/poc_martial_arts.json`  
> 승인 계약: `docs/planning-data/approved_20260802_observation_stats_mastery_contract.json`  
> 상태: 성장 골격은 `APPROVED_PLANNING`, 개별 수치·기술 데이터는 `POC_HYPOTHESIS`

## 1. 현재 상태

프로젝트 코어와 무공서 성장 골격은 사용자 승인 상태다. 런타임에는 아직 최신 스테이터스·기술 요구 조건이 연결되지 않았으며 개별 무공 수치와 기술 예산은 `POC_HYPOTHESIS`다.

현재 T0에는 세력 선택이 없고, 런타임의 공용 절초 3종은 기술 계보 보존 대상으로 남는다. 새 무공·세력 데이터는 공용 전투 계약을 대체하지 않고 확장한다.

## 2. 현행 전투 계약과 연결 원칙

전투 행동은 `기본 행동 + 무공서 기술`로 구성한다. 무공 기술은 공용 필드 `action_slots`, `stamina_cost`, `internal_cost`, `range`, `move_range`, `hits`, `effects`, `sure_hit`을 조합한다. 세력 하나를 위해 별도 라운드·판정 엔진을 만들지 않는다.

효과는 `scope=PER_HIT|ONCE_PER_ACTION`과 `trigger=ON_ACTION_START|ON_ACTION_RESOLVE|ON_CLASH_WIN|ON_EVADE_SUCCESS|ON_HIT|ON_HEALTH_DAMAGE|ON_ACTION_END`를 명시한다.

기술 결과는 다음 세 층으로 구성한다.

1. 항상 적용되는 고정 효과
2. 외공·근골·신법·내공·심안 중 허용된 스테이터스 참조
3. 5·9성에서 해당 기술에 추가되는 스테이터스 임계 효과

이동 거리, 공격 사거리, 관찰량, 행동 슬롯 수, 회피 횟수와 같은 구조적 값은 스테이터스 1점마다 연속 증가하지 않는다. 기술에 명시된 임계 효과에서만 변경한다.

## 3. 다음 PoC 성장 실험

다음 PoC에서는 시작 후보 6개 중 4개를 3성으로 선택한다. 네 중간 구간의 수련·전투·사건 보상에서 분산 투자와 집중 투자를 비교한다. 한 무공에 3→10 총 38 수련포인트를 집중하면 주요 비무 5 전에 10성 절초와 높은 스테이터스 요구를 달성할 가능성이 있어야 하지만, 모든 경로의 보장값으로 만들지는 않는다.

검증 질문:

- 성장 선택이 다음 전투의 거리·순서·자원 계획을 실제로 바꾸는가?
- 단순 피해 상승보다 합·중단·방어·회피·관찰 판단을 강화하는가?
- 짝수 성 보너스와 중간 노드가 기술 요구 스테이터스를 무리 없이 연결하는가?
- 같은 Schema로 두 번째 무공과 두 번째 기술을 만들 수 있는가?

## 3.1 주요 비무 성장 선택

- 자유 수련: 자유6.
- 집중 수련: 지정 무공5 + 자유3, 총 8.
- 문파 전수: 해당 문파 무공을 3성으로 습득. 비교가치 10의 제한 보상이지만 수련포인트로 직접 환산하지 않는다.
- 주요 비무 1~4 집중 수련 32 + 네 중간 구간 최소 집중 수련6 = 38로 주요 비무5 진입 전 10성을 보장 가능한 경로로 만든다.
- 자유 수련24 경로는 고효율 중간 노드14를 골라야 38에 도달한다.
- 중간 노드는 수련포인트뿐 아니라 영구 스테이터스도 제공할 수 있다.

## 4. 장기 보유 구조 가설

- 한 회차에 여러 무공을 익힐 수 있다.
- 해금 기술은 덱·손패·장착 제한 없이 사용 후보가 된다.
- 배운 무공 수 하드캡보다 수련포인트·회차 길이·해금 간격으로 실제 기술 수를 제한한다.
- 정확한 보유 한도는 T1 이후 결정한다.
- 10성 보상은 무공서 고유 `[절초]`로 고정한다. `진의` 선택 구조는 사용하지 않는다.

## 5. 시작 규칙

- 후보 무공 6개 중 4개 선택.
- 모두 3성 시작.
- 시작 무공서의 3성 기술은 요구 영구 스테이터스를 충족한 경우 사용 가능하다.
- 시작 직접 분배와 시작 무공서의 2성 고정 보너스를 포함해 초기 영구 스테이터스를 계산한다.
- 기본 절초 3종은 무공 성급과 독립적으로 시작부터 사용 후보.
- 배운 무공 수 하드캡 없음.
- 실제 사용 가능 기술은 수련 자원, 영구 스테이터스와 회차 길이로 제한.

## 5.1 습득·중복 계약

- 시작 선택 무공과 회차 중 신규 습득 무공은 모두 3성으로 시작한다.
- 1성 패시브와 2성 고정 스테이터스 보너스는 즉시 적용한다.
- 3성 기술은 요구 영구 스테이터스 충족 시 활성화하며, 미달이면 잠긴다.
- 이미 보유한 문파 무공 3성 보상을 다시 고르면 같은 무공의 지정 수련10으로 변환한다.
- 무공 기술은 `category`, `resolution_phase`, `targeting_mode`, `attack.raw_powers/range`, `movement.timing/mode/max_tiles`를 명시한다.
- 5·9성 patch는 기본 강화와 스테이터스 임계 효과를 분리해 기록한다.
- 기술마다 별도 수련도나 수련포인트를 두지 않는다.

## 6. 영구 스테이터스

핵심 스테이터스는 다음 5종이며 주요 운용 범위는 1~15다.

| 스테이터스 | 역할 |
|---|---|
| 외공 | 외가 공격·강공·밀기·방어 파괴 |
| 근골 | 최대 체력·방어도·강건·버티기 |
| 신법 | 이동·보법·회피 |
| 내공 | 최대 내력·내가 효과·호신·회복 |
| 심안 | 관찰·간파·반격·전조 대응 |

영구 스테이터스 획득처:

- 시작 직접 분배
- 무공서 2·4·6·8성의 고정 보너스
- 주요 비무 사이 중간 노드

짝수 성 보너스는 무공서마다 고정한다. 상대도 같은 계약을 사용하므로 비무 전 무공서와 성취를 조사하면 스테이터스 구성의 근거를 확인할 수 있다.

## 7. 1~10성 구조

| 성 | 해금·성장 |
|---:|---|
| 1 | 고유 패시브 |
| 2 | 무공서별 고정 영구 스테이터스 보너스 |
| 3 | 기술 1 획득 판정 |
| 4 | 무공서별 고정 영구 스테이터스 보너스 |
| 5 | 기술 1 기본 강화 + 기술 1 스테이터스 임계 효과 추가 |
| 6 | 무공서별 고정 영구 스테이터스 보너스 |
| 7 | 기술 2 획득 판정 |
| 8 | 무공서별 고정 영구 스테이터스 보너스 |
| 9 | 기술 2 기본 강화 + 기술 2 스테이터스 임계 효과 추가 |
| 10 | 무공서 고유 절초 획득 판정 |

도달 비용은 4:2, 5:3, 6:4, 7:5, 8:6, 9:8, 10:10이며 3→10 총 38이다.

무공서 수련은 스테이터스 요구로 막히지 않는다. 스테이터스 요구는 3·7·10성 신규 기술에만 둔다.

- 3성 기술: 낮은 요구치
- 7성 기술: 중간 요구치
- 10성 절초: 높은 요구치
- 한 기술의 요구 스테이터스는 최대 2종

무공서가 요구 성에 도달했지만 스테이터스가 부족하면 기술만 잠긴다. 무공서는 계속 수련할 수 있으며, 이후 영구 스테이터스를 충족하면 별도 비용 없이 자동으로 사용 가능해진다. 한번 터득한 기술은 전투 중 일시 스테이터스 감소로 다시 잠기지 않는다.

5·9성 기본 강화는 성취 도달 즉시 적용한다. 스테이터스 미달 시 해당 기술의 임계 효과만 비활성화하고, 이후 조건 충족 시 자동 활성화한다.

## 8. 세력 정체성 후보

PoC에서는 세력 전체를 제작하지 않고 다음 전투 역할만 검증한다.

| 역할 후보 | 대표 무공 | 공용 계약 연결 |
|---|---|---|
| 연격 검법 | 유운검결 | 순차 합·중단 |
| 호신 외공 | 금강호체공 | 방어도·강건 |
| 대응 검법 | 태극유전검 | 회피·합 보정 |
| 거리 병기 | 추풍창법 | 사거리·이동 |
| 양생 심법 | 청심양생공 | 자원·의료 |
| 경공 | 무영십보 | 이동·회피 |

문파명·세력 수·무기 계통은 역할 중복과 제작 비용을 검증한 뒤 확정한다.

## 9. 시작 무공 후보

| 무공 | 정체성 | 다음 PoC 역할 |
|---|---|---|
| 유운검결 | 연격·이동 | 순차 합·첫 타격 중단 |
| 금강호체공 | 방어·강건 | 전조 보호·방어도 |
| 태극유전검 | 회피·반격 | 타격 회피·조건 반격 |
| 추풍창법 | 거리·이동 | 거리2 운용 |
| 청심양생공 | 자원·의료 | 회복과 장기 체력 관리 |
| 무영십보 | 이동·회피 | 위치 파훼 |

세부 기술·패치·예산과 짝수 성 스테이터스 보너스는 JSON을 편집한다.

## 10. 슬롯 예산

- 0.05=1tick.
- 목표 20/50/80tick.
- ±5tick 허용.
- 피해·사거리·이동·방어·회피·필중·강건·추가 타격·자원·조건을 중앙 가격표의 `price_id × quantity` ledger로 계산.
- 중앙 가격 변경 시 기존 기술 자동 수정 금지.
- 5·9성 스테이터스 임계 효과도 별도 가격표와 검증 가능한 ledger를 가져야 한다.

## 11. `[의료]`

- 시작 0, 최대 4.
- 청심양생공 1·5·10성의 기존 후보값은 최신 1~10성 계약에 맞춰 재배치가 필요하다.
- 희귀 회차 사건에서 +1 후보.
- 승리 후 `min(잃은 체력, 2+[의료])`.
- 전투 중 회복·객잔·시장에는 자동 적용하지 않는다.

## 12. 기본 절초·10성 절초·진의

- 기본 절초 3종은 PoC 시작부터 기존 기세5·연속 슬롯·대상 계약으로 사용할 수 있다.
- 무공별 10성 절초는 해당 무공 10성 도달과 높은 영구 스테이터스 요구 충족으로 해금된다.
- 별도 비무 승리 게이트는 사용하지 않는다.
- 10성 절초는 3슬롯 80tick 기준으로 평가한다.
- 집중 보상32+최소 집중 노드6 경로는 주요 비무5 진입 전 한 무공 10성 도달을 가능하게 한다.
- 절초 스테이터스 요구까지 포함한 실제 달성 가능성은 시작 분배·짝수 성 보너스·중간 노드를 합쳐 검증한다.
- 선택적 10성 능력이 없어도 PoC를 정상 완료할 수 있어야 한다.
- `진의` 선택 구조는 폐기되었으며 10성 보상은 절초로 고정한다.

## 13. 성장 진입 게이트

- 두 번째 기술을 같은 Schema로 만들 수 있다.
- 강화가 단순 피해 정답이 아니라 계획을 바꾼다.
- 5·9성 패치가 새 카드 수를 폭증시키지 않는다.
- 짝수 성 보너스가 무공 정체성을 강화하고 무조건적인 범용 최적해가 되지 않는다.
- 3·7성 요구치가 정상 경로에서 과도한 잠금을 만들지 않는다.
- 10성 절초 요구치는 집중 빌드에서 달성 가능하지만 분산 빌드의 자동 보상이 아니다.
- AI도 공개 정보만으로 기술을 사용할 수 있다.
- 예산·효과·실패 이유를 복기할 수 있다.

## 14. 검증 기준

정적 검사 항목:

- JSON 파싱·canonical pretty-print·ID 고유성
- 정규화 card fields·tick ledger·패치 허용 필드와 재계산
- `[의료]` 교차 파일 합계
- 효과 trigger/condition
- 습득/중복·3→10 총 38포인트 경로
- 2·4·6·8성 고정 스테이터스 보너스 존재
- 3·7·10성 기술 요구 스테이터스 최대 2종
- 기술 잠금 상태에서도 무공서 수련 지속
- 영구 스테이터스 충족 시 자동 활성화
- 5·9성 기본 패치와 임계 효과 분리
- 10성 보상에 `진의` 선택이 남아 있지 않음
