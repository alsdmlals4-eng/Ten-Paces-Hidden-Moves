# 십보강호 세력·핵심무공·심법 성장 가설

> 책임: 시작 무공 후보·1~10성 성장·기술 예산·`[의료]` 공급  
> 데이터 원본: `docs/planning-data/poc_martial_arts.json`  
> 상태: T1 이후 가설 원본이지만 다음 PoC의 성장 표본을 포함한다.

## 1. 현재 상태

프로젝트 코어가 사용자 승인된 상태에서, 다음 PoC용 성장 데이터를 작성했다. 런타임에는 연결되지 않았으며 모두 `POC_HYPOTHESIS`다.

## 2. 현행 전투 계약과 연결 원칙

무공은 공용 필드 `action_slots`, `stamina_cost`, `internal_cost`, `range`, `move_range`, `hits`, `effects`, `sure_hit`을 조합한다. 세력 하나를 위해 별도 라운드·판정 엔진을 만들지 않는다.

효과는 `scope=PER_HIT|ONCE_PER_ACTION`, `trigger=ON_HIT|ON_HEALTH_DAMAGE`를 명시한다.

## 3. 시작 규칙

- 후보 무공 6개 중 4개 선택.
- 모두 3성 시작.
- 시작 기술 4개 해금.
- 배운 무공 수 하드캡 없음.
- 실제 사용 가능 기술은 수련 자원과 회차 길이로 제한.

## 4. 1~10성 구조

| 성 | 해금 |
|---:|---|
| 1 | 패시브 |
| 3 | 기술 1 |
| 5 | 기술 1 패치 |
| 7 | 기술 2 |
| 9 | 기술 2 패치 |
| 10 | 절초 또는 진의 |

도달 비용은 4:2, 5:3, 6:4, 7:5, 8:6, 9:8, 10:10이며 3→10 총 38이다.

## 5. 시작 무공 후보

| 무공 | 정체성 | 다음 PoC 역할 |
|---|---|---|
| 유운검결 | 연격·이동 | 순차 합·첫 타격 중단 |
| 금강호체공 | 방어·강건 | 전조 보호·방어도 |
| 태극유전검 | 회피·반격 | 타격 회피·조건 반격 |
| 추풍창법 | 거리·이동 | 거리2 운용 |
| 청심양생공 | 자원·의료 | 회복과 장기 체력 관리 |
| 무영십보 | 이동·회피 | 위치 파훼 |

세부 기술·패치·예산은 JSON을 편집한다.

## 6. 슬롯 예산

- 0.05=1tick.
- 목표 20/50/80tick.
- ±5tick 허용.
- 피해·사거리·이동·방어·회피·필중·강건·추가 타격·자원·조건을 중앙 가격표로 계산.
- 중앙 가격 변경 시 기존 기술 자동 수정 금지.

## 7. `[의료]`

- 시작 0, 최대 4.
- 청심양생공 1·5·10성에서 각 +1 후보.
- 희귀 회차 사건에서 +1 후보.
- 승리 후 `min(잃은 체력, 2+[의료])`.
- 전투 중 회복·객잔·시장에는 자동 적용하지 않는다.

## 8. 절초·진의 가설

10성은 3슬롯 80tick 기준으로 평가한다. 절초는 기세5 예약 계약을 재사용하고, 진의는 항상 보이는 상태·로그 원인을 제공해야 한다. 선택적 상위 능력이 없어도 PoC를 정상 완료할 수 있어야 한다.

## 9. 성장 진입 게이트

- 두 번째 기술을 같은 Schema로 만들 수 있다.
- 강화가 단순 피해 정답이 아니라 계획을 바꾼다.
- 5·9성 패치가 새 카드 수를 폭증시키지 않는다.
- AI도 공개 정보만으로 기술을 사용할 수 있다.
- 예산·효과·실패 이유를 복기할 수 있다.

## 10. 검증 기준

JSON 파싱·ID 고유성·패치 참조·예산 ±5tick·`[의료]` 상한을 정적으로 검사한다. 실제 전투 밸런스·재미·UI 이해는 `UNVERIFIED`다.
