## 2. 성장 설계 원칙

- 성장은 거리·순서·대응·자원 계획의 선택지를 확장해야 하며 잘못된 계획을 자동으로 구제하면 안 된다.
- 전투 행동은 `기초 행동 + 현재 해금된 무공 기술`로 구성한다.
- 무공서 자체를 전투 수에 배치하지 않는다.
- 기술은 고정 효과, 허용된 능력치 배수, 5·9성 임계 효과를 분리한다.
- 이동거리·사거리·관찰량·행동 슬롯·회피 횟수·전조 수 같은 구조값은 능력치 1점마다 연속 증가하지 않는다.
- 모든 기술이 주·보조 능력치를 자동으로 동시에 배수에 사용하는 것은 아니다.
- 기술마다 `scope`, `trigger`, 비용, 대상, 사거리, 피해 단위와 효과 예산을 명시한다.

## 3. 핵심 스테이터스

| 스테이터스 | 역할 |
|---|---|
| 외공 `EXTERNAL` | 외가 공격·강공·무기 위력·방어 파괴 |
| 근골 `CONSTITUTION` | 최대 체력·방어도·강건·버티기 |
| 신법 `MOVEMENT` | 이동·보법·회피·위치 조정 |
| 내공 `INTERNAL` | 최대 내력·내가 효과·호신·회복 |
| 심안 `INSIGHT` | 관찰·간파·반격·전조 대응 |

- 디자인 하드캡은 없다.
- 기존 1~15는 초기 밸런스 검증 구간이다.
- 합법적인 15 초과값을 절단·소실·재분배하지 않는다.
- 실제 영구값을 기술 요구치와 공식에 사용한다.
- 회피율·피해 감소율·발동 확률처럼 규칙을 무효화할 수 있는 파생 효과는 점근 곡선·효과 상한·임계 효과로 보호한다.

## 4. 시작 규칙

```text
기본 2 × 5종 = 10
+ 자유 분배 6 = 16
+ 선택 시작 무공 4개의 2성 주 능력치 +1 = 20
```

- 후보 무공 6개 중 4개를 3성으로 선택한다.
- 자유 분배 6점을 먼저 모두 사용한다.
- 직접 분배 단계의 각 능력치는 2~6이다.
- 이후 무공 보너스는 6에서 잘리지 않는다.
- 최종 시작 총합은 20, 평균은 4다.
- 3성 첫 기술은 해당 무공의 주 영구 능력치 4를 요구한다.
- `[추천 배분]`은 선택한 네 첫 기술의 최소 해금 기준선을 보여주되 강제하지 않는다.
- 일부 기술을 잠근 전문화 배분은 경고 뒤 허용한다.
- 기본 절초 3종은 무공 성급과 독립적으로 시작부터 사용 후보다.

## 7. 잠금·자동 활성화

- 무공서 수련은 능력치 요구로 막히지 않는다.
- 요구치 미달 시 해당 기술 또는 절초만 `LOCKED_STAT_REQUIREMENT`가 된다.
- 무공 성급·패시브·짝수 성 보너스·이미 해금된 기술·5/9성 기본 강화는 유지한다.
- 영구 주 능력치 요구치를 충족하면 추가 수련포인트 없이 자동 활성화한다.
- 임시 버프는 해금 판정에 사용하지 않는다.
- 한번 활성화된 기술·절초는 전투 중 임시 능력치 감소로 다시 잠기지 않는다.
- 보조 능력치는 3·7·10성 해금 요구가 아니다.

## 8. 습득·중복·저장 계약

- 시작 선택 무공과 회차 중 신규 습득 무공은 3성으로 시작한다.
- 1성 패시브와 2성 주 +1은 회차당 최초 1회만 적용한다.
- 이미 보유한 무공의 3성 습득 보상을 다시 고르면 같은 무공의 지정 수련 10으로 변환한다.
- 중복 습득·저장 재로드·수련 변환으로 성취 보너스를 재지급하지 않는다.
- 짝수 성 보너스의 idempotent 키는 `회차ID + 무공ID + 성취 milestone`이다.
- 각 3·5·7·9·10성 전환점은 안정 필드 `skill_milestone`으로 기록한다.

효과 시점 예:

```text
ON_ACTION_START
ON_ACTION_RESOLVE
ON_CLASH_WIN
ON_EVADE_SUCCESS
ON_HIT
ON_HEALTH_DAMAGE
ON_ACTION_END
```

- 효과 scope는 `PER_HIT` 또는 `ONCE_PER_ACTION`을 명시한다.
- 기술 작성 순서는 구조·비용→태그→고정치→주/보조 배수→5/9성 patch·임계 효과다.
- 슬롯 기술 예산은 1수20틱·2수50틱·3수80틱이며 기본 허용 편차는 ±5틱이다.
- 최대 사거리 총비용은 사거리1=0틱·2=10틱·3=25틱·4=40틱이다.
- 배수 기준 스테이터스는 4, 작성 단위는 0.25다.
- 개별 기술의 실제 배수·임계값은 후속 Decision과 ledger가 필요하다.

## 10. PoC 성장 실험

주요 비무 성장 선택:

- 자유 수련: 자유 6.
- 집중 수련: 지정 무공 5 + 자유 3, 총 8.
- 문파 전수: 해당 문파 무공을 3성으로 습득하며 수련포인트로 직접 환산하지 않는다.
- 주요 비무1~4 집중 수련 32 + 네 중간 구간 최소 집중 수련 6 = 38로 주요 비무5 전 한 무공 10성 도달 경로를 검증한다.
- 자유 수련 24 경로는 고효율 중간 노드 14가 추가로 필요하다.
- 중간 노드가 영구 스테이터스를 제공할지와 정확한 지급량은 다음 GrillMe 전 `TBD`다.

## 11. `[의료]`와 경로 성장

`[의료]`는 회복·상태 안정·장기 체력 관리 역할이다. 영구 능력치와 수련포인트 공급을 자동으로 겸하지 않는다. 중간 노드 보상은 다음을 분리해 설계한다.

- 회복
- 수련포인트
- 영구 스테이터스
- 상대 정보
- 사건·재화

영구 스테이터스 보상은 핵심 재미와 10성 요구치에 직접 영향을 주므로 사용자 GrillMe 승인 전 확정하지 않는다.
