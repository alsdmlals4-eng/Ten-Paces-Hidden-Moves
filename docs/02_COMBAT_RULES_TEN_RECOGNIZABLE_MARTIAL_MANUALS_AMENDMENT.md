# 초기 무공서 10권 전투 해결 보완 정본

> Decision: `TEN-DEC-20260806-TEN-RECOGNIZABLE-MARTIAL-MANUALS-FULL-GROWTH-01`  
> 구현 권위: `PLANNING_ONLY`

## 공통 원칙

- 상태 생성은 그 상태를 참조하는 공격·회복·반격보다 먼저 처리한다.
- 이동 뒤 공격은 반드시 현재 위치에서 사거리를 다시 확인한다.
- 다단 공격은 각 타격 결과를 순차 확정한다.
- 9성은 기술2에 정확히 하나의 효과만 추가한다.
- 주능력치와 보조능력치 권수 분포는 검사하지 않는다.
- 능력치 계산은 승인된 문파·무학·동작·피해 방식 적합성만 따른다.

## 1. 화산파 매화검결

### 이십사수매화검법

```text
1칸 접근
→ 독립 검격 1
→ 독립 검격 2
→ 독립 검격 3
→ 실제 체력 피해 2회 이상인지 확인
→ 조건 충족 시 1칸 추격
→ 사거리 재확인
→ 결착검
→ 종료 위치 확정
```

실제 24회 공격하지 않는다. 방어가 체력 적중을 막으면 연계 조건을 막을 수 있다.

## 2. 소림사 나한금강공

주능력치는 `외공`, 보조능력치는 `내공`이다. 대력금강장과 여래신장은 원거리 장풍이 아니라 짧은 도달 거리의 외공 장격이다.

### 금강공 강건 순서

```text
공격 또는 전조 시작
→ 방어·강건 생성
→ 중단 판정
→ 강건이 현행 규칙으로 중단을 막았으면 동작 계속
→ 강건이 없거나 막지 못하면 정상 중단 가능
```

### 여래신장

```text
방어·강건 생성
→ 이번 행동의 실제 방어 손실 기록 시작
→ 실행 시 짧은 도달 거리 재확인
→ 외공 기반 기본 장격
→ 기록 방어 손실을 상한 내 추가 피해로 전환
→ 기록 종료
```

무적·전면 반사·절대 중단 면역·상한 없는 방어 비례 피해를 허용하지 않는다.

## 3. 무당파 태극검결

### 태극혜검

```text
태극 검세 준비
→ 대응 시간 내 공격 접촉
→ 심안 기반 특별 합
→ 합 승리 시 상대 공격 흘리기
→ 이동 전 위치에서 반격
→ 내력·방어 안정화
```

상대가 대응 시간에 공격하지 않거나 합에서 승리하면 반격은 발생하지 않는다.

## 4. 양가 양가창결

### 회마창

```text
첫 찌르기
→ 결과 처리
→ 2칸 후퇴
→ 현재 위치에서 사거리 재확인
→ 사거리 유효 시 회마 찌르기
→ 결과 처리
```

후퇴 뒤 사거리가 끊기면 두 번째 공격은 실패한다.

## 5. 화산파 자하심법

### 자하신공

```text
첫 전조 실행
→ 전투당 사용권 즉시 소모
→ 시작 체력·기력·내력 기록
→ 내력 회복
→ 기력 회복
→ 강건·방어 안정화
→ 시작 시 저자원 조건을 만족했다면 제한된 체력 회복
→ 실행 완료 시 절초기세 1 회복
```

- 첫 전조 후 중단되어도 사용권을 돌려주지 않는다.
- 절초기세는 완료 시에만 회복한다.
- 최대치 초과 저장·완전 회복·전투 초기화·사용권 재충전을 허용하지 않는다.

## 6. 소요파 소요보결

### 능파미보

```text
회피 부여
→ 회피 성공
→ 이동 전 위치에서 원래 공격자 반격
→ 반격 결과 처리
→ 공격자 반대 방향으로 최대 3칸 이동
→ 준비 획득
```

반격이 실패하거나 대상이 쓰러져도 합법 이동 칸이 있으면 이동 단계는 수행한다.

## 7. 개방 강룡장결

주능력치는 `내공`, 보조능력치는 `근골`이다. 견룡재전·비룡재천·항룡십팔장의 핵심 피해와 합 위력은 중후한 양강 내력과 방출형 장력을 표현한다.

### 항룡십팔장

```text
1칸 접근
→ 내공 기반 장력 합
→ 합 승리 시 방어 파괴
→ 체력 피해
→ 2칸 밀치기
```

사전 방어 손실을 축적하지 않으며 공격 전에 강건을 자동 획득하지 않는다. 내공 주능력치라도 자동 필중·자동 합 승리·사거리 무시는 없다.

## 8. 사천당문 천기암기록

### 만천화우

```text
사거리 재확인
→ 암기 1 독립 판정·결과 확정
→ 암기 2 독립 판정·결과 확정
→ 암기 3 독립 판정·결과 확정
→ 암기 4 독립 판정·결과 확정
→ 행동 종료
```

독·출혈·무작위 타수·무작위 표적은 별도 승인 전 추가하지 않는다.

## 9. 하북팽가 팽가도결

### 오호단문도

```text
첫 파문도
→ 방어 처리
→ 두 번째 파문도
→ 방어 처리
→ 상대 방어 0 확인
→ 조건 충족 시 결착도
```

실제 체력 적중이 아니라 방어 파괴가 후속 도격을 연다.

## 10. 남궁세가 창궁무애검법

### 제왕검형

```text
제왕검세 전조
→ 실행 시 거리 재확인
→ 내공 기반 특별 검압 합
→ 합 승리 시 방어 파괴
→ 단발 결착검
```

화산식 연격·무당식 공격 흘리기·자동 합 승리를 추가하지 않는다.

## 능력치 적용 기준

| 행동 성격 | 우선 검토 능력치 |
|---|---|
| 방출형 장력·장풍·검강 | 내공 |
| 근접 장격·권격·도격·창격 | 외공 |
| 무거운 자세·충격 지지·육체 안정 | 근골 |
| 검로·방향·빈틈·정밀 조준 | 심안 |
| 이동·회피·변위·빠른 연격 | 신법 |

이 표는 권수 분배표가 아니다. 무공서별 승인된 능력치 조합이 우선하며, 예외는 무학과 해결 순서로 설명한다.
