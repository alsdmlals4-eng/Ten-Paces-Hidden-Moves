## 제작 기준과 한계

공통 장면은 안개 낀 산수의 두 성인 검객, 왼쪽 근경의 플레이어와 오른쪽 원경의 상대가 대각선으로 대치하는 구성이다. 얼굴·복장·크기·거리·지형을 확정하는 설정화가 아니라 먹선·채색·명암·묘사 방식을 고르는 자료다. 시안마다 구도의 세부 차이가 있으므로 거리나 인물 크기를 규칙으로 해석하지 않는다.

사용자가 첨부한 대각선 대치 화면은 구도 참조로만 사용했다. 8~10번 최종 수정본은 같은 장면 설명으로 새로 생성했다. 원본에 있던 UI 문구와 수치, 타 작품의 캐릭터를 프로젝트 정본에 채택하지 않는다.

실제 게임의 1차원 논리 전장, 거리, 3수/3수/4수, 공개/비공개 정보 및 게임 규칙은 이번 탐색에서 변경하지 않았다. 화풍 선택 후 캐릭터와 배경 분리, 전투 UI, 무공 선택 화면, 모션 및 가독성을 검증하는 후속 작업을 수행한다.

1. 범위·화풍 검토: 최신 요청을 화풍 선택 단계로 한정하고 10개 비교본을 생성했다. 초기 8·9·10번은 다른 시안과 차이가 작아 인물의 선·여백·입체감을 각각 강화했다. 코어 규칙·승인 자산·게임 런타임·기존 사용자 코멘트는 수정하지 않았다.
2. 전달 검토: 10개 번호·이름·파일·생성 프롬프트의 대응, 원본 복사 후 해시, 이미지의 전신·무기·대각선 대치 여부를 확인했다. IAB에서 10개 이미지가 모두 실제 1672×941로 로드되고 가로 넘침이 없음을 확인했다. 모아 보기, 8번 확대, 다음 버튼으로 9번, 방향키로 10번, Esc로 목록 복귀를 실행했다. 현재 671px 미리보기 검증이며 다른 크기·실기기 전체 검수를 주장하지 않는다.

- 이미지 생성 및 육안 확인: 10개 완료.
- 파일 해시 및 브라우저 표시: 10/10 확인, 잘못된 이미지 연결 없음.

- 실제 Godot 연결·런타임·Android·사람 플레이: NOT_RUN, 이번 탐색 범위 밖.
