# 검로에 먹을 싣다 · 움직임 시안 02

상태: **OFFLINE_REVISION_CANDIDATE / 사용자 최종 검토 전**. 사용자가 v1의 멋과 무협 분위기가 부족하다고 평가해 다시 제작한 후보다. 화풍 8번의 인물·선, 3번의 대비, 9번의 안개라는 선택은 유지한다.

## 핵심 재미와 이번 수정

사용자 확정 목표는 **수싸움(행동설계)**과 **무협 액션을 관람하며 멋을 느끼는 연출(전투진행)**이다. 책임 원본은 [의도 Decision](../../../../decisions/2026-09-24_INK_WUXIA_STYLE_AND_FLOW.md)이다. 자동 재생이 성공했다는 이유만으로 이 두 재미를 통과 처리하지 않는다.

인물을 더 크게 보여주고, 낮게 파고드는 진입과 비틀어 베는 자세, 받아친 힘을 돌려주는 교환을 새 원화로 구성했다. 검의 궤적에는 거친 붓자국을 붙이고 결정적인 접점에서 짧은 근접 원화 컷을 넣었다. 하단은 결과 한 줄로 줄여 인물과 검을 읽는 시간을 확보했다. 정적 → 진입 → 검의 교환 → 결정 접점 → 공격 → 회수의 6.4초 구성이다.

## 원화와 제작 방식

새 원화는 내장 이미지 도구에서 제작했다. `hero-clash.png`(접점 원화), 검객별9자세의 투명 PNG 2개(현재 사용: 플레이어8자세·상대7자세), `background.png`(발을 디딜 넓은 바닥으로 재교정), `ink-brush.png`(실제 붓자국 질감)를 사용한다. [prompts.json](prompts.json)에 프롬프트와 참조 역할을 보존한다. 외부 게임의 이미지·영상·음악을 자산으로 사용하지 않았다.

움직임은 키 자세 전환, 위치·회전 보간, 약한 옷자락 변형, 검끝을 따라 휘어지는 붓 질감, 접점 강조와 카메라로 합성했다. 2.50~2.70초에는 별도 근접 원화가 나온다. **모든 중간 동작을 새로 그리거나 관절을 완성한 최종 애니메이션은 아니다.** 실제 Godot 녹화도 아니다. 세 차례의 검 교환은 한 합의 연출이며 추가 피해·반격 판정을 만들지 않는다.

## 조사와 적용 경계

앞 [v1 조사](../clash-v1/README.md)의 ProjectMoon 공식 합 자료·Library of Ruina 퍼블리셔 설명·Nine Sols 개발사 설명은 같은 의사결정 범위라 재사용했다. 최신 사용자 피드백에 따라 액션 자세와 안무의 근거를 추가 조사했다.

[S-GAME 공식 Phantom Blade Zero 제작 설명](https://pbz.s-game.com/en-US/news/year-of-the-snake-trailer/)은 2025-01-21 공개 자료이며 무술가의 모션 캡처와 액션 안무가의 참여, 이어지는 실제 전투 시퀀스를 설명한다. 2026-09-24 본문을 확인했다. 여기서 **효과를 더하기 전에 몸의 중심·발의 접지·동작의 인과를 설계한다**는 원칙을 이번 작업에 적용한 것은 우리의 제작 판단이다. 영상 전체를 시청하거나 프레임 시간을 측정했다고 주장하지 않으며 적 구성·무기·캐릭터·게임 규칙은 복제하지 않는다.

## 검증과 현재 한계

기준 main `ec7240633e21aec448f9426781a7acbf294aa748`, 수정 시작 HEAD `f9ca2435f5504e71f479d859cfd3cf4d1da7950f`. Work Mode BUILD/VISUAL_PROTOTYPE + REVIEW. Skill: project workflow router / 승인 범위 continuation; imagegen / built-in reference generation. `CURRENT_SOURCE_RELEVANCE_CHECK`는 기존 공식 근거 재사용 + S-GAME 공식 제작 설명 추가 확인, `FEASIBLE`은 기존 생성·로컬 합성·제한형 미리보기 도구로 실제 파일 제작까지 확인했다.

- [render-check.json](render-check.json): 실제 192프레임과 각각의 해시, 수동 지정한 검손잡이·검끝 선의 1.36/1.93/2.50초 교차. 좌표 검사는 실제 Godot 판정이나 신체 동작의 자연스러움을 증명하지 않는다.
- [media-check.json](media-check.json): GIF를 다시 디코딩해 128프레임, 6,400ms, 반복과 전장 영역의 128개 서로 다른 프레임을 확인했다. MP4/GIF/포스터 SHA256과 크기를 기록한다.
- 이전 후보에서 이미 수행한 전체 검토2회는 초기화하지 않는다. 이번 사용자 결함에 대한 집중 검토에서 발이 떠 보이는 배경, 매끈한 선처럼 보이는 먹 효과, 인접 자세의 옷 조각, 배경과 겹쳐 읽기 어려운 상단 문구, 과도한 GIF 용량을 발견해 교정했다. 원화는 실제 생성 도구로 수정하고 표시용 자산 절단·연출은 별도 합성 코드가 소유한다.

- IAB에서 최종 MP4 6.4초/1280×720 로드와 실제 재생, 0.5배 시간 진행(0.112→4.709초)을 확인했다. GIF 800×450 로드·서로 다른 자세와 결과 표시, 전환 시 영상 숨김/정지와 GIF 단독 표시를 확인했다. 약656px 창에서 가로 넘침이 없다. 넓은 화면·실기기 전체 검수를 새로 했다는 뜻은 아니다.

**미검증:** 사용자가 느끼는 멋·자연스러움·반복 관람의 재미, 최종 모션 승인, 실제 판정과 동기화한 Godot 구현, 다른 무공/회피/중단 장면, Android, 사운드, 출시 성능. v1의 사용자 품질 거절을 기술 검증으로 덮어쓰지 않는다. 현재 미리보기의 결과 문구는 이 한 상황의 연출 설명이다.
