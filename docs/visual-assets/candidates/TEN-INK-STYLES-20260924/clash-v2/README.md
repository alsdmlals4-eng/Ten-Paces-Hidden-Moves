# 검로에 먹을 싣다 · 움직임 시안 02

상태: **USER_APPROVED_ART_AND_CHOREOGRAPHY_BASELINE / 하단 판정 표시 추가**. 사용자는 “오 멋지다 잘만들었는데?”에 이어 “좋아 기준으로잡아줘”로 v2를 후속 화풍·합 연출의 기준으로 확정했다. v1을 다시 제작한 이 방향의 승인과 모든 기술의 최종 모션·게임 적용 완료는 구분한다. 화풍 8번의 인물·선, 3번의 대비, 9번의 안개라는 선택은 유지한다.

## 핵심 재미와 이번 수정

사용자 확정 목표는 **수싸움(행동설계)**과 **무협 액션을 관람하며 멋을 느끼는 연출(전투진행)**이다. 책임 원본은 [의도 Decision](../../../../decisions/2026-09-24_INK_WUXIA_STYLE_AND_FLOW.md)이다. 자동 재생이 성공했다는 이유만으로 이 두 재미를 통과 처리하지 않는다.

인물을 더 크게 보여주고, 낮게 파고드는 진입과 비틀어 베는 자세, 받아친 힘을 돌려주는 교환을 새 원화로 구성했다. 검의 궤적에는 거친 붓자국을 붙이고 결정적인 접점에서 짧은 근접 원화 컷을 넣었다. 후속 요청에 따라 전장과 인물 크기를 유지하고 하단에 양측 행동·소모 자원·비교 위력·실제 체력과 기세 변화를 담은 종이 결과판을 추가했다. 정적 → 진입 → 검의 교환 → 결정 접점 → 공격 → 회수의 6.4초 구성이다.

## 원화와 제작 방식

새 원화는 내장 이미지 도구에서 제작했다. `hero-clash.png`(접점 원화), 검객별9자세의 투명 PNG 2개(현재 사용: 플레이어8자세·상대7자세), `background.png`(발을 디딜 넓은 바닥으로 재교정), `ink-brush.png`(실제 붓자국 질감)를 사용한다. [prompts.json](prompts.json)에 프롬프트와 참조 역할을 보존한다. 외부 게임의 이미지·영상·음악을 자산으로 사용하지 않았다.

움직임은 키 자세 전환, 위치·회전 보간, 약한 옷자락 변형, 검끝을 따라 휘어지는 붓 질감, 접점 강조와 카메라로 합성했다. 2.50~2.70초에는 별도 근접 원화가 나온다. **모든 중간 동작을 새로 그리거나 관절을 완성한 최종 애니메이션은 아니다.** 실제 Godot 녹화도 아니다. 세 차례의 검 교환은 한 합의 연출이며 추가 피해·반격 판정을 만들지 않는다.
