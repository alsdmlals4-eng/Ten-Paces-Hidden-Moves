## 효과 trigger 정본

```text
ON_ACTION_START
→ ON_CLASH_WIN
→ ON_EVADE_SUCCESS
→ ON_HIT / ON_HEALTH_DAMAGE
→ 중단·전투 불능
→ ON_ACTION_END
```

공격 타격이 없는 행동은 정상 실행 시 `ON_ACTION_RESOLVE`를 사용한다. `PER_HIT`은 적중 계열에만 사용하며 행동 단위 trigger는 `ONCE_PER_ACTION`만 허용한다.

## 절초·성장 정본

- 기본 절초 3종: PoC 시작부터 기존 기세5·연속 슬롯·대상 조건으로 사용 가능.
- 무공 10성 절초: 해당 무공 10성 도달로 해금.
- 전역 비무 번호 해금: 없음.
- 3→10 총비용: 38 수련포인트.
- 집중 경로: 주요 비무 5 전에 10성 도달 가능성이 있으나 모든 경로·등급·선택에서 보장하지 않음.
- 분산 경로: 여러 무공의 중간 성급을 선택할 수 있으며 10성 도달을 포기할 수 있음.

## 검증 추가

- 비공격 행동에 `ON_HIT`을 넣으면 실패.
- `[필중]`·합 보정이 `ON_ACTION_START`가 아니면 실패.
- 비무 5에 `progression_unlock=ultimate_access`를 재도입하면 실패.
- 기본 절초 시작 가용성 또는 집중 도달성 38포인트가 누락되면 실패.
- PoC subset·스테이지·노드·예산·ID·의료 기존 검사를 유지.

## 남은 미검증

- 38포인트가 실제 생성 지도와 플레이 성과에서 얼마나 자주 가능한지.
