# HTML PoC 전투 규칙 교정 결정

- Decision ID: `TEN-DEC-20260804-HTML-POC-COMBAT-CORRECTIONS-01`
- 승인일: 2026-08-04
- 상태: `CURRENT_APPROVED_PLANNING / HTML_POC_IMPLEMENTED`
- 적용 범위: 전투 공통 규칙과 HTML 기술1 검증 PoC
- 기존 충돌 표현: 준비 내력1 비용, `general` 혼합 순차 처리, 묶음별 내력·절초기세 회복 누락, 회피 성공 기세 누락

## 1. 준비

- `[준비]`는 1수를 소비하는 무비용 행동이다.
- 기력·내력·절초기세를 소비하지 않는다.
- 슬롯을 사용해 다음 비이동 행동을 강화한다는 의미를 유지한다.
- 이동·보법은 준비 상태를 소비하지 않는다.
- 다음 공격의 원공격력 +2와 강건1, 준비된 명상의 추가 효과 등 기존 강화 효과는 유지한다.

## 2. 한 수의 해결 순서

```text
대응 → 속공 → 이동 → 공격
```

- 같은 단계의 양측 유효 공격은 기존 합 규칙으로 처리한다.
- 마지막 `[공격]` 단계에 공격과 명상·준비·관찰·자원 행동이 함께 있으면 공격과 합을 먼저 정산한다.
- 공격으로 실제 체력 피해를 받고 강건으로 막지 못하면 아직 실행되지 않은 같은 수의 명상·준비·관찰·자원 행동은 중단된다.
- 따라서 명상과 상대 공격이 같은 수라면 피격·중단 판정 뒤 살아남은 경우에만 명상 회복이 적용된다.

## 3. 공격 정보 표시

- 모든 공격 선택 항목은 `피해`와 `거리`를 반드시 표시한다.
- 연격은 총합으로 뭉개지 않고 피해 단위 순서를 표시한다.
- 유운삼첩 기준 표시는 `거리1 · 피해 4→3→3 · 순차 연격`이다.
- UI는 가능한 한 전투 계약의 실제 계산 결과에서 공격 설명을 생성해 수기 문구 누락을 방지한다.

## 4. 묶음 시작 자동 회복

각 행동묶음 전환 시 양측에 다음을 적용한다.

```yaml
internal_gain_per_bundle: 1
ultimate_momentum_gain_per_bundle: 1
resource_cap_applies: true
```

- 내력과 절초기세는 각자의 최대값을 넘지 않는다.
- 세 번째 묶음 종료 뒤 다음 라운드 첫 묶음으로 전환할 때도 동일하게 적용한다.
- 기존 라운드 시작 기력 회복은 별도 규칙으로 유지한다.

## 5. 절초기세 획득

- 실제 회피 성공 시 절초기세 +1.
- 합 승리 시 절초기세 +1.
- 합 승리는 기존대로 한 공격 행동에서 여러 피해 단위 합을 이겨도 행동당 최대 +1이다.
- 회피 성공은 실제 피해 단위를 무효화한 사건에만 적용한다. 회피 횟수 획득만으로는 기세를 얻지 않는다.
- 모든 획득은 최대5 상한을 적용한다.
