## 연결 방식

각 결정 행은 고유 ID와 `연결 프로필`을 가진다. 연결 프로필은 다음 필드를 소유한다.

- 주장 유형
- 근거
- 영향 책임 원본
- 적용 빌드·Commit
- 재검토 조건

따라서 개별 행의 문장을 중복 복제하지 않으면서도 모든 결정이 책임 원본과 검증 조건에 연결된다.

## 최신 사용자 결정

- 후속 전체 적대적 검토는 `[보류]`다.
- 16개 개별 절초 설계는 `[보류]`다.
- `[연격 N]`은 최종 총피해를 N회로 나눈다. `10 + [연격 2] = 5/5`, `10 + [연격 3] = 3/3/4`다.
- 방어와 보호막은 하나의 `[방어도]`로 통합한다.
- 성장 경제·교착 감소·슬롯 예산·피해 묶음 트리거의 세부는 사용자 지시에 따라 권장안을 적용했다.
- PR #45의 BUILD 승인·구형 10전·구형 연격·구형 성장 비용은 현재 권한이 아니다.

## `[보류]` 의미

`[보류]`는 사용자 표시용 상태다.

- 결정 원장: `DEFERRED`
- 게이트: `HOLD`
- 런타임 구현 입력: 제외
- 재개 조건: 사용자의 명시적 재개·승인
