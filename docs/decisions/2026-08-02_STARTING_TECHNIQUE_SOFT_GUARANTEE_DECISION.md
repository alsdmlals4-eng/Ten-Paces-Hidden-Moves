# 시작 기술 4개 소프트 활성 보장 결정

- Decision ID: `TEN-DEC-20260802-STARTING-TECHNIQUE-SOFT-GUARANTEE-01`
- 승인일: 2026-08-02
- 상태: `CURRENT_APPROVED_PLANNING`
- 구현 권한: `PLANNING_ONLY`
- GrillMe 묶음: `7/10`
- 선행 결정:

  - `TEN-DEC-20260802-STARTING-TECHNIQUE-PRIMARY-STAT4-01`

## 1. 승인 결론

시작 무공 6개 중 선택한 4개의 첫 3성 기술을 모두 활성화할 수 있는 능력치 배분은 **항상 제공**한다. 그러나 네 기술의 동시 활성화를 시작 확정의 강제 조건으로 만들지는 않는다.

시작 설정에는 `[추천 배분]`을 제공한다. 추천 배분은 선택한 네 무공의 주 능력치 요구값 4를 모두 충족하는 **최소 해금 기준선**을 자동 구성하며, 남은 자유 분배점은 플레이어가 직접 전문화에 사용한다.

플레이어는 활성·잠금 상태와 결과를 확인한 뒤 일부 기술을 의도적으로 잠그고 특정 능력치에 집중할 수 있다.

## 2. 소프트 보장 범위

보장하는 것:

- 어떤 시작 무공 4개 조합을 선택해도 네 첫 기술을 모두 활성화할 수 있는 배분이 존재한다.
- `[추천 배분]`으로 최소 해금 기준선을 즉시 구성할 수 있다.
- 최종 확정 전에 예상 영구 능력치, 기술 활성·잠금 상태, 부족한 능력치 점수를 확인할 수 있다.
- 확정 전에는 무공 선택과 자유 분배를 다시 조정할 수 있다.
- 잠긴 기술이 남아 있어도 명시적 경고를 확인하면 시작 설정을 확정할 수 있다.

보장하지 않는 것:

- 네 기술의 동시 활성화를 강제하지 않는다.
- 추가 능력치나 무료 보정점을 지급하지 않는다.
- 플레이어가 선택한 극단 배분을 자동 수정하지 않는다.
- 7성 기술과 10성 절초의 요구치를 이번 규칙에 포함하지 않는다.

## 3. 추천 배분 계산

선택한 무공들의 주 능력치별 2성 보너스를 합산한다.

```text
해당 능력치 최소 직접 투자점
= max(0, 기술 요구값 4 - 기본값 2 - 선택 무공 2성 보너스 합)
```

추천 배분은 선택한 기술 네 개의 최소 직접 투자점을 모두 적용한다.

- 현재 배분의 미사용 점수만으로 부족분을 채울 수 있으면 기존 배분을 유지하며 부족분만 추가한다.
- 모든 점수를 이미 사용했지만 일부 기술이 잠겨 있으면, 추천 배분 적용 전에 변경 결과를 미리 보여준다.
- 적용하면 직접 배분을 최소 해금 기준선으로 재구성하고 나머지 점수를 미사용 상태로 돌려준다.
- 시작 확정 전에는 자유 분배 6점을 모두 사용해야 한다.
- 이미 네 기술이 모두 활성화되어 있으면 추천 배분은 능력치를 변경하지 않는다.

## 4. 조합별 필요 자유점 검증

| 선택 조합 구조 | 네 기술 활성에 필요한 최소 자유점 | 남는 전문화점 |
|---|---:|---:|
| 신법 무공 2개 + 서로 다른 다른 무공 2개 | 2 | 4 |
| 신법 무공 1개 + 서로 다른 다른 무공 3개 | 4 | 2 |
| 신법 무공 없이 다른 무공 4개 | 4 | 2 |

따라서 모든 시작 무공 4개 조합은 자유 분배 6점 안에서 네 첫 기술을 동시에 활성화할 수 있다.

신법 무공 두 개를 함께 선택하면 두 무공의 신법 +1이 합산되어 기본 신법 2에서 요구값 4를 자동 충족한다. 이는 승인된 조합 시너지이며 추가 무료점 지급이 아니다.

## 5. 시작 설정 표시 계약

최종 확정 전 한 화면 또는 동일 단계에서 다음 인과를 확인할 수 있어야 한다.

1. 기본 능력치 2
2. 자유 분배값
3. 선택 무공별 2성 보너스
4. 최종 예상 영구 능력치
5. 선택한 네 첫 기술의 활성·잠금 상태
6. 잠긴 기술별 부족한 주 능력치 점수
7. `[추천 배분]` 적용 전후 변화
8. 남은 자유 분배점

잠긴 기술을 남긴 채 확정할 경우 다음 사실을 명시한다.

- 무공·1성 패시브·2성 보너스는 유지된다.
- 해당 3성 기술만 잠긴다.
- 회차 중 영구 주 능력치 4 도달 시 자동 활성화된다.
- 임시 능력치 증감은 해금·재잠금 판정에 사용하지 않는다.

## 6. 설계 의도

- 초보자가 선택 구조를 몰라 기술을 우연히 잃는 문제를 막는다.
- 네 기술을 모두 사용하고 싶은 플레이어에게 즉시 이해 가능한 안전 배분을 제공한다.
- 일부 기술을 포기하고 특정 능력치에 집중하는 전문화는 유지한다.
- 무공 선택·2성 보너스·자유 분배·3성 기술 요구치의 인과를 한 단계에서 보여준다.
- 추천 배분이 정답 빌드를 강요하지 않고 해금 기준선만 제공하도록 제한한다.

## 7. 적대적 위험과 보호 조건

### 추천 배분의 정답화

추천 배분을 최종 빌드로 오인하면 자유 분배가 형식적인 선택이 될 수 있다.

보호 조건:

- 추천 배분은 `최소 기술 활성 기준`으로 표시하고 `최적 배분`이라고 부르지 않는다.
- 남은 2~4점의 전문화 선택을 별도로 강조한다.
- 전투 피해·승률·추천 무공 조합을 자동 최적화하지 않는다.

### 잠금 경고 피로

매 조정마다 팝업을 띄우지 않는다. 활성·잠금 상태는 상시 표시하고, 잠긴 기술이 남은 상태에서 최종 확정을 누를 때만 확인 경고를 제공한다.

### 신법 이중 효율

유운검결·무영십보 조합은 최소 해금 투자점이 다른 조합보다 2점 적다. 이는 현재 허용하지만 시작 선택률과 승률을 사람 검증에서 별도 추적한다.
