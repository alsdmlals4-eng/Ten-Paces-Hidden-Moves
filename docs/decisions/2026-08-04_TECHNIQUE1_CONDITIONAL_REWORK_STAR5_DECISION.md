## 1. 승인 결론

여섯 3성 기술1을 `낮은 실패 저점 + 조건 성공 시 높은 고점` 구조로 다시 설계한다. 기술의 유효 슬롯과 기력·내력 비용은 기존 승인 행동 새 가격 오버레이를 그대로 사용하고, 이번 결정은 기술1의 효과·조건·5성 patch를 최종 권위로 가진다.

5성은 추가 슬롯·기력·내력 소모 없이 현재 유효 사용 가능 예산의 약 `20%`를 무료 강화 예산으로 받는다.

```text
5성 무료 강화 예산
= round_half_up(기술의 유효 사용 가능 예산 × 0.20)
```

향후 기본 예산이 변경돼도 5성 예산을 자동 재계산하지 않는다. 별도 전후 비교와 사용자 승인으로 다시 확정한다.

## 2. 조건 난도 가격

조건부 효과는 정상 원가에 다음 계수를 곱하고 조건부 묶음 전체에서 한 번만 반올림한다.

| 난도 | 예상 성공 범위 | 가격 계수 | 원가 감소 |
|---|---:|---:|---:|
| 쉬움 | 약 70~85% | 0.85 | 15% |
| 보통 | 약 50~70% | 0.70 | 30% |
| 어려움 | 약 30~50% | 0.55 | 45% |
| 매우 어려움 | 약 15~30% | 0.40 | 60% |
| 극단적 | 약 15% 미만 | 0.25 | 75% |

조건 문장의 길이가 아니라 실제 실패 지점 수·상대 대응·실전 성공률을 기준으로 난도를 판정한다.

## 3. 조건 악용 방지 계약

- 조건이 만족된 경우에만 연결된 조건부 효과 묶음 전체를 얻는다.
- 조건 실패 시 부분 지급·이월·다른 효과 대체·기본 효과 전환을 모두 금지한다.
- 같은 행동이 스스로 만든 상태를 사전 조건처럼 사용해 조건 가격 감소를 받을 수 없다.
- 복수 조건은 하나의 복합 난도로 가격을 계산하며 할인율을 더하지 않는다.
- 조건은 선언된 trigger의 실제 전투 상태로 판정한다.
- `실제 체력 피해`는 사거리 밖·회피·중단·취소·체력 피해0을 성공으로 보지 않는다.
- `실제 유효 공격 회피`는 원래 적중 가능한 공격을 회피한 경우만 인정한다.
- 조건부 이동과 보상이 하나의 묶음이면 이동 실패 시 나머지 보상도 지급하지 않는다.

## 4. 연격 총피해 선계산 계약

연격은 타격별 피해 공식을 따로 계산하지 않는다.

```text
총 피해 D를 한 번 계산
→ 1타 = floor(D × 0.40)
→ 2타 = floor(D × 0.30)
→ 3타 = D - 1타 - 2타
```

- 능력치 배수와 총피해 반올림은 한 번만 적용한다.
- 후속타가 취소되거나 조건을 실패하면 해당 타격에 배정된 피해는 소멸한다.
- 취소된 피해를 앞 타격에 재분배하거나 다음 타격으로 이월하지 않는다.
- 피해감소·방어·회피·합은 실제 실행된 각 타격에 개별 적용한다.
- 5성에서 피해가 증가해도 총피해에 먼저 더한 뒤 같은 비율로 다시 나눈다.

## 5. 3성 기술1 재설계

| 기술 | 유효 구조·비용 | 실패 저점 | 성공 고점 | 효과 원가 / 예산 / 편차 |
|---|---|---|---|---|
| 유운삼첩 | 2수·기력1·내력1 | 기준 외공4 1타 피해5 | 총피해14 `5→4→5`·완주 후퇴1 | `58 / 61 / -3` |
| 금강가세 | 1수·기력1·내력1 | 방어4 | 완전 방어 시 방어7·강건1·기력1 | `31 / 31 / 0` |
| 운수회신 | 1수 반응·기력2·내력1 | 회피 시도 | 성공 시 회피·후퇴1·내력1·방어3 | `38 / 40 / -2` |
| 추풍일섬 | 1수·기력1·내력3 | 전진1 뒤 피해1 | 창끝 성공 시 총피해7·방어2 파괴 | `50 / 45 / +5` |
| 청심조식 | 1수·무비용·묶음당1회 | 내력1 | 저자원 성공 시 기력2·내력2·방어3 | `22 / 24 / -2` |
| 철각유영 | 1수·기력3·내력2 | 후퇴1·회피 시도 | 회피·추가후퇴 성공 시 후퇴2·절초기세1 | `48 / 46 / +2` |

모든 편차는 `±5틱` 범위 안이다.

### 유운검결 — 유운삼첩

```text
total_damage = floor(10 + EXTERNAL × 1.00)
hit1 = floor(total_damage × 0.40)
hit2 = floor(total_damage × 0.30)
hit3 = total_damage - hit1 - hit2
```

- 1타는 항상 실행한다.
- 1타가 실제 체력 피해를 주면 2타를 실행한다.
- 1·2타가 모두 실제 체력 피해를 주면 3타를 실행한다.
- 세 타 모두 실제 체력 피해를 주면 고정 후퇴1을 실행한다.
- 기준 외공4 총피해14는 `5→4→5`다.

가격:

```text
1타 피해5: 25틱
2타 피해4+추가타: 24×0.70=17틱
3타 피해5+추가타: 29×0.40=12틱
완주 후퇴1: 15×0.25=4틱
총 58틱
```

### 금강호체공 — 금강가세

```text
사용 즉시 방어4
→ 다음 자기 행동 전 실제 적 공격을 체력 피해0으로 완전히 흡수
→ 방어3 추가 + 강건1 + 기력1
```

빗나감·사거리 밖·취소·중단된 공격은 완전 방어 조건을 만족하지 않는다.

### 태극유전검 — 운수회신

```text
회피1 준비
→ 실제 유효 공격 회피 성공
→ 고정 후퇴1 + 내력1 + 방어3
```

공격이 없거나 회피에 실패하면 조건부 묶음을 얻지 못한다.

### 추풍창법 — 추풍일섬

```text
고정 전진1
→ 거리1~2 공격·기본 피해1
→ 전진1 완수 + 정확히 거리2 + 실제 체력 피해
→ 추가 피해6 + 방어2 파괴
```

전진이 막히거나 거리1에서 적중하거나 체력 피해가0이면 창끝 조건부 묶음은 발동하지 않는다.

### 청심양생공 — 청심조식

```text
행동 시작 시 기력+내력 snapshot
→ 항상 내력1
→ snapshot 합계≤1이면 추가 기력2 + 추가 내력1 + 방어3
```

기본 내력 회복으로 조건을 사후 충족할 수 없다. 묶음당1회 제한을 유지한다.

### 무영십보 — 철각유영

```text
고정 후퇴1 + 회피1 준비
→ 실제 유효 공격 회피 성공 + 두 번째 후퇴 칸 합법 완료
→ 추가 후퇴1 + 절초기세1
```

두 번째 후퇴가 막히면 절초기세만 따로 얻지 못한다.

## 6. 5성 무료 강화

| 기술 | 5성 무료 예산 | 강화 효과 | 책정 원가 / 편차 |
|---|---:|---|---:|
| 유운삼첩 | 12틱 | 총피해 +3 후 재분배; 외공4 `6→5→6` | `11 / -1` |
| 금강가세 | 6틱 | 완전 방어 성공 시 내력1 | `5 / -1` |
| 운수회신 | 8틱 | 회피 성공 시 절초기세1 | `7 / -1` |
| 추풍일섬 | 9틱 | 창끝 성공 시 후퇴1·방어2 | `9 / 0` |
| 청심조식 | 5틱 | 저자원 성공 시 체력2 회복 | `5 / 0` |
| 철각유영 | 9틱 | 완전 탈출 성공 시 강건1·방어1 | `8 / -1` |

5성 patch는 별도 슬롯·기력·내력 비용을 추가하지 않는다. 조건부 patch는 해당 조건이 실패하면 전부0이다.

유운삼첩 5성은 특정 타격에 피해를 직접 더하지 않는다.

```text
기본 총피해14 → 5성 총피해17
17을 40% / 30% / 나머지로 분배
→ 6→5→6
```
