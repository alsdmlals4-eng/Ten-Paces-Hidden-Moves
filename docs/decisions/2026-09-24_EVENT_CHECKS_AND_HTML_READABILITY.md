## 의도와 구현 계약

사건은 자원·수련·위험을 비교하는 짧은 선택이다. 모든 사건을 기연 지급 통로로 만들지 않는다. 일반 사건 4개와 기존 기연 관련 사건 6개를 제공한다. 각 사건은 상황 설명 한 번과 세 선택지를 갖는다. 도전 두 가지는 다른 능력치를 읽고, 안전한 떠나기는 무판정·무보상·무손실이다.

- 성공률: `clamp(50 + (능력치 - 난도) × 10, 10, 90)%`. 수치는 최초 조정값이며 Human 재미·밸런스 검증은 별도다.
- 일부 선택지에만 기연 후보가 있다. 선택 성공 뒤 독립 10% 판정을 추가한다. 성공률60%라면 최종 기연 확률6%다. 실패·일반 사건·안전 선택에는 기연 판정이 없다.
- 기연을 이미 보유했다면 희귀 보상 판정에 당첨되었을 때만 수련+3으로 전환한다. 일반 성공 보상과 별도로 표시한다.
- 회차 시드·비무·단계·사건·선택지·판정 종류로 결과를 고정한다. 클릭 반복·불러오기·다른 화면 열기는 재추첨하지 않는다. 결과 receipt는 저장 검증에서 재계산해 대조한다.
- 외공·근골·신법·내공·심안은 현재 실제 전투 시작 데이터의 플레이어 능력치를 읽는다. 현재 main은 각4다. PR #342의 영구 능력치 성장 구현을 이번 변경의 완료 사실로 흡수하지 않는다.
- 새 회차는 기연 규칙v2/저장schema6. 기존1·2와 기연v1/schema5는 당시 카탈로그·판정으로 계속된다. #342 후보schema3·4와 구분한다. 고정 v1 호환 자료는 사용자 저장을 열기 위한 코드이며 사용하지 않는 이미지 보관과 무관하다.
- HTML은 사건별 작은 표로 선택·관련 능력치·성공/실패·희귀 보상을 표시한다. 게임 판정은 Godot만 소유하고 JavaScript에 복제하지 않는다. 전체보기의 연속 읽기, 이미지 번호, 코멘트, 깊은 링크와 스크롤 위치를 보호한다.
