- 승인일: 2026-08-02
- 상태: `CURRENT_APPROVED_PLANNING`
- 구현 권한: `PLANNING_ONLY`
- GrillMe 묶음: `1/10`
- 선행 결정:
  - `docs/decisions/2026-07-24_PREPARE_AND_AUTO_PLACEMENT_RULE_CHANGE.md`
  - `docs/decisions/2026-08-02_OBSERVATION_STATS_MASTERY_DECISION.md`

## 1. 승인 결론

최신 기초 행동은 다음 10종이다.

1. 이동
2. 보법
3. 막기
4. 회피
5. 속공
6. 강공
7. 관찰
8. 명상
9. 준비
10. 장풍

현재 main의 8종 기초 행동 데이터와 ActionSelectionDock은 `[관찰]`과 `[장풍]`이 빠진 `IMPLEMENTED_LEGACY`다. 이 Decision은 제품 코드·런타임 데이터 변경 권한을 부여하지 않는다.

## 2. `[전조]`와 `[준비]`의 분리

### `[전조]`

- 다중 수 행동이 실행되기 전 점유하는 슬롯의 표시다.
- 공격·이동·강화·방어·상태 부여 등 독립 전투 효과가 없다.
- 2수 행동은 첫 수 `[전조]`, 둘째 수 `[실행]`이다.
- 3수 행동은 앞의 두 수 `[전조]`, 마지막 수 `[실행]`이다.
- 비용 선지불·중단·점유 슬롯 계약은 해당 행동 규칙을 따르며 `[전조]` 자체가 강화 효과를 만들지 않는다.

### `[준비]`

- 카드 ID `basic_stance`의 사용자 표시명이다.
- 독립된 1수 기초 행동이다.
- 실행하면 다음 비이동 행동에 승인된 강화 효과를 적용한다.
- 이동·보법은 준비 상태를 소비하지 않는다.
- 세부 강화 수명과 소비 규칙은 `2026-07-24_PREPARE_AND_AUTO_PLACEMENT_RULE_CHANGE.md`가 소유한다.
- 사용자 표시 용어 `[태세]`는 사용하지 않는다.

## 3. 기초 행동 `[장풍]`

| 항목 | 승인 규칙 |
|---|---|
| 출처 | `[기초]` |
| 행동 종류 | `[공격]` |
| 슬롯 | 2수: `[전조] → [실행]` |
| 비용 | 내력 1 |
| 사거리 | 1~3칸 |
| 피해 역할 | 속공보다 낮은 저위력 중거리 견제 |
| 능력치 참조 | 고정 기본 피해 + 내공 참조 |
| 사용 주체 | 플레이어와 적 모두 |
| 준비 상호작용 | `[준비]`의 다음 공격 강화 적용 |

정확한 고정 피해, 내공 계수, 반올림, 최솟값은 후속 밸런스 데이터에서 확정한다. 다만 최종 유효 피해는 동일 조건의 기본 속공 피해보다 낮아야 한다.

## 4. 현재 순번 `[합]`과 연격 지속

같은 수에 양측 유효 공격이 충돌하면 각 공격의 현재 순번 피해 단위끼리 합한다.

```text
현재 순번 피해 단위 원공격력 비교
→ 합 승패·동점
→ 패자 현재 피해 단위 취소 / 동점 시 양측 현재 피해 단위 상쇄
→ 승자 현재 피해 단위의 사거리·방향·회피·방어·체력 피해 정산
→ 중단·강건 정산
→ 양측 공격이 유지되고 양쪽에 다음 피해 단위가 있으면 다음 순번 합
→ 한쪽만 남으면 잔여 단독 타격
```

- 합 패배·동점만으로 공격 행동 전체를 자동 취소하지 않는다.
- 현재 순번 정산 뒤 양측 체력 피해가 0이고 두 공격 행동이 유지되면 다음 순번 피해 단위도 합에 참여한다.
- 체력 피해가 발생해 한쪽 공격이 중단되면 해당 공격의 미실행 후속 피해 단위가 취소된다.
- `[강건]` 등 명시적 중단 방지가 공격을 유지시키면 체력 피해가 있었더라도 다음 순번 합을 계속할 수 있다.
- 한쪽 피해 단위가 먼저 끝나면 상대의 유지된 잔여 피해 단위는 단독 타격으로 해결한다.

## 5. 사거리 밖 `[합]`

각 현재 순번 합 비교는 공격의 대상 사거리와 무관하게 진행한다.

```text
현재 순번 합 승패 결정
→ 승자의 현재 피해 단위 사거리 검사
→ 사거리 안이면 합 차이 피해 전달
→ 사거리 밖이면 해당 피해 단위의 대상 체력 피해 0
→ 양측 공격 유지 여부와 다음 피해 단위 확인
```

예시:

- 거리 3에서 속공과 장풍이 같은 수에 충돌한다.
- 두 공격의 현재 순번 합 비교는 정상 진행한다.
- 속공이 합에서 이겨도 상대가 거리 3이면 해당 합 차이 피해를 전달하지 못한다.
- 장풍이 합에서 이기면 상대가 사거리 안이므로 합 차이 피해를 전달할 수 있다.
- 사거리 밖 합으로 양측 체력 피해가 0이고 양쪽 공격에 다음 피해 단위가 남아 있으면 다음 순번도 다시 합한다.

사거리 밖 합 승리 보상·절초기세·전투 종료 등급 반영은 후속 Decision `TEN-DEC-20260802-OUT-OF-RANGE-CLASH-REWARD-01`이 소유한다.

## 6. 관찰 공개 태그

- 장풍은 `[공격]`으로 공개한다.
- `[전조]` 슬롯은 `[전조]`로 공개한다.
- 사용자 표시에서 `[태세]` 대신 `[준비]`를 사용한다.
- `[준비]` 행동은 `[준비]` 종류로 공개한다.

## 7. 검증 요구

1. 연격 `[8,5,7]` 대 `[6,7,4]`에서 1타 정산 후 양측 체력 피해가 0이면 2타도 합한다.
2. 2타 정산 후에도 양측 공격이 유지되면 3타도 합한다.
3. 현재 합에서 체력 피해로 한쪽이 중단되면 그쪽 후속타를 취소하고 상대 잔여타를 단독 해결한다.
4. 강건이 중단을 막으면 다음 순번 합을 계속할 수 있다.
5. 거리 3의 속공 대 장풍에서 속공 합 승리 시 속공 피해 0, 양측 공격이 유지되면 다음 순번 합 가능.
6. 거리 3의 장풍 대 속공에서 장풍 합 승리 시 장풍 합 차이 피해 전달.
7. `[전조]`만 점유한 상태에서 강화 상태가 새로 생성되지 않음.
8. `[준비]` 뒤 장풍 실행 시 준비 강화가 적용됨.
9. 장풍 기본 피해가 동일 조건 속공보다 낮음.
10. AI가 공개 상태만으로 장풍을 선택하고 플레이어 미확정 계획을 읽지 않음.

## 8. 남은 미결정
