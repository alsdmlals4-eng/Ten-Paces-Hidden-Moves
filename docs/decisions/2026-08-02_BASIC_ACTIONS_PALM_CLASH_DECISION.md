# 기초 행동 10종·장풍·사거리 밖 합 승인 결정

- Decision ID: `TEN-DEC-20260802-BASIC-ACTIONS-PALM-CLASH-01`
- 승인일: 2026-08-02
- 상태: `CURRENT_APPROVED_PLANNING`
- 구현 권한: `PLANNING_ONLY`
- GrillMe 묶음: `1/10`
- 선행 결정:
  - `docs/decisions/2026-07-24_PREPARE_AND_AUTO_PLACEMENT_RULE_CHANGE.md`
  - `docs/decisions/2026-08-02_OBSERVATION_STATS_MASTERY_DECISION.md`

## 1. 승인 결론

최신 기초 행동은 다음 10종이다.

1. 이동
2. 보법
3. 막기
4. 회피
5. 속공
6. 강공
7. 관찰
8. 명상
9. 준비
10. 장풍

현재 main의 8종 기초 행동 데이터와 ActionSelectionDock은 `[관찰]`과 `[장풍]`이 빠진 `IMPLEMENTED_LEGACY`다. 이 Decision은 제품 코드·런타임 데이터 변경 권한을 부여하지 않는다.

## 2. `[전조]`와 `[준비]`의 분리

### `[전조]`

- 다중 수 행동이 실행되기 전 점유하는 슬롯의 표시다.
- 공격·이동·강화·방어·상태 부여 등 독립 전투 효과가 없다.
- 2수 행동은 첫 수 `[전조]`, 둘째 수 `[실행]`이다.
- 3수 행동은 앞의 두 수 `[전조]`, 마지막 수 `[실행]`이다.
- 비용 선지불·중단·점유 슬롯 계약은 해당 행동의 규칙을 따르며, `[전조]` 자체가 강화 효과를 만들지는 않는다.

### `[준비]`

- 카드 ID `basic_stance`의 사용자 표시명이다.
- 독립된 1수 기초 행동이다.
- 실행하면 다음 비이동 행동에 승인된 강화 효과를 적용한다.
- 이동·보법은 준비 상태를 소비하지 않는다.
- `[준비]`의 세부 강화 수명과 소비 규칙은 `2026-07-24_PREPARE_AND_AUTO_PLACEMENT_RULE_CHANGE.md`가 소유한다.
- 사용자 표시 용어 `[태세]`는 사용하지 않는다.

## 3. 기초 행동 `[장풍]`

| 항목 | 승인 규칙 |
|---|---|
| 출처 | `[기초]` |
| 행동 종류 | `[공격]` |
| 슬롯 | 2수: `[전조] → [실행]` |
| 비용 | 내력 1 |
| 사거리 | 1~3칸 |
| 피해 역할 | 속공보다 낮은 저위력 중거리 견제 |
| 능력치 참조 | 고정 기본 피해 + 내공 참조 |
| 사용 주체 | 플레이어와 적 모두 |
| 준비 상호작용 | `[준비]`의 다음 공격 강화 적용 |

정확한 고정 피해, 내공 계수, 반올림, 최솟값은 후속 밸런스 데이터에서 확정한다. 다만 최종 유효 피해는 동일 조건의 기본 속공 피해보다 낮아야 한다.

## 4. 사거리 밖 `[합]`

같은 수에 양측 공격이 충돌하면 각 공격의 대상 사거리와 무관하게 `[합]` 비교 자체는 진행한다.

판정 순서:

```text
양측 유효 공격 시작
→ 현재 피해 단위의 원공격력 비교
→ [합] 승패·동점 결정
→ 패자의 현재 피해 단위 취소 또는 동점 상쇄
→ 승자의 합 차이 계산
→ 승자 공격의 대상이 현재 유효 사거리 안인지 검사
→ 사거리 안이면 합 차이 피해 전달
→ 사거리 밖이면 대상 체력 피해 0
```

예시:

- 거리 3에서 속공과 장풍이 같은 수에 충돌한다.
- 속공은 사거리 1, 장풍은 사거리 1~3이다.
- 두 공격의 `[합]` 비교는 정상 진행한다.
- 속공이 합에서 이겨도 상대가 거리 3이면 합 차이 피해를 전달하지 못한다.
- 장풍이 합에서 이기면 상대가 사거리 안이므로 합 차이 피해를 전달할 수 있다.

사거리 밖 승리도 패자의 현재 피해 단위를 취소한다. 단, 사거리 밖 합 승리에 기세·`ON_CLASH_WIN`·기타 합 승리 효과를 부여할지는 후속 GrillMe에서 확정한다.

## 5. 관찰 공개 태그

- 장풍은 `[공격]`으로 공개한다.
- `[전조]` 슬롯은 `[전조]`로 공개한다.
- 사용자 표시에서 `[태세]` 대신 `[준비]`를 사용한다.
- `[준비]` 행동은 `[준비]` 종류로 공개한다.

## 6. 검증 요구

구현 시 최소 다음 반례를 검증한다.

1. 거리 3의 속공 대 장풍: 속공 합 승리, 속공 피해 0, 장풍 현재 피해 단위 취소.
2. 거리 3의 장풍 대 속공: 장풍 합 승리, 장풍 합 차이 피해 전달.
3. 거리 4의 장풍 대 다른 공격: 합은 진행하되 장풍이 이겨도 피해 0.
4. `[전조]`만 점유한 상태에서 강화 상태가 새로 생성되지 않음.
5. `[준비]` 뒤 장풍 실행 시 준비 강화가 적용됨.
6. 장풍 기본 피해가 동일 조건 속공보다 낮음.
7. AI가 공개 상태만으로 장풍을 선택하고 플레이어 미확정 계획을 읽지 않음.

## 7. 미결정

- 장풍의 정확한 기본 피해·내공 계수·반올림
- 사거리 밖 합 승리의 기세 획득 여부
- 사거리 밖 합 승리에서 `ON_CLASH_WIN` 계열 효과 발동 여부
- 장풍의 합 승리·피격·중단 특수 효과 유무
