# 관찰 정답 유출 위험 가드레일 결정

- Decision ID: `TEN-DEC-20260805-OBSERVATION-ANSWER-LEAK-GUARDRAILS-01`
- 승인일: 2026-08-05
- 상태: `CURRENT_APPROVED_PLANNING_GOVERNANCE`
- 위험 상태: `ACCEPTED_PENDING_HUMAN_MEASUREMENT`
- 구현 권한: `PLANNING_ONLY`
- 활성 승인 배치: PR #92 · `8/10`
- 부모 권위: `TEN-DEC-20260802-OBSERVATION-STATS-MASTERY-01`

## 1. 승인 결론

기존 관찰 방식을 유지한다.

```text
관찰 행동 1수 사용
→ 관찰량 1 획득
→ 적이 현재 묶음을 먼저 확정·잠금
→ 저장 관찰량을 앞 수부터 1점씩 소비
→ 실제 행동 종류를 직접 공개
→ 플레이어가 공개 정보와 조사 정보를 바탕으로 계획 확정
```

관찰을 전술 단서·추론 문장으로 바꾸거나, 의도적으로 두 개 이상의 대응 후보를 남기도록 흐리는 B안은 채택하지 않는다.

## 2. 선택 이유

- 관찰은 현재 묶음에서 다른 행동 하나를 포기하는 명확한 기회비용이 있다.
- 관찰량도 공개 슬롯마다 1점씩 소비되므로 효과가 즉시 이해되어야 한다.
- 직접 행동 종류 공개는 행동 비용과 보상의 관계가 직관적이다.
- 단서 생성 방식은 상대 기술별 단서 작성, 후보군 계산, UI 설명, 로컬라이징, AI·콘텐츠 검증을 추가로 요구한다.
- 추가 작업량에 비해 핵심 재미 개선의 기대값이 낮다고 판단한다.
- 정확한 기술이 논리적으로 특정될 수 있는 경우는 관찰과 사전 조사에 비용을 지불한 결과로 허용한다.

## 3. 유지되는 관찰 계약

- 기본 `[관찰]`은 행동 슬롯 1수를 사용한다.
- 기본 `[관찰]` 1회는 관찰량 1을 획득한다.
- 공개 시 관찰량 1당 적 현재 잠금 묶음의 앞 슬롯 1개를 공개한다.
- 공개 순서는 앞 수부터다.
- 복합 기술은 해당 수에서 실제 발생하는 모든 행동 종류를 표시한다.
- 저장·획득 상한은 두지 않는다.
- 남은 관찰량은 묶음·라운드를 넘어 이월한다.
- 아직 계획되지 않은 미래 묶음을 관찰 때문에 미리 생성하지 않는다.
- 기력·내력 비용을 새로 추가하지 않는다.

## 4. 공정성 가드레일

```text
상태·회복 정산
→ 적 현재 묶음 계획
→ 적 계획 잠금
→ 관찰량 소비·공개
→ 플레이어 계획·확정
→ 해결
```

- 적은 공개 전에 현재 묶음을 잠근다.
- 공개 뒤 더 유리한 행동으로 계획을 교체하지 않는다.
- 적은 플레이어의 미확정 계획·대상·방향을 읽지 않는다.
- 공개 정보는 잠긴 실제 행동 종류와 일치해야 한다.
- 플레이어는 공개 뒤 자신의 묶음을 계획한다.

## 5. 계속 금지되는 정보

관찰은 다음을 직접 공개하거나 자동 계산하지 않는다.

- AI 가중치·선호 점수
- 정확한 기술명·무공서명
- 정확한 비용·방향·거리·피해·사거리·대상
- 권장 정답 대응

공개된 행동 종류와 비무 전 조사 정보를 플레이어가 조합해 하나의 기술을 추론하는 것은 허용한다. 시스템이 정답 대응까지 추천하는 것은 금지한다.

## 6. 위험 수용과 변경 Gate

관찰 정답 유출 가능성은 설계 변경으로 선제 제거하지 않고 사람 플레이에서 측정한다.

```yaml
risk_state: ACCEPTED_PENDING_HUMAN_MEASUREMENT
automatic_nerf: false
automatic_reprice: false
automatic_category_blurring: false
planning_change_requires_new_user_decision: true
```

측정값이 경고선을 넘더라도 자동으로 공개량·비용·분류를 바꾸지 않는다. 사용자 GrillMe 승인과 새 Decision이 필요하다.

## 7. 측정 지표

- 관찰 사용률
- 묶음당 소비 관찰량
- 전체 묶음 공개율
- 관찰 뒤 정확한 기술 추론율
- 관찰 사용 후 올바른 대응률
- 관찰 미사용 올바른 대응률
- 관찰 사용 전투의 등급 상승폭
- 관찰 미사용 승률

초기 권장 검토 기준은 유효 관찰 묶음 30개 이상이다.

경고 기본값:

- 정확한 기술 추론율 `70% 초과`
- 관찰 사용의 올바른 대응률 상승폭 `20%p 초과`
- 전체 묶음 공개율 `50% 초과`

이는 자동 밸런스 변경 기준이 아니라 수동 적대적 재검토를 여는 초기 권장값이다.

## 8. 적대적 검토 결론

### 유지

- 비용 대비 직관적인 직접 공개.
- 적 선잠금과 공개 뒤 계획 교체 금지.
- 앞 슬롯부터 공개하는 예측 가능성.
- 관찰량 저장과 이월.

### 기각

- 관찰 결과를 추상 전술 단서로 변환.
- 후보가 항상 둘 이상 남도록 강제.
- 직접 공개를 확률·모호도 표현으로 약화.

기각 이유는 구현·콘텐츠·검증 비용이 크고 현재 핵심 재미 개선의 기대값이 낮기 때문이다.

### 남은 위험

- 관찰을 충분히 축적하면 전체 묶음을 공개할 수 있다.
- 조사 정보와 행동 종류의 조합이 정확한 기술을 특정할 수 있다.
- 합·회피·체력 손실·라운드 기반 등급에서 관찰이 안전한 점수 생산으로 연결될 수 있다.

마지막 항목은 다음 Decision `GRADE_FARMING_RISK`에서 별도로 다룬다.
