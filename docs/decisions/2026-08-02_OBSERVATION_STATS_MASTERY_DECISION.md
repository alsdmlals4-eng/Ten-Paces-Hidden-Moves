# 관찰·스테이터스·무공서 성장 승인 결정

- Decision ID: `TEN-DEC-20260802-OBSERVATION-STATS-MASTERY-01`
- 승인일: 2026-08-02
- 상태: `CURRENT_APPROVED_PLANNING`
- 범위: 주요 비무 후보 구조, 비무 전 조사, `[관찰]`, 적 계획 잠금, 결착 압력, 스테이터스, 무공서 1~10성 성장
- 구현 권한: `PLANNING_ONLY`; 별도 Build 승인 전 런타임 변경 금지

## 1. 주요 비무와 후보 풀

- 핵심 비무는 5전까지 진행한다.
- 각 비무는 고정된 학습 역할 슬롯을 가진다.
- 각 슬롯은 후보 3명으로 구성하며 데모 후보 총수는 15명이다.
- 기존 연교·묵진·설하·청허·적우는 고정 5연전 상대가 아니라 각 슬롯의 기준 원형으로 취급한다.
- 첫 비무는 슬롯 1 후보 3명 중 1명을 `run_seed`로 선정한다.
- 이후 비무는 다음 슬롯 후보 3명 중 2명을 경로 종착점으로 제시하고 플레이어가 상대와 경로를 선택한다.

## 2. 비무 전 정보

비무 전에는 무림식의 짧은 인물·문파 소개만 제공한다.

조사로 확인 가능한 정보:

- 상대의 영구 스테이터스
- 보유 무공서와 현재 성취
- 무공서별 현재 사용 가능한 기술과 기술 조합
- 기술의 공개 규칙 정보: 행동 종류, 슬롯 수, 비용, 사거리, 고정 효과와 알려진 조건

비공개 정보:

- 실제로 선택한 현재 묶음의 행동
- 행동 순서·방향·대상
- AI 성향·가중치·선호 행동
- 정답형 파훼법

`public_tells` 또는 비무 전 행동 성향 자동 공개는 현행 권한이 없다.

## 3. 기본 행동과 무공 기술

전투 행동은 `기본 행동 + 무공서 기술`로 구성한다.

- 기본 행동은 모든 플레이어가 사용할 수 있는 공통 전투 문법이다.
- 무공서는 기술 묶음과 성장 단위다.
- 기술은 기본 행동을 강화하거나 여러 종류로 복합하며 기력·내력·기세 등 자원을 소모한다.
- 플레이어와 상대 모두 보유 무공서의 기술을 사용한다.
- `[관찰]`은 플레이어 전용 기본 행동이며 적 AI는 사용할 수 없다.

관찰 분류의 기본 집합:

- `[전조]`
- `[이동]`
- `[공격]`
- `[방어]`
- `[회피]`
- `[태세]`
- `[자원]`
- `[관찰]`

복합 기술은 해당 수에서 실제로 발생하는 모든 종류를 표시한다. 예: `[이동+공격]`, `[방어+이동]`.

관찰은 기술명, 무공서명, 정확한 비용, 이동 방향·거리, 공격 피해·사거리, 대상과 세부 수치를 공개하지 않는다.

## 4. 묶음 시작과 적 계획 잠금

한 라운드는 `3수 → 3수 → 4수`의 세 묶음으로 진행한다.

각 묶음의 순서:

1. 직전 묶음 종료 상태를 정산한다.
2. 적 AI가 현재 공개 상태만 사용해 이번 묶음의 계획을 확정·잠근다.
3. 이전에 축적된 관찰량만큼 적 계획의 앞 수부터 행동 종류를 공개한다.
4. 플레이어가 공개된 종류와 비무 전 조사 정보를 바탕으로 자신의 묶음을 계획·확정한다.
5. 양측 계획을 실행한다.

적은 다음 묶음을 미리 잠그지 않는다. 플레이어의 미확정 계획도 읽지 않는다. 플레이어에게 공개된 뒤에는 해당 묶음의 적 계획을 다른 행동으로 교체할 수 없다.

## 5. 관찰량과 이월

- 기본 `[관찰]` 1회는 관찰량 1을 획득한다.
- 관찰량은 다음에 적이 확정하는 묶음의 앞 수부터 공개한다.
- 공개량과 저장량에 상한은 없다.
- 관찰량이 현재 묶음 길이를 초과하면 남은 양을 다음 묶음으로 이월한다.
- 아직 계획되지 않은 미래 묶음은 미리 생성하지 않는다. 남은 관찰량을 예약하고, 해당 묶음이 현재 상황을 기준으로 확정되는 순간 적용한다.
- 3묶음에서 얻은 관찰량은 다음 라운드 1묶음에 적용한다.

예: 관찰량 6을 보유한 상태에서 4수 묶음이 확정되면 네 수의 종류를 공개하고 관찰량 2를 다음 묶음으로 이월한다.

## 6. 결착 압력

1~3라운드는 정상 규칙으로 진행한다. 4라운드 종료부터 양측에 결착 피해를 동시에 적용한다.

```text
결착 단계 = 라운드 - 3
결착 피해 = 최대 체력의 10% + (결착 단계 × 5)
```

- 4라운드 종료: 최대 체력 10% + 5
- 5라운드 종료: 최대 체력 10% + 10
- 이후 라운드 종료마다 고정 가산량이 5씩 증가한다.
- 결착 피해는 방어력·방어도·막기·회피·피해 감소·무적·반격을 무시한다.
- 3묶음과 상태 효과 정산 뒤 승패를 먼저 확인하고, 승패가 없을 때만 결착 피해를 적용한다.

결착 피해로 동시 전투 불능이 되면:

1. 결착 피해 직전 남은 체력 비율이 높은 쪽이 승리한다.
2. 비율도 같으면 해당 라운드의 유효 체력 피해량이 높은 쪽이 승리한다.
3. 두 값이 모두 같으면 무승부다.

## 7. 영구 스테이터스

핵심 스테이터스는 5종이며 주요 운용 구간은 `1~15`다.

| 스테이터스 | 역할 |
|---|---|
| 외공 | 외가 공격, 강공, 밀기, 방어 파괴 |
| 근골 | 최대 체력, 버티기, 방어도·강건 계열 |
| 신법 | 이동·보법·회피 계열 |
| 내공 | 최대 내력, 내가 효과, 호신·회복 계열 |
| 심안 | 관찰·간파·반격·전조 대응 계열 |

지속·전투 파생값은 체력, 기력, 내력, 방어도, 기세, 관찰량, 회피, 태세와 상태 효과로 분리한다.

기존 범용 `공격력`과 `방어력`은 최신 기획의 독립 영구 스테이터스가 아니다. 레거시 데이터 호환을 위한 별칭은 허용하지만 신규 기획은 `외공·근골·신법·내공·심안`을 참조한다.

## 8. 기술 효과와 스테이터스

무공 기술은 다음 세 층으로 구성한다.

1. 항상 적용되는 고정 효과
2. 허용된 수치에 대한 주·보조 스테이터스 참조
3. 특정 스테이터스 이상에서 활성화되는 기술별 임계 효과

피해·방어도·체력·내력·회복처럼 연속 보정 가능한 수치는 스테이터스를 참조할 수 있다.

이동 거리, 공격 사거리, 관찰량, 행동 슬롯 수, 회피 횟수, 전조 수, 복합 행동 구성, 비용 감소와 중단·반격 권한은 스테이터스 1점마다 연속 증가하지 않는다. 이러한 구조적 변화는 기술에 명시된 임계 효과로만 발생한다.

기본 `[관찰]`은 관찰량 1을 고정 획득한다. 관찰 강화는 관련 무공 기술의 5·9성 강화와 스테이터스 임계 효과에서 제공할 수 있다.

## 9. 무공서 수련과 성취

- 무공서는 1~10성이다.
- 시작 무공서는 기존 계약대로 3성에서 시작한다.
- 플레이어는 획득한 수련포인트를 선택한 무공서에 투자한다.
- 누적 수련포인트가 성취 비용을 충족하면 해당 무공서의 성이 상승한다.
- 기술마다 별도 수련도나 수련포인트를 쌓지 않는다.

기존 3성→10성 비용 계약을 유지한다.

| 도달 성 | 필요 수련포인트 |
|---:|---:|
| 4성 | 2 |
| 5성 | 3 |
| 6성 | 4 |
| 7성 | 5 |
| 8성 | 6 |
| 9성 | 8 |
| 10성 | 10 |

## 10. 성취별 보상

| 성 | 보상 |
|---:|---|
| 1성 | 무공서 고유 패시브 |
| 2성 | 무공서별 고정 영구 스테이터스 보너스 |
| 3성 | 기술 1 획득 판정 |
| 4성 | 무공서별 고정 영구 스테이터스 보너스 |
| 5성 | 기술 1 기본 강화 + 해당 기술의 스테이터스 임계 효과 추가 |
| 6성 | 무공서별 고정 영구 스테이터스 보너스 |
| 7성 | 기술 2 획득 판정 |
| 8성 | 무공서별 고정 영구 스테이터스 보너스 |
| 9성 | 기술 2 기본 강화 + 해당 기술의 스테이터스 임계 효과 추가 |
| 10성 | 무공서 고유 절초 획득 판정 |

짝수 성의 스테이터스 보너스는 무공서마다 고정한다. 상대도 같은 규칙을 사용하므로 무공서와 성취를 조사하면 영구 스테이터스 구성의 근거를 확인할 수 있다.

10성 보상은 `절초`로 고정하며 `진의` 선택지는 사용하지 않는다.

## 11. 기술 요구 스테이터스

- 무공서 성취 상승 자체에는 스테이터스 요구가 없다.
- 신규 기술을 획득하는 3·7·10성 보상에만 영구 스테이터스 요구를 둔다.
- 3성 기술 요구는 낮게, 7성 기술 요구는 중간, 10성 절초 요구는 높게 설계한다.
- 한 기술이 요구하는 스테이터스는 최대 2종이다.
- 3·7성 요구치는 정상적인 시작 분배, 짝수 성 보너스와 중간 노드 성장으로 무리 없이 달성 가능한 수준이어야 한다.
- 절초는 해당 무공에 집중한 빌드가 핵심 비무 5전 안에서 도달할 수 있는 높은 요구치를 사용한다.

무공서가 요구 성에 도달했지만 스테이터스가 부족하면:

- 해당 기술만 잠긴다.
- 무공서는 계속 수련하고 다음 성으로 상승할 수 있다.
- 기술 획득 기회와 성취는 소실되지 않는다.
- 이후 영구 스테이터스를 충족하면 별도 비용 없이 자동으로 사용 가능해진다.
- 한번 터득한 기술은 전투 중 일시적인 스테이터스 감소로 다시 잠기지 않는다.

5·9성의 기본 강화는 성취 도달 즉시 적용한다. 스테이터스가 부족하면 추가 임계 효과만 비활성화되며, 이후 조건 충족 시 자동 활성화한다.

## 12. 스테이터스 성장 경로

플레이어의 영구 스테이터스는 다음 경로로 형성한다.

- 시작 시 직접 분배
- 무공서 2·4·6·8성의 고정 보너스
- 주요 비무 사이 중간 노드의 수련·사건 보상

중간 노드는 자유 스테이터스 선택, 제시된 관련 스테이터스 중 선택, 특정 무공 수련포인트와 관련 스테이터스를 함께 주는 보상을 혼합할 수 있다.

## 13. GrillMe 병합 운영 규칙

- 사용자 승인 결정 10건마다 질문을 잠시 중단한다.
- 철회·정정된 중간 답변은 제외하고 살아 있는 최신 결정만 센다.
- 10건을 Decision·설계 Spec·planning data와 관련 정본 문서·Google Sheet에 통합한다.
- 충돌·누락·구형 참조를 검사하고 PR CI를 확인한다.
- PR을 main에 병합한 뒤 main과 Sheet를 다시 읽어 최종 SHA와 동기화 상태를 기록한다.
- 런타임 구현·Windows·사람 검증은 별도 실행 증거 없이 완료 처리하지 않는다.

## 14. 정본 우선순위와 폐기 항목

이 결정은 다음 충돌 표현보다 우선한다.

- 고정된 5명의 상대만 진행한다는 표현
- 비무 전 상대 행동 성향·대표 위협·파훼법을 자동 공개한다는 표현
- 적이 플레이어의 미확정 계획을 관찰한다는 표현
- 적이 현재 묶음보다 먼 미래 묶음을 미리 잠근다는 표현
- 관찰량에 묶음별 상한이 있다는 표현
- 범용 공격력·방어력이 신규 성장의 핵심 영구 스테이터스라는 표현
- 모든 스테이터스가 이동 거리·관찰량 같은 구조적 값을 연속 증가시킨다는 표현
- 기술마다 별도 수련도를 쌓는다는 표현
- 무공서 최대 성취가 7성이라는 표현
- 10성에서 절초와 진의 중 선택한다는 표현

구현·수치 데이터는 이 결정과 별도 Build Decision 전까지 `POC_HYPOTHESIS`다.

## 15. 검증 게이트

- 관찰량 이월이 3수·4수 묶음과 라운드 경계를 정확히 넘는가
- 관찰 전에 적 계획이 현재 상태로 확정되고 공개 뒤 변경되지 않는가
- 관찰 UI가 기술명을 누출하지 않고 복합 종류는 모두 표시하는가
- 적 AI가 플레이어 미확정 계획과 관찰 정보를 읽지 않는가
- 결착 피해·동시 전투 불능 판정 순서가 결정과 일치하는가
- 무공서 성취와 기술 잠금이 별도 수련도로 오해되지 않는가
