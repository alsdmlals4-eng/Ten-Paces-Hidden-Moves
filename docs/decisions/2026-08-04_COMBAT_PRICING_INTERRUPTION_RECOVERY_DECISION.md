## 1. 연결 행동과 전조 중단

- 2수·3수 행동의 전조와 실행은 하나의 `action_instance_id`로 연결한다.
- 전조 중 실제 체력 피해를 받고 `[강건]`으로 중단을 막지 못하면 연결된 행동 전체가 중단된다.
- 남은 전조 슬롯과 실행 슬롯을 모두 취소한다.
- 예: 1수 유운삼첩 전조 중 피격·중단되면 2수 유운삼첩 실행은 발생하지 않는다.
- 회피 성공, 방어로 체력 피해 0, 강건으로 중단 방지인 경우에는 후속 실행을 유지한다.
- 비용은 첫 슬롯에서 전액 선지불하며 확정 뒤 중단에는 환불하지 않는다.

## 2. 준비와 명상

- `[준비]`는 자원 소모 없이 1수를 소비하는 강화 행동이다.
- 이동·보법은 준비 상태를 소비하지 않는다.
- 준비된 명상은 기력 +1·내력 +1·절초기세 +1을 얻고 준비 상태를 소비한다.
- 같은 수의 공격으로 먼저 실제 체력 피해를 받고 중단되면 명상 회복은 발생하지 않는다.
- 해결 순서는 `대응 → 속공 → 이동 → 공격 → 살아남은 비공격 행동`이다.
- 같은 단계의 양측 공격은 기존 합 규칙으로 처리한다.

## 3. 이동·사거리 통합 가격

이동과 공격 사거리는 같은 거리 단가를 사용한다.

```yaml
distance_ticks_per_tile: 15
movement_formula: movement_tiles * 15
attack_range_formula: max(0, max_range - 1) * 15
```

| 구조 | 틱 가격 |
|---|---:|
| 이동 1칸 | 15 |
| 이동 2칸 | 30 |
| 이동 3칸 | 45 |
| 최대 사거리 1 | 0 |
| 최대 사거리 2 | 15 |
| 최대 사거리 3 | 30 |
| 최대 사거리 4 | 45 |

- 사거리1은 기본 근접 기준점이므로 0틱이다.
- 이동과 사거리를 함께 가진 기술은 두 ledger를 모두 합산한다.
- 밀치기·끌어오기·자리 교환처럼 추가 전술 이점이 있는 위치 변화는 이동 틱 외의 별도 효과 가격을 가진다.
- 거리5 이상도 동일한 15틱 선형 단가를 사용하되 10칸 전장과 기술별 합법 범위를 검토한다.
- 구형 `0/10/25/40틱` 최대 사거리 가격은 신규·수정 기술에 사용하지 않는다.

### 기존 승인 ledger의 마이그레이션

- 중앙 가격 변경은 기존 승인 기술의 효과나 ledger를 자동 수정하지 않는다.
- 기존 `poc_martial_arts.json` ledger는 승인 당시 가격 스냅샷을 유지한다.
- 새로 작성하거나 명시적으로 재검토하는 기술부터 이동·사거리 15틱 가격을 적용한다.
- 중앙 데이터의 `pricing_ticks`는 기존 승인 ledger 검증용 역사 스냅샷이고, 현재 작성 가격은 `active_authoring_distance_pricing_ticks`와 `range_pricing_contract`가 소유한다.
- 각 기존 기술은 후속 재검토에서 before/after 가격 차이와 편차를 먼저 공개한 뒤 효과·비용 변경을 별도로 승인한다.

## 4. 슬롯 예산과 자원 비용

```text
사용 가능 예산
= 슬롯 기본 예산
+ 기력 소모 × 4틱
+ 내력 소모 × 7틱
+ 절초기세·기타 확정 비용 허용량
+ 조건 허용량
```

| 항목 | 추가 예산 |
|---|---:|
| 기력 1 소모 | +4틱 |
| 내력 1 소모 | +7틱 |
| 절초기세 5 소모 | +30틱 |
| 체력 1 자해 | +3틱 |

- 슬롯 기본 예산은 1수20·2수50·3수80틱이다.
- 기력·내력 소모의 추가 예산은 슬롯 수와 독립적으로 누적한다.
- 따라서 1수 행동도 높은 기력·내력 비용을 확정 지불하면 2수 무비용 행동보다 높은 성능 예산을 가질 수 있다.
- 자원 비용은 첫 슬롯에서 전액 선지불한다.
- 계획 확정 전 제거 시에만 환불한다.
- 확정 뒤 전조 중단·사거리 실패·방향 실패·회피 등에는 환불하지 않는다.
- 실제 최대 자원으로 지불할 수 없는 비용은 설정할 수 없다.
- 면제되거나 실제로 지불되지 않는 비용은 같은 추가 예산을 받지 않는다.
- 절초도 기술별로 기력·내력 비용을 가질 수 있으며, 개별 비용과 효과는 각 절초 설계 Decision에서 확정한다.

## 5. 묶음 전환 자동 회복

전투 최초 1묶음 시작을 제외한 모든 묶음 전환 시 생존한 양측에 적용한다.

```yaml
stamina_gain: 1
internal_gain: 1
ultimate_momentum_gain: 1
resource_caps_apply: true
```

적용 전환:

- 1묶음 → 2묶음
- 2묶음 → 3묶음
- 3묶음 → 다음 라운드 1묶음

처리 순서:

```text
직전 묶음과 전투불능 정산
→ 기력 +1·내력 +1·절초기세 +1
→ 각 최대치 적용
→ AI가 회복된 공개 상태로 다음 계획 잠금
→ 관찰 공개
→ 플레이어 계획
```

기존 라운드 시작 기력 회복은 이 규칙으로 대체하며 중복 적용하지 않는다.

## 6. 절초기세 획득

- 묶음 전환: +1
- 준비된 명상: +1
- 실제 회피 성공: 회피 사건당 +1
- 합 승리: 공격 행동당 최대 +1
- 모든 획득은 절초기세 최대5를 넘지 않는다.

## 7. 가격 변경 영향

현재 작성 가격으로 기준 능력치4 기초 공격을 재평가한다.

| 행동 | 새 효과 원가 | 사용 가능 예산 | 편차 | 상태 |
|---|---:|---:|---:|---|
| 속공 | 25틱 | 24틱 | +1틱 | 허용 |
| 강공 | 70틱 | 61틱 | +9틱 | 재검토 필요 |
| 장풍 | 60틱 | 57틱 | +3틱 | 허용 |

- 위 표는 새 가격의 영향 감사이며 기존 승인 ledger 값을 덮어쓰지 않는다.
- 강공과 이동·사거리 효과가 있는 기존 기술은 후속 재검토 대상이다.
- 효과·피해·비용 조정은 별도 승인 없이 자동 적용하지 않는다.
