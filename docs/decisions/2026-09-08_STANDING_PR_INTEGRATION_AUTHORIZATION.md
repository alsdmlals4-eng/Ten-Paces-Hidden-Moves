# 관련 PR 통합 상시 승인

- 결정: TEN-DEC-20260908-STANDING-PR-INTEGRATION-01
- 상태: USER_APPROVED — repository publication pending
- 승인 근거: 사용자 최신 명시 지시 “번호 지정 허용 앞으로 필요없게해. 무조건 포함해서 검토흡수해서 교정 검증 병합 진행하는걸로 해.”
- 책임: 프로젝트 PR 통합 권한. Base 공용 규칙이나 다른 프로젝트의 권한은 변경하지 않는다.

현재 승인된 십보강호 작업과 관련되거나 겹치는 기존 open/draft/ready PR을 번호별 재질문 없이 조사·검토·흡수·교정·검증·병합한다. 기존 번호 지정 필수·일괄 read-only 규칙보다 이 프로젝트의 최신 사용자 승인이 우선한다. PR 번호는 추적 기록이지 실행 승인 입력이 아니다.

실제 diff와 현재 작업의 관계를 먼저 확인한다. 기존 branch·미커밋 파일·고유 자산을 보존하고 필요한 delta를 통합한다. draft는 미완료 사유를 해소하고 exact-head 검사와 검토를 통과한 경우에만 병합한다. 무관한 PR은 보존한다. 실패한 검사, 미해결 blocking review, 보안·비용·파괴적 마이그레이션, direct main push·force push·admin/ruleset bypass까지 승인한 것은 아니다.

이번 첫 적용 대상은 PR #321의 승인 전투 자산·UI·연출 변경이다. 해당 PR의 기존 성공 표시는 로컬·최신 main 재검증을 대신하지 않는다. 승인 블루프린트 구현은 그 검증 결과와 실제 consumer를 기준으로 이어간다.

검토 대안: 번호별 재질문은 사용자가 철회했다. 모든 PR 무검증 자동 병합은 무관한 변경과 실패를 유입한다. 채택안은 관련 PR 자동 포함 + 기존 exact-head 안전 Gate 유지다. 되돌리기는 이 결정을 후속 명시 지시로 대체하며 이미 병합된 제품은 별도 회귀·복구 절차를 따른다.
