# 상대 보조 무공·단계 예산과 설명 자료 복원

ID: TEN-DEC-20260910-OPPONENT-SUPPORT-BUDGET-READER-01

상태: 사용자 방향 승인 / 상세 튜닝 시작값 SPECIFIED / 런타임 연결·사람 밸런스 검증 전.
이 결정은 주력 한 권만 유지한다던 81쪽 편집판의 제한을 대체한다.

## WHY / HOW / WHAT

상대가 주력 무공만 반복하는 문제를 보완한다. 인물의 주력은 유지하고 거리·방어·회복·
보조 공격을 담당하는 두 권을 더한다. 열 번째 비무를 기준으로 하위 단계를 약화한다.
숫자 owner는 `docs/blueprint/OPPONENT_BUDGET.json`, 사람용 파생표는
`OPPONENT_STAGE_TABLES.md`다. 기술·강화 효과는 기존 무공 JSON이 소유한다.

## 대안과 채택

- 총 성수 합계를 예산으로 쓰기: REJECT. 성수별 수련 가격이 다르다.
- 실제 3성 이후 누적 수련 비용 + 별도 능력 합계: ADOPT. 10/5/3은43점,
  10/7/5는57점이다. 최종 기준57점은9승 자유수련54점과 행로 수련 선택의 사이에 놓는 시작값이다.
- 플레이어의 숨은 계획·구매 의도에 맞춰 적을 재편성: REJECT. 시작 때 정한 만남과 정보 경계를 지킨다.

능력40은 기존 성향 배분의 최종 목표이며 무공 보너스를 중복 가산하지 않는다.
자원 상한30/5/4는 별도다. 실제 플레이어 영구 능력 성장과 적 목표의 효과가 일치하는지
검증하기 전에는 “진검승부 보장”이나 난도 PASS로 쓰지 않는다.
비교 경로는 직전 승리당 자유6, 집중5+자유3, 행로 선택당 수련3을 구별한다.
집중분은 지정 무공 전용이며 전수 선택의 취득 기회비용도 별도로 기록한다.

## 제품 연결의 실제 경계

catalog의15명·slot별3명, shell/bridge/codec의 적 한 권 가정, 제약의 무공 대상,
정탐·브리핑·밸런스 측정 소비자를 함께 변경해야 한다. 공통 엔진은 이미 여러 권을 받는다.
후보 추가만으로 저장 content identity가 변한다. 이전 저장의 identity를 현재값으로 바꾸거나
진행 중인 적의 보유 무공을 몰래 늘리지 않는다. 기존 저장은 보존한다.
천기비성술5성의 관찰 강화는 enemy-forbidden 경계다. 적 고성수 적용 시 실제 카드 필터와
숨은 정보 차단을 검증하고, 플레이어 관찰 권한을 적에게 주지 않는다.
전수 보상은 기존처럼 주력 한 권3성을 유지한다. 보조 무공 보유는 보상 확장 승인이 아니다.

## 블루프린트 복원

불필요한 표지/경험/행로 장식 원화를 제거한다. 화면 아틀라스, 이미지 노드 흐름,
상태 영역을 포함한 행로, 사건 효과, 비무 브리핑, 매화삼첩 연격, 회피/피해 구분을 복원한다.
역사 PDF의 원본 내장 이미지를 비손실 추출하고 원본 해시와 출처를 보존한다.
옛 화면의 보상·거리·원형 자원 표시를 현행 규칙으로 오인하지 않도록 명시한다.
기존 가면 검객도 고유 이름·세 권의 무공·단계별 수치를 가진 인물로 연결한다.

제품 소비자·저장·공개 정보: 읽기 전용 표적 검토 완료, 변경/실행 PASS 아님.
