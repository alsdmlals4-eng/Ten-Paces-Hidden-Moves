## 문제와 선택

기존 오프라인 합 검토는 검이 하체에서 교차하고 접촉 자세를 고정해 불꽃을 시험했다. 교차 여부는 볼 수 있었지만 상체 힘겨루기와 판정 뒤 역할 차이는 표현하지 못했다. GIF 저장 성공을 연출 품질 완료로 취급하지 않는다.

| 대안 | 판단 | 이유 |
|---|---|---|
| 낮은 접점에서 VFX만 강화 | 제외 | 상체 긴장감 요청에 맞지 않고 자세 오류를 효과로 가릴 위험 |
| 기존 전투 카메라에서 상단 합과 결과별 반동 제작 | 채택 | 무대·상태 정보와 연결하며 얼굴·검·팔의 힘 관계 검토 가능 |
| 매 합 별도 클로즈업 전환 | 보류 | 반복 피로·카메라 복귀·거리 가독성 비용 증가 |

## 조사 후 제작

consumer는 `src/combat/combat_character_placeholder.gd`의 전투원 표현과 전투 해결 화면이다. 실제 상태 지원과 경로는 구현 시 다시 읽는다. 이 문서만으로 새 모션의 구현 완료를 주장하지 않는다.

새/변경 연출은 정본·승인 이미지·실제 카메라를 읽고 필요한 제작 사례를 조사한다. 출처·확인일·관찰 사실·한계·`ADOPT / ADAPT / REJECT`, 의도 감정·첫 시선·실루엣·시선 방향·체중·접점·여백·타이밍 대비를 기록한 뒤 제작한다. 유효한 동일 범위 조사만 재사용한다. 상위 benchmark gate를 생략하지 않는다. 이번 변경은 운영 기준 교정이며 신규 게임 기능·이미지 제작은 실행하지 않는다.

2026-09-09 열람한 1차 자료:

- [Riot VALORANT Gameplay Clarity](https://www.riotgames.com/en/news/valorant-shaders-and-gameplay-clarity): 스타일·성능·가독성 균형을 조정 적용. FPS 카메라·효과를 그대로 적용하지 않는다.
- [GDC Powerful and Effective Animation](https://www.gdcvault.com/play/1021657/Powerful-and-Effective-Animation-for): 공개 소개에서 키프레임·예비동작·smear·타이밍과 게임 제약을 확인. 전체 강연 시청이나 정량 효과 검증은 아님.
- 사용자 실사/애니메이션 이미지는 상체 교차·시선·힘 관계의 reference-only 자료다. 인물·복장·구도 전체 복제와 제품 포함은 하지 않는다. 배포 권리 검증 `NOT_RUN`.

## 상단 합

적용 범위: 아래 검 교차·금속 불꽃·검 반동은 **실제 접촉이 타당한 검 대 검 합 후보**에 한정한다. `docs/02_COMBAT_RULES.md`는 사거리 밖 합과 장풍 계열 합도 지원한다. 이 경우 억지로 접근시키거나 검 접촉을 만들지 않고, 실제 해결 사건·기술·presentation 계약에 맞는 비접촉/해당 기술 표현으로 분기한다. 상단 검 자세는 모든 합의 공통 필수 모션이 아니다.

- 두 사람 사이 어깨~턱 높이를 목표로 교차하되 얼굴은 가리지 않는다. 정확한 좌표는 카메라·자세 시안에서 검토한다.
- 손은 가슴 부근, 검은 위쪽에서 비스듬히 교차하는 후보를 우선한다. 손목·검 길이를 왜곡해 높이를 맞추지 않는다.
- 양쪽 손·팔·검 자세를 함께 교정한다. 불꽃만 위로 옮겨 가짜 접점을 만들지 않는다.
- 짧은 백금색 섬광과 금빛 금속 불꽃은 별도 VFX. 원화·VFX에 합 글자를 굽지 않고 결과 문구는 별도 UI로 둔다.
- 베기 VFX, 실제 검 이동을 표시한 진단선, 충돌 불꽃을 구분한다. 수동 검 위치 표식은 오차 있는 검토 자료이지 게임 판정 정본이 아니다.

## 판정 뒤 역할별 분기

| 단계 | 합 승자 | 합 패자 |
|---|---|---|
| 상단 접촉 | 중심을 유지하며 맞댐 | 같은 접점에서 맞섬 |
| 판정 직후 | 팔·검의 축을 유지하며 상대 검을 밀어냄 | 검이 바깥으로 밀리거나 튕기고 팔·어깨가 반응 |
| 회복 | 흐름을 정리해 안정된 다음 자세 | 균형을 회복하고 검을 준비 위치로 |
| 마지막 합 | 실제 비무 종료이면 종료 동작 | 실제 비무 종료이면 종료 동작 |

- 합 승패와 비무 승패를 구분한다. 최종 승리·패배 동작을 매 합에 재생하지 않는다.
- 피해·경직·이동·사망은 실제 판정에 있을 때만 표현한다. 합 패배 자체로 부여하지 않는다.
- 논리 위치가 유지되면 발이 다른 칸으로 밀려난 것처럼 표시하지 않는다. 국소 반동과 실제 이동을 구분한다.
- 무승부·중단·회피는 현재 규칙이 지원하는 결과만 다룬다. 모션 표를 채우려고 새 판정을 만들지 않는다.
- 플레이어 승리/상대 승리의 역할 반전 모두 검토한다. 방어는 받아낸 지점, 회피는 접촉 없는 경로로 구분한다.

## 제작·검증 순서

`조사·brief → 상단 접촉 핵심 자세 → 진입·접촉·승패 반동·회복 → 효과 없는 GIF → 효과 포함/감소 비교 → 최종 자산 승인 → 엔진 연결·캡처`

검토: 얼굴/손/검 식별, 무기 길이·그립, 프레임 연속성·접지, 역할 반전, 반복 피로, 텍스트 가림, 효과 off/on, 종료/중단 뒤 정상 상태. 음향·hit-stop·흔들림은 강도와 감소 경로를 따로 검토하며 임의 수치를 확정하지 않는다.

현재 증거는 낮은 접점의 오프라인 검토와 사용자 교정이다. 새 상단 자세·승패 반동 자산, Godot 연결·실행, Human·Android·출시는 `NOT_RUN`. 낮은 베기 후보와 승인 원본은 보존한다.

Base에는 조사·표현 의도·결과별 역할·효과 없는 검토 원칙만 반영한다. 이 문서의 무협 구도·높이·색은 프로젝트 전용이다. Base version lock은 교체하지 않는다.
