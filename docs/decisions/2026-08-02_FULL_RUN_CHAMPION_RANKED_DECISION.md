# 정식 회차·천하제일인·챔피언 랭킹 승인 결정

- Decision ID: `TEN-DEC-20260802-FULLRUN-CHAMPION-RANKED-01`
- 승인일: 2026-08-02
- 상태: `CURRENT_APPROVED_PLANNING`
- 범위: 데모·정식 회차, 주요 비무 6~10, 천하제일인 후보, 회차 초기화·영구 유지, 챔피언 등록, 비동기 랭킹전, 등록 AI 학습, 랭킹전 `[관찰]` 제한
- 구현 권한: `PLANNING_ONLY`; 별도 Build·온라인 서비스 승인 전 제품 코드·서버·런타임 변경 금지

## 1. 데모와 정식 회차

- 데모는 주요 비무 1~5까지다.
- 정식 출시의 기본 회차는 주요 비무 1~10으로 구성한다.
- 주요 비무 10전 이후 별도의 `[천하제일인]`전을 진행한다.
- 따라서 정식판의 완전한 한 회차는 `주요 비무 10전 + 천하제일인전`이다.
- 데모 5전은 전체 회차의 절반을 검증하는 종료 지점이며 세계관상 최종 완결점이 아니다.

## 2. 회차 성장과 영구 유지

회차 종료 또는 새 회차 시작 시 다음 전투력 요소를 초기화한다.

- 외공·근골·신법·내공·심안
- 무공서 성취와 투자 수련포인트
- 회차 중 획득한 무공서
- 기술·절초 활성 상태
- 체력·회차 재화·경로·중간 노드 효과

다음 발견·해금·기록 요소는 영구 유지한다.

- 발견한 무공서와 기술 도감
- 만난 상대와 조사 기록
- 신규 시작 무공서와 시작 선택지
- 인물·문파·이야기 진행
- 외형·편의 기능
- 제한적인 영구재화
- 천하제일인 도전·격파 기록
- 챔피언 등록본과 시즌·누적 기록

영구 성장은 다음 회차의 직접 전투력 누적이 아니라 선택지·정보·표현·기록 확장에 집중한다.

## 3. 주요 비무 1~10의 역할

- 1~5전은 기본 규칙 학습과 회차 빌드 형성 구간이다.
- 6~10전은 형성된 빌드의 숙련도와 약점을 검증하는 후반 구간이다.
- 후반 난도는 단순 체력·피해량 증가보다 기존 전투 문법의 복합화로 높인다.

권장 학습·검증 역할:

| 비무 | 역할 |
|---:|---|
| 6전 | 복합 행동과 여러 행동 종류의 추론 |
| 7전 | 거리·이동·사거리 통제 |
| 8전 | 기력·내력·기세의 자원 압박 |
| 9전 | 플레이어 주력 빌드의 약점 대응 |
| 10전 | 관찰·합·중단·절초의 종합 검증 |
| 천하제일인전 | 앞선 모든 체계의 최종 숙련 검증 |

후반 상대도 관찰 정보를 거짓으로 표시하거나 플레이어의 미확정 계획을 읽지 않는다.

## 4. 주요 비무 후보 규모

- 주요 비무는 학습 역할이 고정된 10개 슬롯이다.
- 각 슬롯은 후보 3명으로 구성한다.
- 정식판 주요 비무 후보 총수는 30명이다.
- 데모는 슬롯 1~5의 후보 15명을 사용한다.
- 한 회차에서는 각 슬롯 후보 중 일부만 만나므로 경로와 상대 조합이 달라진다.

## 5. 천하제일인 후보군

천하제일인은 단일 고정 인물이 아니라 무림에서 널리 알려진 전설급 인물 후보군으로 구성한다.

예시 범주:

- 천마
- 개방 태상장로
- 무림맹의 최고 고수
- 대문파의 태상급 인물
- 은거한 검성·도성 등 절대고수

이들은 일반적인 11번째 주요 비무 슬롯이 아니라 별도의 최종 후보군이다. 각 후보는 공통 전투 규칙을 유지하면서 서로 다른 최종 숙련 과제를 제공한다.

## 6. 천하제일인 후보 공개와 선택

- 회차 중에는 최종 후보를 예고하거나 출현 단서를 누적 공개하지 않는다.
- 주요 비무 10전을 완료한 뒤 후보 2명을 처음 공개한다.
- 후보 2명은 해당 회차의 경로·상대한 문파·수련한 무공·명성·사건 결과를 바탕으로 전설 후보군에서 선정한다.
- 후보 선정 계산식과 출현 조건은 공개하지 않는다.
- 플레이어는 두 후보의 스테이터스·무공서·현재 사용 가능한 기술을 조사한 뒤 한 명을 선택한다.
- 두 후보 모두 해당 회차 빌드로 정상 공략 가능한 범위여야 하며 시스템은 정답 후보나 예상 승률을 제시하지 않는다.

## 7. 챔피언 배틀 해금

```text
주요 비무 10전 완료
→ 천하제일인 후보 2명 공개
→ 상대 1명 선택
→ 천하제일인전 승리
→ 완주 캐릭터 등록 자격 획득
→ [챔피언 배틀] 해금·참가
```

`[챔피언 배틀]`은 본편 이후의 비동기 경쟁 콘텐츠다. 데모와 초기 세로 슬라이스 범위에는 포함하지 않는다.

## 8. 챔피언 등록 스냅샷

- 천하제일인전 승리 당시의 완성된 캐릭터 빌드를 수정 불가능한 고정 스냅샷으로 등록한다.
- 등록 뒤 현재 해금 상태에 따라 자동 갱신하지 않는다.
- 다른 회차를 완주하면 새 버전을 별도 등록할 수 있다.
- 한 사용자가 여러 등록 캐릭터 빌드를 보유할 수 있다.

등록 스냅샷 후보 필드:

- 캐릭터 이름·외형·칭호
- 외공·근골·신법·내공·심안
- 보유 무공서와 성취
- 사용 가능한 기술·절초
- 전투 자원·규칙에 영향을 주는 회차 완성 상태
- 게임 데이터 버전
- 천하제일인 격파 상대·완주 기록
- 등록 AI 행동 프로필

내 등록 캐릭터 A를 직접 조종하고 내 등록 캐릭터 B를 AI 상대방으로 불러 자체 비무할 수 있다. 자기 등록본 간 대전은 공식 랭킹과 승패에 반영하지 않는다.

## 9. 다른 사용자 챔피언과 비동기 대전

공식 대전 구조:

```text
내 등록 캐릭터 — 사용자가 직접 조종
vs
다른 사용자의 등록 캐릭터 — AI가 조종
```

다른 사용자의 등록 빌드 목록에서 다음 정보를 확인할 수 있다.

- 사용자명·캐릭터명·외형·칭호
- 주요 무공서와 성취
- 핵심 스테이터스
- 천하제일인 격파 기록
- 챔피언 배틀 승리·패배
- 연승·방어 성공
- 현재 시즌 평점·등급·랭킹
- 등록 시점과 데이터 버전

원시 입력 기록이나 비공개 계정 정보는 다른 사용자에게 공개하지 않는다.

## 10. 시즌 랭킹

공식 순위는 누적 승수가 아니라 시즌 평점으로 결정한다.

- 상대 평점과 경기 결과에 따라 평점이 증감한다.
- 사용자가 직접 조종한 도전 결과와 등록 캐릭터 AI의 방어 결과를 모두 반영한다.
- 동일 상대 반복 대전은 시즌 또는 기간별 제한 횟수까지만 평점에 반영한다.
- 자기 등록본 대전과 친선전은 평점에 반영하지 않는다.
- 시즌 종료 시 공식 평점과 순위는 초기화한다.
- 등록 스냅샷, 누적 전적, 최고 연승, 역대 최고 순위, 천하제일인 격파 기록은 유지한다.
- 누적 승수는 업적·인기도 지표로 별도 표시하며 공식 랭킹 산정의 주 지표로 사용하지 않는다.

정확한 평점 공식·시즌 길이·매칭 범위·어뷰징 방지 규칙은 온라인 서비스 설계 단계에서 별도 승인한다.

## 11. 등록 AI 학습 범위

등록 캐릭터의 AI는 사용자가 수동으로 고른 성향이 아니라 해당 캐릭터로 천하제일인전을 치른 실제 플레이 방식을 요약한 행동 프로필을 사용한다.

- 학습 데이터는 **선택한 천하제일인과의 최종전 한 경기**로 제한한다.
- 주요 비무 1~10과 등록 이후 챔피언 배틀 기록은 학습 데이터에 포함하지 않는다.
- 등록 시 행동 프로필을 생성하고 스냅샷과 함께 고정한다.
- 등록 뒤 자동 재학습·선택적 기록 추가·유리한 경기만 선별 학습을 허용하지 않는다.
- 과거 행동 순서를 그대로 재생하지 않고 현재 공개 상태와 등록 빌드에 맞춰 현재 묶음 계획을 생성한다.
- 학습 표본이 한 경기뿐이라 판단 근거가 부족한 상황은 공용 합리 AI가 보완한다.
- 등록 AI도 상대 사용자의 미확정 계획을 읽지 않는다.

행동 프로필 후보 항목:

- 선호 거리와 접근·이탈 빈도
- 공격·방어·회피 선택 비율
- 기력·내력·기세 보존·소비 기준
- 체력·자원 우위와 열세에서의 압박 변화
- 기술 조합과 절초 사용 시점
- 공개 행동 종류에 대한 대응 경향
- 위험 감수 성향
- 결착 압력 구간의 행동 변화

## 12. 랭킹전 `[관찰]` 제한

- 본편 비무의 `[관찰]`은 계속 플레이어 전용 기본 행동이다.
- 등록 AI 상대는 `[관찰]`을 사용할 수 없다.
- 공식 `[랭킹전]`에서는 대칭성과 공정성을 위해 **양측 모두 `[관찰]` 행동을 사용할 수 없다.**
- 이 제한은 랭킹전 전용 모드 규칙이며 본편·천하제일인전의 관찰 계약을 변경하지 않는다.
- 관찰을 강화하거나 관찰량을 전제로 하는 무공·기술의 랭킹전 호환 방식은 아직 승인되지 않았다. 별도 결정 전에는 자동 대체·무료 보상·임의 재설계를 금지한다.

## 13. 정본 우선순위와 대체 항목

이 결정은 다음 과거 표현보다 우선한다.

- 정식 회차가 주요 비무 10전에서 완전히 종료된다는 표현
- 천하제일인이 단일 고정 상대라는 표현
- 회차 중 후보 이명·실루엣·단서를 미리 공개한다는 표현
- 플레이 성향에 대응하는 후보 한 명이 자동으로 먼저 도전한다는 표현
- 첫 후보 승리 뒤에야 나머지 후보를 자유 선택한다는 표현
- 등록 캐릭터가 현재 해금 상태에 따라 자동 갱신된다는 표현
- 챔피언 배틀 순위를 누적 승수만으로 산정한다는 표현
- 등록 AI가 주요 비무 1~10 또는 등록 이후 경기까지 계속 학습한다는 표현
- 공식 랭킹전에서 플레이어만 `[관찰]`을 사용할 수 있다는 표현
- 서버·비동기 챔피언 배틀·자가 비무를 설계상 미정인 `HOLD`로 두는 표현

단, 온라인 서비스·서버·매칭·보안·운영 구현은 여전히 `FUTURE / NOT_AUTHORIZED`다.

- 등록 슬롯 수와 교체·삭제·보관 정책
- 공격자·방어자 평점 반영 비율

- 부정행위·승수 작업·계정 연계 방지
- 친선전과 자기 등록본 대전에서 `[관찰]`을 허용할지 여부
