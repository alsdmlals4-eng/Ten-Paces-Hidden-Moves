# 첫 5전 다양성과 실제 무공·유효 성과 연결

- Decision: `TEN-DEC-20260921-FIRST-FIVE-DUELS-GRADE-EVIDENCE-01`
- 사용자 승인: 2026-09-21 “좋아 작업 진행해. 강호행로 및 5번째까지 각기 다른 상대, 무공과 겨룰 수 있는 상태여야 해.” 기존 권장 P05 집계 구현 및 필요한 연관 교정의 연속 실행.
- 기준: PR342 `8403105196ad8d68bd484636be48d255b4d92ca3`, main `e5ec55e622d7c050e885e5bbdb698df9fd9bb8d3`. Base completed main `23ecad5a3084f97c4e5d1e39a9a6d70d1eeb37ef` 조회, 채택 계약은 BASE_RULES_VERSION을 유지한다. 이 SHA들은 이번 검증 기준이지 영구 최신 기준이 아니다.

## 행동과 보호 경계

1. 새 여정의 첫 5전은 인물 ID와 대표 무공 ID가 각각 중복되지 않게 추첨한다. 16명 승인 후보와 기존 단계별 능력·숙련·보유무공은 수정하지 않는다. 6~10전의 기존 반복 가중치는 유지한다. 저장된 `resolved_encounters`는 다시 뽑지 않고, 과거 중복 편성도 그대로 이어한다.
2. stats-v4 적 AI는 자신의 대표 무공을 최근 공개 해결 이력에 사용하지 않았고 체력·자원·거리·수 배치가 합법이면 소개 선택을 우선한다. 저체력 회복 및 정보 금지 경계는 유지한다. NPC에 금지된 관찰 overlay를 제거하거나 숙련도를 올리지 않는다. 언제나 매 전투 시전한다는 보장은 아니다. 선제 격파·중단·불리한 거리와 자원 부족에서는 사용하지 못할 수 있다. v1~v3의 AI 선택과 이미 잠긴 계획은 보존한다.
3. 실제 사용 감사에서 찾은 기존 대응 분기 결함을 교정한다. stats-v4의 무공 대응은 공통 막기로 대체하지 않고 작성된 효과 프로그램을 자기 실행 수에 시작한다. 회피 성공 조건 앞에서 대기하고 실제 같은 수 공격 후 조건부 후속 효과를 실행한다. 비용은 한 번, 임시 회피는 해당 수에 한 번 소비하며 미사용분은 수 종료에 만료한다. 정상 저장은 해결 완료 경계만 사용하므로 임시 continuation은 저장하지 않는다. 태극의 특별합·소요의 반격도 실제 결과를 기록한다.
4. 같은 v4 실제 공격 경로에서 무공 타격도 대응 방어/회피를 소비한다. 순수 효과 파이프라인 및 legacy 기본 경로는 callback이 없으면 종전 동작이다. 승인 무공 데이터, 피해 수치, 능력 요구치, 기초 대응 정의, 숨은 정보 경계는 변경하지 않는다.
5. P05는 승인된 등급 파밍 방지 집계만 구현한다. 원시 5지표를 유지하고 첫 3라운드의 적 공격 source/instance로 합·회피 성과를 집계한다. 같은 기술 1→0.5→0, 같은 공격의 다단 사건은 한 credit pool을 공유, 합/회피 각각 최대3, 실제 비용 외 효과가 있는 첫 절초1을 적용한다. 명상·이동·막기 상대의 무경쟁 특별합은 원시 기록을 보존하되 유효 합에서 제외한다.
6. 선택적 version1 `grade_ledger` 및 결과 `grade_summary`를 저장한다. 구형 누락은 `LEGACY_UNAVAILABLE`이며 상세 근거를 발명하지 않는다. malformed 근거는 거부한다. S/A/B/C 최종 산식·가중치·컷·보상 경제는 `FORMULA_PENDING`이며 이 결정이 승인하지 않는다.

## 경험 가설과 인수

가설: 첫 5명과 대표 기술이 다르고 실제 타격·이동·대응으로 드러나면, 다음 상대의 공개 습관과 거리에 맞춰 선택을 바꿀 이유를 제공한다. 반례: 이름/초상만 다름, 무공이 공통 막기로 처리됨, 첫 상대만 바뀜, 강호행로에서 진행/저장 단절, 이긴 결과를 주입해야 5전에 도달함. 기계 테스트는 이 반례를 검사하며 재미 만족을 판정하지 않는다.

인수: 여러 seed 첫5 고유성·16후보 도달·기존 저장 보존, 공개정보 AI 동일성, 태극/소요 조건 성공·실패·비용·타이밍·고성 반격·다음수/저장 경계, 실제 Windows UI의 5승/16행로·대표 효과 증거·결과 저장 readback. 상세 실행과 정확한 로그·캡처·한계는 기존 `docs/operations/2026-09-13_PLAYABLE_FLOW_IMPROVEMENT.md`에 누적한다.

최종 그림 4장 lock 전 PR342 Draft를 유지한다. Human 재미, 물리 입력, Android, 접근성 사용자, release는 별도 미검증이다. 후속은 P06 사건/공급량과 P12 정책별 측정이며 이번 성공 seed 하나를 전반 난이도 확정으로 승격하지 않는다.
