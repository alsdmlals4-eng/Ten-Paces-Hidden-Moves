# 무공서 → 해금 기술 → 수 자동 배치 UX 결정

- Decision ID: `TEN-DEC-20260801-MARTIAL-TECHNIQUE-UX-01`
- 상태: `APPROVED_PLANNING`
- 런타임 권한: `NONE`
- 작업 모드: `PLAN`

## 결정

전투 중 행동 선택의 제품 UX 정본은 다음 3단계 계층으로 고정한다.

```text
행동 출처 선택
├─ 기본 행동
├─ 무공서
│  └─ 해당 무공서에서 현재 해금된 기술
└─ 절초
   ├─ 기본 절초
   └─ 10성 해금 절초

기술 선택
→ 현재 행동묶음에서 가장 앞의 유효한 연속 빈 수에 자동 배치
→ 필요한 경우 이동 목적지 또는 공격 방향 지정
→ 진행 전까지 제거·재배치 가능
```

## 1. 전투 타임라인

- 한 라운드는 총 10수다.
- 묶음은 `1~3 / 4~6 / 7~10`으로 구성한다.
- 화면에는 전체 10수 진행도와 현재 편집 묶음을 동시에 표시한다.
- 현재 행동묶음만 편집할 수 있다.
- `[진행]` 후 현재 묶음은 잠기고 해결한다.

## 2. 무공서와 기술

- 무공서는 성장·계보·기술 분류 단위다.
- 무공서를 직접 수 슬롯에 배치하지 않는다.
- 실제 배치 대상은 해당 무공서에서 해금된 기술이다.
- 덱·손패·드로우·장착 기술 제한을 사용하지 않는다.
- 시작 시 후보 무공서 6권 중 4권을 선택하고 모두 3성으로 시작한다.
- 1/3/5/7/9/10성 해금 구조를 유지한다.

## 3. 기본 행동

기본 행동은 무공서와 분리된 고정 진입점으로 둔다.

초기 범위:
- 이동
- 보법
- 막기
- 회피
- 속공
- 강공
- 명상
- 준비

기본 행동과 무공 기술을 하나의 평면 손패처럼 섞지 않는다.

## 4. 다중 수 기술

- 1수 기술은 선택한 수에 실행한다.
- 2수 기술은 첫 수 `[전조]`, 둘째 수 실행이다.
- 3수 기술은 앞 2수 `[전조]`, 셋째 수 실행이다.
- 다중 수 기술은 하나의 연결 프레임으로 표현한다.
- 묶음 경계를 넘지 못한다.
- 비용은 첫 전조에서 전액 선지불한다.
- 중단돼도 비용과 점유 수를 환불하지 않는다.

## 5. 자동 배치

- 기술 선택 시 현재 묶음에서 가장 앞의 유효한 연속 빈 수를 찾는다.
- 연속 공간이 충분하면 즉시 배치한다.
- 공간이 없으면 실패 이유를 표시하고 계획을 변경하지 않는다.
- 자동 배치 이후 진행 전까지 제거와 재배치를 허용한다.
- 사용자가 명시적으로 수를 선택해 넣는 방식은 보조 편집 수단으로만 검토한다.

## 6. 절초와 절초기세

- 절초는 별도 진입점으로 둔다.
- 공유 절초기세는 `0/5`로 독립 표시한다.
- 기력·내력과 시각적으로 분리한다.
- 절초 선택 시 기세 5를 임시 예약한다.
- 진행 전 배치 제거 시 예약한 기세를 복원한다.
- 묶음 확정 후에는 소비를 되돌리지 않는다.
- 기본 절초와 10성 해금 절초를 구분하되 동일한 절초기세를 사용한다.

## 7. 빠른 접근

제품 P1에서 최근 사용 기술 또는 즐겨찾기 기술 3~4개를 `빠른 무공` 영역에 노출할 수 있다.

제약:
- 빠른 접근은 무공서 계층을 대체하지 않는다.
- 기술의 소속 무공서와 성급을 항상 추적 가능해야 한다.
- 자동 추천이나 정답 기술 제시는 하지 않는다.

## 8. 화면 계층

```text
상단 HUD
- 체력 / 기력 / 내력 / 절초기세

중앙 결투
- 1대1 전장 / 거리 / 상대 전조 / 판정 피드백

수 타임라인
- 전체 10수
- 현재 3수 또는 4수 확대 편집

행동 선택
- 기본 행동 / 무공서 / 절초
- 무공서 선택 시 해금 기술 표시

상세
- 점유 수 / 전조 / 실행 수 / 비용 / 사거리 / 이동 시점 / 타격 수 / 중단 위험
```

## 9. 금지

- 무공서를 직접 수 슬롯에 놓는 표현
- 무공 기술을 무작위 손패처럼 표현
- 다중 수 기술을 독립 카드 여러 장처럼 표현
- 현재 3수만 보이고 전체 10수 진행이 사라지는 화면
- 절초기세를 기력·내력과 합치는 표현
- 상대 실제 계획이나 정답 기술 추천

## 10. 후속 결정 필요

- 무공서 목록의 상세 레이아웃
- 기술이 많아졌을 때 검색·정렬·필터 방식
- 자동 배치 후 드래그 재배치의 정확한 입력 계약
- `준비 → 명상 → 절초기세 +1`의 제품 정본 유지 여부
- 패시브·진의의 전투 중 상시 표시 범위
