# 십보강호 전투 연출 기획서

> 책임: 최신 전투의 시선 흐름·수별 타격·합·중단·복기·접근성 폴백  
> 규칙 원본: `docs/02_COMBAT_RULES.md`

## 1. 연출 목표

화려함보다 “어떤 타격이 왜 살아남고 어떤 후속타가 왜 취소됐는가”를 우선한다. 모션·자산·음향이 없어도 같은 결과를 읽어야 한다.

## 2. 첫 시선

```text
10칸 전장·거리
→ 양측 자원·상태
→ 현재 3/3/4 묶음
→ 전조·실행 슬롯
→ 사용 가능 행동·기술
→ 진행 가능 이유
```

## 3. 현재 전투 흐름

계획·대상·예상 자원 → commit → 대응 → 수별 공격 행동 → 타격쌍 → 효과·중단 → 이동·일반 행동 → 다음 묶음 또는 종료 → 복기 → 결전 다시 시작.

## 4. 수별 판정 표현

같은 수 공격군의 합을 공격 행동 단위로 묶고, 내부 타격을 번호로 순차 표현한다.

```text
행동 시작
→ 1타 합/단독
→ 회피·방어도 차감·체력 피해
→ 효과
→ 중단·강건
→ 2타 ...
→ 행동 종료
```

현행 반환 토큰: `timing_results`; UI는 `presentation_events`를 재생한다.

## 5. 합 연출

- 양측 행동명과 `1타/3타`.
- 원공격력과 차이 원피해.
- 상쇄·승리·패배.
- 최종 피해와 방어도 변화.
- 행동당 기세 +1 획득 여부.
- 패자 후속타 취소와 승자 잔여타 전환.

## 6. 중단·강건 연출

`피해1 → 중단 시도 → [강건] 소비 → 행동 계속` 또는 `피해1 → 중단 → 남은 2타 취소`를 분리한다. `[강건]`은 피해를 막는 방패처럼 표현하지 않는다.

## 7. 효과 연출

- `PER_HIT`: 각 타격 아래 효과 아이콘·문구.
- `ONCE_PER_ACTION`: 최초 발동 뒤 잠금 표식.
- `ON_ACTION_START`: 현재 공격을 바꾸는 선적용 표식.
- `ON_ACTION_RESOLVE`: 비공격 행동 실행 결과.
- `ON_CLASH_WIN`·`ON_EVADE_SUCCESS`: 해당 판정 사건과 연결.
- `ON_HIT`: 적중 표시.
- `ON_HEALTH_DAMAGE`: 실제 체력 감소 수치와 연결.
- `ON_ACTION_END`: 행동이 완주된 뒤 발생하며 중단 시 미발동 표시.
- 취소·회피된 타격의 적중 효과가 나타나면 실패다.
- `[필중]`은 남은 스택과 실제 회피 우회 시 `-1`을 표시한다. 취소·중단·대상 부재·사거리 실패·회피 부재에는 스택을 소모하지 않는다.

## 8. 절초 연출

기본 절초 3종은 시작부터 표시하고 기존 예약·취소·기세 선소모 계약을 유지한다. 무공 10성 절초는 성급 도달 순간 목록에 추가하며, 주요 비무 5 승리 전역 해금 연출은 사용하지 않는다. 집중 경로의 “5전 전 10성 가능”은 예상치로 표시하고 보장 표식을 금지한다.

## 9. 종료·재시작 연출과 유료 재도전

마지막 타격쌍·동시 효과를 끝낸 뒤 승패·무승부를 표시한다. 패배 시 전투 직전 복원 범위, 같은 전투 재도전 횟수, 다음 `[영구재화]` 비용 1/2/3과 보유 잔액을 보여 준다. 결제 뒤 영구재화만 감소하고 전투 피해·임시 자원은 복원됐음을 요약한다. 잔액 부족 시 회차 포기·타이틀 복귀를 제시한다. 현행 T0 `결전 다시 시작`은 개발용 완전 초기화로 별도 표기한다.

## 10. 접근성 폴백

- 모든 핵심 사건에 텍스트 로그와 접근성 이름.
- 색·모션·음향을 단독 정보 채널로 사용하지 않음.
- 빠른 재생·즉시 완료·모션 감소에서 동일 이벤트 순서.
- 명시적 포커스와 결과 요약으로 타격 수가 많아도 탐색 가능.

## 11. 현재 상태

현행 연출에는 `timing_results`와 `presentation_events` 기반 기술 증거가 있으나 새 연격 이벤트는 미구현이다. `HUMAN_NOT_RUN`, 실제 읽기성·피로도·사운드 선호는 `UNVERIFIED`다.
