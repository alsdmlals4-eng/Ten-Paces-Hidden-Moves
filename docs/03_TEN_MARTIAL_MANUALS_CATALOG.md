# 초기 무공서 10권 카탈로그

> Decision: `TEN-DEC-20260806-TEN-RECOGNIZABLE-MARTIAL-MANUALS-FULL-GROWTH-01`  
> 상태: `APPROVED_DRAFT_PLANNING`  
> 수치·슬롯·비용 권위: `approved_20260806_ten_manual_growth_budget_overlay_contract.json`

## 1. [화산파] 매화검결 — 신법 / 외공

(3성) 기술1 **매화삼첩** - 근거리에서 최대 세 번 검격한다. 실제 체력 피해가 발생해야 다음 검격으로 이어진다.  
**5성 추가 효과 = 낙매유향:** 세 타가 모두 성공하면 후퇴하고 방어를 얻는다.  
(7성) 기술2 **낙매추영** - 1칸 접근한 뒤 거리 1~2에서 단발 합 공격을 한다.  
**9성 추가 효과 = 매화연세:** 합에서 승리하면 `[준비]`를 얻는다.  
(10성) 절초 **이십사수매화검법** - 접근 후 독립 3타를 펼치고, 두 번 이상 실제 체력 피해를 주면 추격하여 결착검을 가한다.

## 2. [소림사] 나한금강공 — 외공 / 내공

(3성) 기술1 **금강호체** - 방어와 `[강건]`을 먼저 얻는다. 다음 자기 행동 전까지 공격을 완전히 흡수하면 추가 방어와 기력을 얻는다.  
**5성 추가 효과 = 금강불괴:** 완전 흡수 성공 시 내력 1을 회복한다.  
(7성) 기술2 **대력금강장** - `[강건]`과 방어 2를 먼저 얻고 현재 방어를 기록한 뒤 외공 기반 근접 장격을 가한다.  
**9성 추가 효과 = 금강진력:** 실제 체력 피해를 주면 `[강건]`을 다시 얻는다.  
(10성) 절초 **여래신장** - 방어와 `[강건]`으로 이번 행동의 충격을 받아낸 뒤 짧은 도달 거리의 외공 장격과 상한 있는 추가 피해를 방출한다.

## 3. [무당파] 태극검결 — 심안 / 내공

(3성) 기술1 **운수검식** - 회피를 부여하고 성공 시 후퇴한 뒤 내력과 방어를 회복한다.  
**5성 추가 효과 = 유전회신:** 회피 성공 시 절초기세 1을 얻는다.  
(7성) 기술2 **사량발천근** - 심안 기반 합 공격을 하고, 승리하면 방어와 내력을 얻는다.  
**9성 추가 효과 = 음양전환:** 합 승리 시 상대를 1칸 밀친다.  
(10성) 절초 **태극혜검** - 상대 공격과 특별 합을 벌여 승리하면 공격을 흘리고 반격한 뒤 내력과 방어를 안정화한다.

## 4. [양가] 양가창결 — 외공 / 신법

(3성) 기술1 **추풍일섬** - 1칸 접근한 뒤 거리 1~2에서 찌른다. 정확한 창끝 거리에서는 방어를 추가로 파괴한다.  
**5성 추가 효과 = 이화회창:** 창끝 적중 성공 시 공격 후 1칸 후퇴한다.  
(7성) 기술2 **연환쇄로** - 두 번 찌르고 한 번 이상 적중하면 후퇴한다.  
**9성 추가 효과 = 쌍룡쇄로:** 두 타가 모두 적중하면 상대를 1칸 밀친다.  
(10성) 절초 **회마창** - 첫 찌르기 후 2칸 후퇴하고 사거리를 다시 확인한 뒤 되돌아 찌른다.

## 5. [화산파] 자하심법 — 내공 / 근골

(3성) 기술1 **자하토납** - 내력을 회복한다. 저자원 상태에서는 기력과 방어도 추가로 회복한다.  
**5성 추가 효과 = 자기양원:** 저자원 조건을 만족하면 제한된 체력 회복을 추가한다.  
(7성) 기술2 **자하회천** - 내력을 먼저 회복하고 `[강건]`·방어·체력을 순서대로 안정화한다.  
**9성 추가 효과 = 자하귀원:** 저자원 조건을 만족한 자하회천은 종료 후 `[준비]`를 얻는다.  
(10성) 절초 **자하신공** - 전투당 한 번 자원을 전투 복귀선까지 회복한다. 첫 전조에서 사용권을 소모하며, 실행 완료 시에만 절초기세 1을 회복한다.

## 6. [소요파] 소요보결 — 신법 / 심안

(3성) 기술1 **미진환보** - 먼저 후퇴하고 회피를 얻는다. 회피 성공 시 추가 후퇴와 절초기세를 얻는다.  
**5성 추가 효과 = 나영무흔:** 선행·후속 후퇴가 모두 성공하면 `[강건]`을 얻는다.  
(7성) 기술2 **소요환위** - 회피 성공 시 이동하기 전에 원래 공격자를 반격하고, 반격 후 최대 2칸 후퇴한다.  
**9성 추가 효과 = 유영귀허:** 반격의 합 위력이 증가한다.  
(10성) 절초 **능파미보** - 공격을 피하고 이동 전 반격한 뒤 공격자 반대 방향으로 최대 3칸 이동하고 `[준비]`를 얻는다.

## 7. [개방] 강룡장결 — 내공 / 근골

(3성) 기술1 **견룡재전** - 준비 없이 승인 사거리에서 중후한 내공 장력을 발사한다.  
**5성 추가 효과 = 잠룡물용:** 실제 체력 피해를 주면 방어를 얻는다.  
(7성) 기술2 **비룡재천** - 1칸 접근해 내공 기반 합 장력을 가하고, 합 승리 시 상대를 밀친다.  
**9성 추가 효과 = 항룡유회:** 합 승리 시 기력 1을 회복한다.  
(10성) 절초 **항룡십팔장** - 접근 후 내공 장력 합을 벌여 승리하면 방어 파괴·체력 피해·2칸 밀치기를 순서대로 적용한다.

## 8. [사천당문] 천기암기록 — 심안 / 신법

(3성) 기술1 **추혼표** - 거리 1~3의 단발 암기로 피해와 방어 파괴를 가한다.  
**5성 추가 효과 = 비성추혼:** 실제 체력 피해를 주면 `[관찰]` 1을 얻는다.  
(7성) 기술2 **폭우이화침** - 거리 2~4에서 암기 두 발을 독립 판정한다. 첫 적중은 방어를 추가로 파괴한다.  
**9성 추가 효과 = 유성귀영:** 한 발 이상 적중하면 공격 후 1칸 후퇴한다.  
(10성) 절초 **만천화우** - 거리 1~4에서 네 발의 암기를 차례대로 독립 판정한다.

## 9. [하북팽가] 팽가도결 — 근골 / 외공

(3성) 기술1 **맹호출림** - 거리 1의 묵직한 도격으로 피해와 방어 파괴를 가한다.  
**5성 추가 효과 = 호아파문:** 이 공격으로 상대 방어가 0이 되면 절초기세 1을 얻는다.  
(7성) 기술2 **백호단문** - 첫 도격 후 상대 방어가 0이면 두 번째 결착도가 이어진다.  
**9성 추가 효과 = 호맥강신:** 두 번째 도격이 발생하면 `[강건]`을 얻는다.  
(10성) 절초 **오호단문도** - 두 번의 파문도로 방어를 깎고, 상대 방어가 0이면 결착도를 내려친다.

## 10. [남궁세가] 창궁무애검법 — 내공 / 심안

(3성) 기술1 **철검십식** - 거리 1의 합 검격이다. `[준비]`를 소비하면 방어를 추가로 파괴한다.  
**5성 추가 효과 = 창궁입세:** 준비를 소비한 공격은 합 전에 방어를 얻는다.  
(7성) 기술2 **창궁검뢰** - 전조 후 거리 1~3에서 내공 기반 직선 검압 합을 수행한다.  
**9성 추가 효과 = 무애검세:** 정확한 거리 3에서 합에 승리하면 절초기세 1을 얻는다.  
(10성) 절초 **제왕검형** - 전조 뒤 특별 검압 합을 벌여 승리하면 방어를 깨뜨리고 단발 결착검을 가한다.
