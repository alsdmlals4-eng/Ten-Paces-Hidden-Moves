# GrillMe 벤치마킹·현업 비교 프로토콜

- 적용일: 2026-08-03
- 적용 범위: 이후 GrillMe 질문, 적대적 검토, 주요 기획 Decision
- 승인 카운트: 별도 Decision이 아니라 작업 절차이므로 카운트하지 않음

## 1. 목적

프로젝트 내부 논리만으로 권장안을 만들지 않고, 유사 장르·인접 시스템·현업 설계 관행을 비교해 왜 이 프로젝트에 맞거나 맞지 않는지 설명한다.

벤치마킹은 인기 게임의 규칙을 복사하는 절차가 아니다. 프로젝트의 핵심 재미인 `정보 읽기 → 견고한 비공개 계획 → 결정론적 해결 → 복기와 적응`을 강화하는지 판단하기 위한 외부 반례·대안 탐색이다.

## 2. 이후 GrillMe 기본 순서

1. 현재 GitHub·Google Sheet 권위 정본 확인
2. 사용자의 직전 의도와 제약 재확인
3. 충돌·누락·악용 가능성 적대적 검토
4. 최소 2개 이상의 관련 벤치마크 또는 현업 설계 패턴 비교
5. 프로젝트에 적용할 수 있는 점과 적용하면 안 되는 점 분리
6. A/B/C 선택지와 권장안 제시
7. 권장 이유·반대 이유·검증 지표 제시
8. 승인 시 같은 Decision ID로 GitHub·Sheet 동기화

## 3. 소스 우선순위

1. 개발사 공식 문서·패치노트·개발자 발표
2. 공식 또는 개발사 호스팅 위키
3. 신뢰할 수 있는 Game Developer·GDC 등 현업 자료
4. 최신 전문 분석·커뮤니티 위키는 보조 증거로만 사용

검색 결과가 실제 시스템을 뒷받침하지 않으면 억지로 사례를 끼워 넣지 않는다. 프로젝트에 더 적절한 직접 비교군이 없으면 인접 시스템임을 명시한다.

## 4. 비교 표준

각 사례마다 다음을 확인한다.

- 무엇을 제한하는가: 원천 스탯, 파생 수치, 획득량, 콘텐츠 공급, 적용 효율
- 어떤 성장 곡선을 쓰는가: 선형, 단계형, 점근형, 쌍곡선형, 지수형
- 플레이어가 수치를 이해할 수 있는가
- 극단 빌드가 허용되는가
- 극단 빌드가 핵심 규칙을 무효화하는가
- 시스템이 전략 다양성을 늘리는가, 하나의 최적해로 수렴시키는가
- 프로젝트의 수읽기·거리·합·중단·복기와 어떻게 상호작용하는가

## 5. 이번 무상한 능력치 비교에서 얻은 원칙

### Path of Exile 계열

핵심 속성은 계속 누적되어 장비·기술 요구치와 수치 보너스에 사용되지만, 저항·피해 감소·방어 확률처럼 전투 규칙을 무효화할 수 있는 파생 수치는 별도 한계를 가진다.

프로젝트 적용:

- 외공·근골·신법·내공·심안 자체에는 상한을 두지 않는다.
- 회피율·피해 감소율 같은 파생 효과는 별도 보호 계약을 둔다.

### Risk of Rain 2 계열

대부분의 스택은 계속 증가하지만, 100% 확률·완전 무효화에 가까워지는 효과는 쌍곡선형 감소 효율이나 실질 한계를 사용한다. 선형·쌍곡선·지수 스택을 효과 성격에 따라 구분한다.

프로젝트 적용:

- 모든 파생 효과에 동일한 선형 공식을 사용하지 않는다.
- 확률·감소율은 점근형, 피해·체력은 선형 또는 명시된 기술 배수를 우선한다.

### Vampire Survivors Limit Break 계열

많은 수치는 기존 최대 레벨을 넘어 계속 성장하지만, 특정 수치는 개별 성격에 따라 별도 제한을 둔다.

프로젝트 적용:

- 전체 시스템 공통 상한 대신 효과별 계약을 사용한다.
- 무상한 성장은 유한한 회차 보상 공급과 콘텐츠별 도달 최대치 검증으로 관리한다.

## 6. 금지 사항

- 유명 게임이 사용한다는 이유만으로 채택하지 않음
- 장르와 플레이타임이 다른 게임의 수치를 직접 복사하지 않음
- 벤치마크를 사용자 승인 대신 사용하지 않음
- 출처 없는 “현업에서는 보통” 표현 금지
- 프로젝트의 승인 정본과 충돌하는 외부 사례를 조용히 우선하지 않음

## 7. 출력 형식

이후 GrillMe에는 가능한 경우 다음 항목을 짧게 포함한다.

```text
벤치마크
- 사례 A: 사용 방식 / 장점 / 프로젝트 차이
- 사례 B: 사용 방식 / 장점 / 프로젝트 차이

적대적 판정
- 채택할 원칙
- 버릴 원칙
- 남은 위험

선택지
- A / B / C
- 권장안과 검증 지표
```

외부 비교가 실질적으로 도움이 되지 않는 질문은 사례를 억지로 추가하지 않고, 비교 가치가 낮다고 명시한다.
