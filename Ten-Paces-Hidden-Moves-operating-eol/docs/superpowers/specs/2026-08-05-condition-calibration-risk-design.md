## 목표

조건부 기술의 `실패 시 낮은 저점·성공 시 높은 고점`을 유지하면서 선언 난도와 실제 성공률이 달라 무료 고효율 또는 함정 기술이 되는 문제를 막는다.

## 권장 구조

- 현재 다섯 계수를 유지하고 성공률85% 이상 `준확정=1.00`을 추가한다.
- 가격 기준은 규칙을 이해한 일반 플레이어의 유효 시도 성공률이다.
- 공개 상태상 이미 불가능한 사용은 가격 분모에서 제외하고 오사용 지표로 남긴다.
- 숨은 상대 대응으로 실패한 사용은 유효 실패다.
- 한 condition group과 같은 trigger의 5성 patch는 성공을 한 번만 센다.
- 자동·실시간 repricing은 금지하고 충분한 증거와 별도 Decision으로만 재분류한다.

## 난도 구간

| 난도 | 성공률 | 계수 |
|---|---:|---:|
| 극단적 | 0~15% 미만 | 0.25 |
| 매우 어려움 | 15~30% 미만 | 0.40 |
| 어려움 | 30~50% 미만 | 0.55 |
| 보통 | 50~70% 미만 | 0.70 |
| 쉬움 | 70~85% 미만 | 0.85 |
| 준확정 | 85~100% | 1.00 |

## 실패 taxonomy

`PUBLIC_STATE_MISMATCH`, `PREDICTION_MISS`, `POSITION_FAILURE`, `INTERRUPTED`, `EVADED_OR_MISSED`, `NO_HEALTH_DAMAGE`, `PARTIAL_CHAIN_FAILURE`, `SUCCESS`.

## 보정 Gate

- 경고: 유효 시도30·전투10·선언 구간에서10%p 이상 이탈.
- 재분류: 유효 시도100·전투30 + Wilson 95% CI 전체 이탈 또는 같은 방향 연속 두 배치.
- 한 단계 차이: 새 계수로 원가와 ±5틱 편차 재검사.
- 두 단계 이상 차이: 조건 설계 자체를 적대적으로 재검토.

## 현재 값 동결

기술1 효과·비용·슬롯·선언 난도는 실측 전 변경하지 않는다. 사람·밸런스·Godot·Windows·접근성·성능 검증은 `NOT_RUN`이다.
